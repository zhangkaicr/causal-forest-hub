《grf 方法导论：广义随机森林》

原文：An introduction to grf（英文） · grf 官方文档中文译本

本教程介绍如何使用 grf 这个 R 包，借助随机森林来做因果推断。广义随机森林（generalized random forest，Athey、Tibshirani 与 Wager，2019）在 Breiman（2001）随机森林的基础上做了扩展，能够数据驱动地估计因果参数的异质性，例如在无混杂假设（unconfoundedness）下的条件平均处理效应（conditional average treatment effect，CATE）。下面我们概览其核心功能，包括平均处理效应的双稳健估计、最优线性投影（best linear projection）、用 TOC 曲线评估异质性的工具、用 Qini 曲线评价处理规则，以及学习可解释的基于树的策略。本教程包含两个应用实例，展示处理效应异质性在实践中的表现。更多细节可参见包文档，以及 Athey 与 Wager（2019）、Sverdrup、Petukhova 与 Wager（2024）的进阶应用教程。

我们将说明：在估计平均处理效应时，现代机器学习如何灵活地控制混杂；Breiman（2001）的随机森林如何被改造以针对处理效应的异质性；以及这种方法如何推广到一大类场景，包括工具变量（instrumental variable）和右删截结局（right-censored outcome）。更多内容可参考 Athey 与 Wager（2019）、Cui 等人（2023）、Dandl 等人（2024）、Friedberg 等人（2020）以及 Sverdrup 等人（2024）。关于更系统的理论论述，Wager（2024）提供了教科书式的讨论。

用机器学习做因果推断

机器学习方法天生是为预测而设计的。但在因果应用中，我们的目标往往是推断（inference）而非预测（prediction）。尽管统计估计与统计预测是不同的任务（Efron，2020），但预测工具用得合适时，也能支撑有效的推断。本节将概述：现代机器学习如何结合半参数统计（semi-parametric statistics）的思想，为因果推断提供灵活、且与具体模型形式无关（model-agnostic）的工具。

假设我们观测到结局 \(Y_i\)、二元处理指示变量 \(W_i \in {0,1}\) 以及协变量 \(X_i\)。我们的目标是估计平均处理效应（average treatment effect，ATE）\(\tau = \text{E}[Y_i(1) - Y_i(0)]\)。在观察性研究中，我们可能会跑一个回归 \[ Y_i \sim \tau W_i + \beta X_i, \] 并把 \(\hat\tau\) 解释为 ATE 的一个估计。这种解释依赖于以下几点：

  1. \(W\) 在给定 \(X\) 的条件下是无混杂的（unconfounded）（例如 Rosenbaum 与 Rubin，1983）。
  2. 混杂因素 \(X\) 对 \(Y\) 有线性影响。
  3. 处理效应 \(\tau\) 是恒定的（constant）。

假设 1) 是一个识别（identifying）假设，我们只能依赖领域知识来接受它。而假设 2) 和 3) 属于建模选择，是我们希望放宽的限制。

放宽假设 2)。不再假设线性，而是考虑部分线性模型（partially linear model）\[ Y_i = \tau W_i + f(X_i) + \varepsilon_i, \quad \text{E}[\varepsilon_i \mid X_i, W_i] = 0, \] 其中 \(f\) 是一个未知函数。难点在于 \(f(X_i)\) 并没有被事先指定。

Robinson（1988）指出，借助以下两个中间量——倾向得分（propensity score）\[ e(x) = \text{E}[W_i \mid X_i=x], \] 和条件均值（conditional mean），\[ m(x) = \text{E}[Y_i \mid X_i = x] = f(x) + \tau e(x), \] 我们可以把模型改写成中心化（centered）形式：\[ Y_i - m(x) = \tau \Big(W_i - e(x)\Big) + \varepsilon_i. \] 这意味着，\(\tau\) 可以通过把"残差化后的结局"对"残差化后的处理"做回归来估计。重要的是，Robinson（1988）证明：即使 \(m(x)\) 和 \(e(x)\) 估计得比较慢，这个估计量依然是 √n 一致的（root-n consistent）。这种稳健性常被称为正交性（orthogonality）：干扰参数（nuisance）估计中的微小误差，不会显著偏倚我们关心的目标参数。

背景与解释 · 正交化与去偏

Robinson 的中心化变换是整篇文章的"地基"。它的关键在于：我们并不需要对混杂函数 \(f(X)\) 估计得很准。把模型写成"残差化的结局 对 残差化的处理"之后，真正要估计的目标 \(\tau\) 与那些 nuisance（倾向得分 \(e\)、条件均值 \(m\)）被"解耦"了——只要 \(e\) 和 \(m\) 估计得"够好"（收敛速度比 \(n^{-1/4}\) 快即可），\(\tau\) 的估计误差就不会被它们带偏。这种性质叫作正交性（orthogonality），在半参数文献里也叫"去偏（debiasing）"。

对医学研究者而言，这点的价值在于：我们几乎从不知道协变量怎样真正影响结局，但可以用随机森林、提升方法等灵活地"黑箱式"去拟合，而不必担心某一步建模不准就毁掉因果结论。换句话说，机器学习在这里充当"预处理工具"，而因果推断的严谨性由正交结构来保证。

我们怎样灵活地估计 \(m(x)\) 和 \(e(x)\) 呢？它们本质上是标准的回归问题：用 \(X_i\) 预测 \(Y_i\)，以及用 \(X_i\) 预测 \(W_i\)。提升方法（boosting）或随机森林等现代机器学习方法非常适合这类任务（James 等人，2013）。这里有个小陷阱：直接把机器学习的估计值代入上面的估计量，会因为正则化（regularization）而引入偏倚。半参数估计中有一个标准技巧叫样本分割（sample splitting），即用不同的数据子集分别训练和评估这些分量。交叉拟合（cross-fitting）——轮流用不同的折（fold）做训练与估计——是常见的实现方式（Chernozhukov 等人，2018；Zheng 与 van der Laan，2011）。在 grf 中，袋外（out-of-bag）预测提供了一种"森林原生"的留一法交叉拟合。

放宽假设 3)。不再假设处理效应恒定，而是假设处理效应随协变量变化：\[ Y_i = \textcolor{red}{\tau(X_i)}W_i + f(X_i) + \varepsilon_i, \,\, \text{E}[\varepsilon_i \mid X_i, W_i] = 0, \] 其中 \(\textcolor{red}{\tau(x)}\) 是条件平均处理效应（conditional average treatment effect，CATE）\(\text{E}[Y_i(1) - Y_i(0) \mid X_i = x]\)。如果我们能找到一个邻域 \(\mathcal{N}(x)\)，在其中 \(\tau\) 近似恒定，就可以像之前一样，对属于 \(\mathcal{N}(x)\) 的样本做一次残差对残差（residual-on-residual）的回归，即：\[ \tau(x) := \text{lm}\Biggl( Y_i - \hat m^{(-i)}(X_i) \sim W_i - \hat e^{(-i)}(X_i), \text{weights} = 1\{X_i \in \mathcal{N}(x) \}\Biggr), \] 其中 \(^{{(-i)}}\) 表示袋外估计。从概念上讲，因果森林（causal forest）就是利用那些被预测为具有相似处理效应的样本，跑一个局部加权的残差对残差回归，从而估计出 \(\tau(x)\)。

关键在于如何构造这些权重。下一节将回顾 Breiman 的随机森林，并解释它如何充当"自适应邻域寻找器"（adaptive neighborhood finder）。

把随机森林当作自适应邻域寻找器

Breiman 的随机森林分两个阶段来估计条件均值 \(\mu(x) = \text{E}[Y_i \mid X_i = x]\)：

  1. 建树阶段（Building phase）：贪心地选择能使子组均值平方差最大化的协变量切分点，该平方差为 \(n_L n_R (\bar y_L - \bar y_R)^2\)。

  2. 预测阶段（Prediction phase）：对于目标样本 \(x\)，跨所有树取其落在同一个终端叶子（terminal leaf）\(L_b(x)\) 中的结局 \(Y_i\) 取平均：\(\hat \mu(x) = \frac{1}{B} \sum\limits_{b=1}^{B} \sum\limits_{i=1}^{n} Y_i \dfrac{1\{Xi \in L_b(x)\}} {|L_b(x)|}\)。

对于单棵树和单次切分，图 1 展示了所选的切分点：即那条能使叶子均值差异最大化的竖线。目标点 \(x\) 会落进其中一个叶子，预测值就是该叶子内结局的平均。对多棵树重复这一过程再取平均，就得到最终估计。

把预测式改写为 \[\begin{equation*} \begin{split} \hat \mu(x) & = \sum_{i=1}^{n} \frac{1}{B} \sum_{b=1}^{B} Y_i \frac{1\{X_i \in L_b(x)\}} {|L_b(x)|} \\ & = \sum_{i=1}^{n} Y_i \textcolor{magenta}{\alpha_i(x)}, \end{split} \end{equation*}\] 可以看出：随机森林的预测其实是结局的一个加权平均。权重 \(\textcolor{magenta}{\alpha_i(x)}\) 反映了训练样本 \(i\) 与 \(x\) 落在同一叶子的频繁程度。它们可以被理解为自适应相似度权重（adaptive similarity weights）。这种把随机森林看作加权过程的视角在统计应用中很常见，例如可参见 Zeileis、Hothorn 与 Hornik（2003）。

因果森林（causal forest）把这种森林权重与 Robinson 的方法结合起来：

  1. 建树阶段：选择能最大化"估计出的子组处理效应平方差"的切分点，即 \(n_L n_R (\hat \tau_L - \hat \tau_R)^2\)，其中 \(\hat\tau\) 由残差对残差回归算得。

  2. 预测阶段：用得到的森林权重 \(\textcolor{magenta}{\alpha(x)}\) 来估计 \[ \tau(x) := \text{lm}\Biggl( Y_i - \hat m^{(-i)}(X_i) \sim W_i - \hat e^{(-i)}(X_i),~ \text{weights} = \textcolor{magenta}{\alpha_i(x)} \Biggr). \]

因此，因果森林执行的是 Robinson 回归的"森林局部化"版本。在 causal_forest 中，参数 Y.hat 和 W.hat 提供 \(m(x)\) 和 \(e(x)\) 的估计，默认由独立的回归森林（regression forest）给出。如果我们处在随机化实验场景下、且已知倾向得分，就可以直接通过 W.hat 参数传入。Robinson 的变换还启发了一种针对异质性处理效应的通用损失函数（Nie 与 Wager，2021），causal_forest 用它来指导调参。

背景与解释 · 为什么用随机森林做因果推断

传统做法找"异质性"往往要先拍脑袋定下亚组（如"按年龄分层""按性别分层"），但真实世界的效应差异未必落在这些预设边界上。随机森林的妙处是把"找相似个体"这件事交给数据自己完成：每棵树的叶子就是一群特征相近的样本，跨树汇总后得到的权重 \(\alpha_i(x)\) 衡量"训练样本 \(i\) 与目标 \(x\) 有多像"。

这正是局部中心化（local centering）的思路——在这样一个自适应邻域里，处理效应近似恒定，于是又能套用 Robinson 的残差对残差回归。和普通线性回归只能给一个全局常数 \(\tau\) 不同，因果森林给的是每个 \(x\) 各不相同的 \(\tau(x)\)，而且不需要你事先假设效应随哪些变量、以什么形式变化。对临床异质性研究来说，这等于"用数据发现亚组"，而不是"用假设框定亚组"。

同样的思路并不限于处理效应和残差对残差回归。在广义随机森林框架中，森林被定制用来针对任意由估计方程（estimating equation）\(\psi_\theta(\cdot)\) 所定义的参数的异质性。给定一个在没有协变量时就能识别参数 \(\theta\) 的估计方程后，grf 会构造权重 \(\alpha(x)\)，从而给出针对各协变量取值的估计 \(\theta(x)\)，其蓝图正是 Breiman 的随机森林。对于因果森林，这个估计方程就对应 Robinson 的回归。

正交估计方程（orthogonal estimating equation）通过把各项统计任务分离开来，带来了实际好处。其他森林，如 instrumental_forest（工具变量森林）和 causal_survival_forest（因果生存森林），也采用类似构造。例如，causal_survival_forest 会拟合两个独立的生存森林，来构造对右删失（right-censoring）的校正。这些校正随后被用来构造一个正交估计方程，接着 grf 训练最终的随机森林，专门针对处理效应参数中的异质性。

出于计算与实现的考虑，grf 不会在建树阶段的每个候选切分处都重新估计目标参数。相反，它使用基于影响函数（influence function）的近似，这个近似只在父节点处计算一次。grf 随后复用标准的随机森林机制（Breiman 式的树生长和基于回归的切分），但把原始结局替换为从正交得分（orthogonal score）导出的伪结局（pseudo-outcome）。从实现角度看，这意味着：只要指定合适的得分和伪结局，就能构建新的森林估计量，而底层的随机森林算法保持不变。

注意：目标参数 \(\theta\) 可以是向量值。此时，切分依据的是平方 \(\ell_2\) 距离 \(n_L n_R \lVert \hat\theta_L - \hat\theta_R \rVert^2\)，正如 grf 中的 multi_arm_causal_forest 和 lm_forest 那样。

高效估计 CATE 的汇总量

Robinson 的残差对残差方法是正交的，因此很适合那些收敛较慢的估计。但如果我们想要 \(\tau(x)\) 的一些汇总量——比如 ATE 或最优线性投影（best linear projection，BLP）——并且要求它们具有保证的 √n 收敛速率，还要配上有精确置信区间呢？

简单地对估计值 \(\hat\tau(X_i)\) 取平均并不是最优的：预测误差太大，而且不会相互抵消。Robins、Rotnitzky 与 Zhao（1994）提出了增强逆概率加权（Augmented Inverse Probability Weighted，AIPW）估计量，它把倾向得分与条件均值估计结合起来，对其中任一分量估计误差都具有稳健性。它可以表示为一种"一步去偏"（one-step debiasing）校正，形式如下：

\[ \hat \Gamma_i = \hat \tau^{(-i)}(X_i) + \frac{W_i - \hat e^{(-i)}(X_i)}{\hat e^{(-i)}(X_i)[1 - \hat e^{(-i)}(X_i)]} \Big(Y_i - \hat \mu^{(-i)}(X_i, W_i)\Big), \] 其中 \(\mu(x, w) = E[Y_i \mid X_i = x, W_i = w]\)（这一点可以从因果森林的拟合结果中反推出来）。基于森林的 ATE 则为 \[ \hat \tau_{\text{AIPW}} = \frac{1}{n} \sum_{i=1}^{n} \hat \Gamma_i. \]

这种构造产生了双稳健（doubly robust）估计方程，并构成了 grf 中各类汇总方法的基础，包括 average_treatment_effect 和 best_linear_projection。相关的双稳健得分 \(\hat \Gamma_i\) 可通过函数 get_scores 获取。举个具体例子：ATE 就是 \(\hat \Gamma_i\) 的平均，而最优线性投影则是把 \(\hat \Gamma_i\) 对一组协变量 \(X_i\) 做回归。

背景与解释 · 双稳健与 AIPW 一步去偏

前面因果森林估的是每个点的 \(\tau(x)\)，但想要"整体 ATE""最优线性投影"这类汇总量，并且要 √n 速率和精确置信区间，就不能简单对 \(\hat\tau(x)\) 取平均（那样预测误差不会抵消）。AIPW 的解法是把两个 nuisance 估计——倾向得分 \(e\) 和条件均值 \(\mu\)——组合进一个校正项。

它的双稳健（doubly robust）性质意味着：只要 \(e\) 和 \(\mu\) 中有一个估计对了，得到的 ATE 就是一致且无偏的；即便两个都只估计得"还行"，一步校正仍能把它拉回到无偏。这是它比单纯回归或单纯逆概率加权更放心的地方。

对医学应用尤其友好：倾向得分模型或结局模型往往都不完美，双稳健给我们留了"容错空间"，而且 grf 自动产出这些得分（\(\hat\Gamma_i\)），ATE、BLP、TOC、Qini 全都基于它，保证下游推断口径一致。

用 TOC 曲线评估异质性

结合诚实估计（honesty）和子抽样（subsampling）等技术（Wager 与 Athey，2018），广义随机森林算法具备逐点渐近保证（pointwise asymptotic guarantee）。这类结果令人安心，因为它们刻画了森林在大样本下的行为。不过从实用角度看，还有更直接、更透明的方式来检验某个数据集中是否存在有意义的异质性。

一种简单而务实的做法是训练/测试集评估（train/test evaluation）。我们在训练集上拟合一个 CATE 模型，然后在留出（held-out）的测试集上，根据预测出的处理效应划分亚组，并检查各组的平均处理效应是否存在系统性差异。这种方法相当通用：我们可以评估任何机器学习得到的靶向函数（targeting function），包括替代性的效应指标，比如预测风险（predicted risk）或在某应用场景中可能与治疗获益相对应的其他量。只要"值越大、预期治疗获益越高"这一关系成立，同样的评估逻辑就适用（关于不依赖单一训练/测试划分的方法，可参见例如 Wager，2024）。

函数 rank_average_treatment_effect 提供了这一过程的自动化实现：它根据估计出的靶向函数的所有分位数，对测试样本进行分层。靶向算子特征（Targeting Operator Characteristic，TOC）曲线（Yadlowsky 等人，2024）把"预测 CATE 处于最高的 \(q\) 分位数中的个体"的平均处理效应，与整体 ATE 做比较。\[ \text{TOC}(q) = \text{E}[Y_i(1) - Y_i(0) \mid \text{Estimated CATE}(X_i) \geq (1 - q)\text{-th quantile}] - \text{ATE}. \] 给定一个训练好的评估森林后，grf 会给出 TOC 及其曲线下面积（area under the TOC）的双稳健估计，并附带标准误，从而可以对异质性的存在做简单而有效的 \(t\) 检验。在"处理效应恒定"的零假设下，TOC 曲线下面积的期望为零。

用户也可以提供两个估计出的 CATE，或者更一般地，提供两个靶向得分（targeting score），以比较两个优先级排序策略。rank_average_treatment_effect 函数随后会返回两条 TOC 曲线下面积之差的估计值与置信区间，可用于检验：这两个靶向得分在"给个体排治疗优先级"的能力上是否存在显著差异。

背景与解释 · 标签权重与 TOC 曲线怎么读

TOC（Targeting Operator Characteristic）曲线解决的是一个非常"临床决策"的问题：如果按模型预测的处理效应从高到低给人排序、优先干预，这种优先级策略到底有没有用？

这里的"标签权重"指的是用于排序的那个分数——通常是估计出的 CATE \(\hat\tau(x)\)。TOC(\(q\)) 比较的是"预测 CATE 位于最高 \(q\) 分位"那群人的平均处理效应，与整体 ATE 的差。直观上：如果高分位人群真的获益更大，TOC 就往上翘；如果处理效应处处相同（零假设），TOC 整条贴着 0，曲线下面积（AUTOC）期望为 0。grf 给出带标准误的双稳健估计，于是能直接做 \(t\) 检验。

一个实用提醒：AUTOC 不显著 ≠ 没有可干预的亚组。像下文贫困—注意力那例，整体检验不显著，但盯住某个预设分位（比如最低自主度那 20%）仍可能找到可信的正效应。TOC 的价值正在于把"有没有异质性"细化成"在哪个优先级区间有异质性"。

用 Qini 曲线评估策略

我们经常关心用数据驱动的规则来指导治疗分配决策，这类规则也称为策略（policy）。在二元处理下，一个策略就是一条规则 \(\pi(X_i) \in \{0, 1\}\)，把协变量映射到某个处理决策。一个策略的价值（value）就是遵循它所带来的预期收益，\[ G(\pi) = \text{E}[\pi(X_i)\{Y_i(1) - Y_i(0)\}]. \] 给定双稳健得分 \(\hat \Gamma_i\) 后，我们可以通过对满足 \(\pi(X_i) = 1\) 的样本求 \(\hat \Gamma_i\) 的平均，来估计任意固定策略的价值。一个估计出的 CATE 函数 \(\hat\tau(\cdot)\) 会自然地诱导出各种靶向规则。一个简单的例子是阈值策略（threshold policy）\[ \pi_0(X_i) = \begin{cases} 1,& \hat \tau(X_i) \geq 0\\ 0, & \text{otherwise}. \end{cases} \] 如果真实的 CATE 已知，最优策略就会去处理那些满足 \(\tau(X_i) \geq 0\) 的个体。由于我们只有估计值 \(\hat\tau(\cdot)\)，于是改为通过估计其价值 \(G(\pi_0)\) 来评估这类数据驱动策略的表现。

很多时候，治疗是有成本或受限的，我们可能只能处理人群中的一部分。例如，我们可以按预测效应排序、以第 80 百分位为阈值，专门处理排在前 20% 的个体。改变这个阈值，就得到一族由"被处理比例预算"\(B \in (0,1]\) 索引的策略。Qini 曲线通过画出下式来总结它们的表现：\[ G(\pi_B) = \text{E}[\pi_B(X_i)\{Y_i(1) - Y_i(0)\}], \] 其中 \[ \pi_B(X_i) = \begin{cases} 1, & \hat\tau(X_i) > 0 \text{ and } \hat\tau(X_i) \ge (1-B)\text{-th quantile of positive predicted CATEs} \\ 0, & \text{otherwise}. \end{cases} \] 利用双稳健得分和合适的重抽样方法，我们可以得到整条曲线上 \(G(\pi_B)\) 的置信区间。这一方法在姊妹包 maq（Sverdrup 等人，2025）中实现，该包还支持带可变成本的多处理臂——它通过求解一个中间的线性规划（linear program），把预测效应与成本映射为受预算约束的策略。

学习可解释的策瑋

在某些应用中，直接依据复杂、黑箱式的 CATE 预测来分配治疗并不可取。决策者往往要求透明、可解释的决策规则——只基于少数几个可观测特征来分配治疗。这类策略易于沟通和落地（例如，在数据库查询里写几条条件语句即可），同时又利用了处理效应的异质性。

给定实验性或观察性数据，我们可以通过最大化策略价值来学习这类可解释策略，\[ V(\pi) = \text{E}[Y_i(\pi(X_i))], \] 其中我们把策略 \(\pi\) 限制在一类预先指定的规则中，例如浅层决策树（shallow decision tree）。由于反事实的两个潜在结局我们永远无法同时观测到，我们需要合适的奖励代理（reward proxy）。结果证明（Athey 与 Wager，2021）：用 \(\text{E}[Y_i(1)]\) 和 \(\text{E}[Y_i(0)]\) 的双稳健得分作为奖励代理，就能高效地求解该问题的经验对应版本。 grf 包会自动构造这些得分，而姊妹包 policytree（Sverdrup 等人，2020）负责求解浅层（depth-k）决策树的优化问题。这会产出简单的处理规则，既能在留出数据上评估，也能与"全治"或"全不治"这类自然基线做比较。

实例：处理效应的异质性与金融素养

作为一个简单的实证示例，我们用 causal_forest 函数来分析一项随机对照试验（RCT），该试验测量了金融教育的效果。Bruhn 等人（2016）把巴西的高中随机分配参与一个金融教育项目，并测量了诸如金融素养（financial proficiency）等结局。在学校层面做随机化，可以避免学生之间的相互干扰。我们使用 grf 内置的一份已处理数据，包含约 850 所高中、约 17,000 名学生的个体层面信息。结局是处理后的金融读写能力，共有 13 个处理前协变量，包括问卷回答，以及衡量学生储蓄能力和财务自主度的两个指数。

有 4% 到 10% 的协变量含有缺失值（NA）。我们假设缺失是随机的并将其保留，因为 grf 通过"把缺失性纳入属性"（missingness incorporated in attributes，MIA）切分来处理缺失数据（Mayer 等人，2020；Twala 等人，2008）。

这里我们用袋外预测既来构造 \(\hat\tau(\cdot)\)，又来评估 TOC。由于复用了同一批数据，所得 \(t\) 统计量便没有确切的有限样本保证。我们没有做显式的训练/测试划分，而是采取一个务实的启发式做法：报告我们关注方向上的单侧检验（AUTOC \(> 0\)）。在本例中，单侧检验并未拒绝"无异质性"的零假设。

背景与解释 · 诚实估计与袋外数据的陷阱

诚实估计（honest estimation）是让森林推断"靠得住"的关键技巧。做法上，它把样本一分为二：一部分只用来决定树怎么切（选切分点），另一部分只用来估计叶子里的参数值。这样叶子里的估计就不会"记住"自己参与挑选的结构和噪声，从而避免过于乐观的、过拟合的异质性结论。

本例里我们用的是袋外（OOB）预测：每个样本都被它没参与建树的那些树来打分。OOB 天然近似留一交叉拟合，很方便；但要注意——当同一批 OOB 预测既用于构造 CATE、又用于评估 TOC 时，数据被复用了，严格意义上的有限样本保证就不再成立。文中因此改用"单侧检验 + 务实启发式"来下结论。

对医学研究者的重要提醒：在报告"某亚组效应显著"之前，务必确认它建立在独立验证（诚实估计 / 留出测试集 / 显式训练—测试划分）之上，否则很容易把随机波动误当成真实的疗效差异，进而误导治疗决策。

不过，TOC 在评估替代性优先级策略时依然有用。例如，金融自主度较低的学生可能获益更多。因果森林的变量重要性（variable importance）证实了 financial.autonomy.index 是一个关键预测变量：

var.imp <- variable_importance(c.forest)
head(colnames(X)[order(var.imp, decreasing = TRUE)])
#> [1] "financial.autonomy.index"           "intention.to.save.index"           
#> [3] "family.receives.cash.transfer"      "father.attened.secondary.school"   
#> [5] "is.female"                          "has.computer.with.internet.at.home"

我们可以构造一条 TOC，专门给金融自主度较低的学生排更高优先级：

rate.autonomy <- rank_average_treatment_effect(
  c.forest,
  -1 * X$financial.autonomy.index, # Negate priorities to rank by lowest first.
  q = seq(0.05, 1, length.out = 100),
  subset = !is.na(X$financial.autonomy.index))
plot(rate.autonomy, main = "TOC: By increasing financial autonomy")

结果显示：金融自主度处于最低 20% 的学生，其 ATE 比整体平均高出约 1.1 分，且置信区间不含零。

像这样的培训项目，通常要投入资源才能实施、推广到大量学生。这里的分析表明，把资源投向金融自主度低的学生，可能是一种可取的策略。如果我们估计这条 TOC 下的面积，得到的 \(t\) 值会高于 1.96。我们会在常规显著性水平下拒绝零假设，从而得出结论：这一优先级排序策略是有效的。

rate.autonomy$estimate / rate.autonomy$std.err
#> [1] 3.2

接下来，我们考虑用 policytree 包学习一个简单的策略，把协变量 X 映射为一个处理决策。我们在没有协变量缺失的观测上完成这一任务。首先，我们用 policytree 包中的函数 double_robust_scores，获取 \(\text{E}[Y_i(0)]\) 与 \(\text{E}[Y_i(1)]\) 的双稳健得分。

library(policytree)

Gamma.hat <- double_robust_scores(c.forest)
no.missing <- complete.cases(X)
X.nm <- X[no.missing, ]
Gamma.nm <- Gamma.hat[no.missing, ]

两种处理状态下平均金融素养得分的双稳健估计为：

colMeans(Gamma.nm)
#> control treated 
#>      58      62

在本应用中，很难想象会有学生"不从治疗中获益"，而"全员治疗"策略很可能提升人群整体的金融素养。但全员治疗成本高昂；因此很自然会问：是否存在某种策略，能在扣除成本后仍为整体人群带来净收益？这里，我们假设每次分配治疗时都要支付 ATE 的代价，并在目标函数中把它扣除：

Gamma.nm[, "treated"] <- Gamma.nm[, "treated"] - ate["estimate"]

然后，我们让 policy_tree 执行如下最大化：\[ \underset{\pi \in \text{depth-1 trees}}{\text{argmax}} \frac{1}{n}\sum_{i=1}^{n} \hat \Gamma[\pi(X_i)], \] 其中 \(\pi(X_i) \in \{1, 2\}\) 对应 Gamma 矩阵中的控制组（control）与处理组（treated）两列。

ptree <- policy_tree(X.nm, Gamma.nm, depth = 1)
plot(ptree)

到这里，我们得到了一条简单的决策规则——"若金融自主度得分 ≤ 41，则分配金融教育培训项目"，这再次印证了之前的分析：处理前变量 financial.autonomy.index 可以作为治疗决策的一个良好候选特征（注意：在实践中，我们会留出一份测试集来估计该策略的价值）。

实例：贫困对注意力的影响

本节我们分析 Carvalho 等人（2016）最初研究过的实验数据。作者做了一项随机实验：让低收入个体在发薪日之前或之后完成一项认知测试。结局是某认知测试中的答对题数。原研究没有发现统计显著的平均效应。但后续分析表明，贫困可能会损害某些亚群的认知功能（Farbmacher 等人，2021）。grf 中提供了一份已处理的数据，包含约 2,500 名个体和 24 个处理前特征（年龄、收入、教育程度等）。教育程度按有序编码（4：大学毕业；3：部分大学；2：高中毕业；1：高中以下），因此可以直接用于随机森林的切分。

我们对处理状态做如下编码：若个体在发薪日之后被观测，则 \(W_i=1\)。按此编码，正的处理效应就对应认知表现改善（即损害减轻）。这种选择简化了理解：例如，当优先级排序成功锁定获益最大的个体时，TOC 曲线为正。用潜在结局（potential outcomes）记号，令 \(Y_i(1)\) 表示"无贫困"状态（发薪日后）下的答对题数，\(Y_i(0)\) 表示财务困顿（发薪日前）下的答对题数。平均处理效应为 \[ \text{E}[Y_i(1) - Y_i(0)], \] 它衡量的是个体不受财务约束时，认知表现的平均改善程度。而 CATE 则刻画了这一改善在不同个体间的异质性。

data("attentionrct")
Y <- attentionrct$outcome.correct.ans.per.second
W <- 1 - attentionrct$treatment
X <- attentionrct[-(1:4)]

鉴于样本量相对预测变量数来说只是中等规模，若在所有协变量上拟合 CATE 估计量并做训练/测试评估，检验效能（power）可能不足。为了降维，我们先估计条件均值 \(\text{E}[Y_i \mid X_i]\)，再用森林的变量重要性选出一部分协变量用于 CATE。在下面这个例子里，按重要性保留前 10 个变量就是一种简单的启发式做法。

train <- sample(nrow(X), nrow(X) * 0.6)
test <- -train

Y.forest <- regression_forest(X[train, ], Y[train], num.trees = 500)
varimp.Y <- variable_importance(Y.forest)
keep <- colnames(X)[order(varimp.Y, decreasing = TRUE)[1:10]]
X.cate <- X[, keep]
print(keep)
#>  [1] "age"                               "working"                          
#>  [3] "education"                         "current.income"                   
#>  [5] "pay.day.amount.fraction.of.income" "black"                            
#>  [7] "household.income"                  "white"                            
#>  [9] "disabled"                          "retired"

接下来，我们在训练样本上拟合一个 CATE 森林，并在留出的测试样本上评估异质性。由于数据来自随机实验，我们通过 W.hat 参数传入已知的随机化概率。

# Estimate CATE function.
Y.hat.train <- predict(Y.forest)$predictions
cate.forest <- causal_forest(
  X.cate[train, ],
  Y[train],
  W[train],
  Y.hat = Y.hat.train,
  W.hat = 0.5
)
tau.hat.eval <- predict(cate.forest, X.cate[test, ])$predictions

# Fit evaluation forest.
eval.forest <- causal_forest(
  X[test, ],
  Y[test],
  W[test],
  W.hat = 0.5
)

接下来，我们通过估计 TOC 及其下面积，来评估估计出的 CATE 是否捕捉到了认知损害上的异质性。

rate.cate <- rank_average_treatment_effect(
  eval.forest,
  tau.hat.eval,
  q = seq(0.05, 1, length.out = 100)
)
print(rate.cate)
#>  estimate std.err             target
#>    0.0061  0.0092 priorities | AUTOC

#> [1] 0.67

plot(rate.cate, main = "TOC: By decreasing CATEs")

AUTOC 在常规显著性水平下与零没有统计上的显著差异。不过，对 TOC 曲线的直观观察提示：可能有很小一部分个体确实受到了影响。如果愿意预先指定一个分位数，就可以通过查看 TOC 曲线上该点的置信区间来正式检验这一点。
