异质性的交叉验证（RATE-CV）

原文：Cross-fold validation of heterogeneity（英文） · grf 官方文档中文译本

本篇教程简要介绍如何借助「秩加权平均处理效应」（Rank-Weighted Average Treatment Effects，简称 RATE）来评估条件平均处理效应（CATE）估计量的质量，并且避免使用「单一训练集 + 单一验证集」这种一次性的切分方式。我们将以因果森林（causal forest）为例，针对「二值处理（treatment）分配」的观察性数据或实验数据，演示如何利用 RATE 来检验处理效应的异质性（heterogeneity），并介绍两种思路：一种是「顺序折叠估计（sequential fold estimation）」流程，另一种是基于袋外（out-of-bag）估计、用于单侧检验的启发式方法。

背景与解释

为什么异质性检验需要「交叉验证」？ RATE 检验天然分两步：先用一部分数据拟合出 CATE 函数 \(\hat \tau(\cdot)\)，再用另一部分独立数据评估它。关键在于这两步必须用不同的样本，否则就像「自己出题自己改卷」，会把噪声当信号。最朴素的办法是做一次性的训练/测试切分，但这在样本量不大（比如很多医学研究、罕见病或早期 RCT）时很浪费——你只用了一半数据去拟合模型。交叉折叠（cross-fold）的初衷，正是想「轮流让每一折都当一次测试集」，从而既多用数据、又保持训练与验证相互独立。

RATE 指标的交叉折叠估计

如 RATE 篇教程所述，RATE 指标本身就可以作为「是否存在处理效应异质性」的检验工具。一个常见的做法是：先用训练集拟合出条件平均处理效应（CATE）的估计，再在一个留出的测试集上用 RATE 去评估它。具体来说，我们在训练集上得到某个估计出的 CATE 函数 \(\hat \tau(\cdot)\)，然后在测试集上算出 RATE 的估计值，并据此构造如下假设检验：

\(H_0\)：RATE \(=0\)（即 \(\hat \tau(\cdot)\) 没有检出异质性）

\(H_A\)：RATE \(\neq 0\)。

RATE 指标满足中心极限定理，因此可以用一个简单的 t 检验来检验这个假设：

\[ t = \frac{\widehat{RATE}}{\sqrt{Var(\widehat{RATE})}}. \]

在 5% 的显著性水平（\(\alpha\)）下，如果 p 值 \(2\Phi(-|t|)\) 小于 5%，我们就拒绝 \(H_0\)。

这种做法的一个缺点是：我们只用到了数据的一个子集去训练 CATE 估计量。当样本量较小、而异质性又难以检出时，这会很不利。一个诱人的替代方案是使用交叉折叠（cross-fold）估计：把数据分成 \(K\) 折（fold），轮流用其中一部分训练 CATE 估计量、用另一部分估计 RATE。下图展示了 \(K=5\) 折的情形：在蓝色样本上拟合 CATE 估计量，在红色样本上评估 RATE。

这套策略会给出 5 个 RATE 估计和 5 个 t 值；我们希望，把它们聚合起来之后能提高检出异质性的能力（统计功效，power）。单独来看，每个 t 值都构成一个有效的检验。但问题在于：聚合时它们并不相互独立，因为各折之间存在样本重叠，从而引入了相关性。

我们可以通过一个简单的模拟实验来观察这一点。下面我们定义一个简单函数：把数据分成 5 折，在每一折上各算出一个 RATE 估计和 t 值，再把各折的检验统计量聚合起来算出 p 值。

# 在 K 个随机折上估计 RATE，得到 K 个 t 统计量，再据此返回一个 p 值
# （针对 H0，使用这些 t 值之和）
rate_cv_naive = function(X, Y, W, num.folds = 5) {
  fold.id = sample(rep(1:num.folds, length = nrow(X)))
  samples.by.fold = split(seq_along(fold.id), fold.id)

  t.statistics = c()

  # 构造用于估计 RATE 的 AIPW 得分
  nuisance.forest = causal_forest(X, Y, W)
  DR.scores = get_scores(nuisance.forest)

  for (k in 1:num.folds) {
    train = unlist(samples.by.fold[-k])
    test = samples.by.fold[[k]]

    cate.forest = causal_forest(X[train, ], Y[train], W[train])

    cate.hat.test = predict(cate.forest, X[test, ])$predictions

    rate.fold = rank_average_treatment_effect.fit(DR.scores[test], cate.hat.test)
    t.statistics = c(t.statistics, rate.fold$estimate / rate.fold$std.err)
  }

  p.value.naive = 2 * pnorm(-abs(sum(t.statistics) / sqrt(num.folds)))

  p.value.naive
}

接下来，我们模拟一批「没有任何处理异质性」的合成数据，并用 5% 的显著性水平，通过蒙特卡洛（Monte Carlo）方法估计这个朴素流程的拒绝概率：

res = t(replicate(500, {
  n = 1500
  p = 5
  X = matrix(rnorm(n * p), n, p)
  W = rbinom(n, 1, 0.5)
  Y = pmin(X[, 3], 0) + rnorm(n)

  pval.naive = rate_cv_naive(X, Y, W)

  c(
    reject = pval.naive <= 0.05
  )
}))
paste("Rejection rate:", mean(res) * 100, "%")
#> [1] "Rejection rate: 16.8 %"

在 5% 的显著性水平下，任何拒绝率高于 5% 的检验都是无效的检验。

背景与解释

过拟合风险：为什么朴素交叉折叠会让 p 值「膨胀」？ 上面模拟得到 16.8% 的拒绝率，远高于名义上的 5%——这说明检验「太容易拒绝 H0」，假阳性偏高。根源在于：各折之间是重叠的（每个样本除了当测试集的那一折外，还出现在其余所有折的训练集里），因此各折算出的 t 值彼此相关。当你直接把 K 个相关的 t 值当作独立量加起来求 p 值时，聚合后的标准误被低估了，于是检验统计量被人为放大。这其实是「同一批数据既拟合又评估」导致的过拟合，在交叉验证里以「折叠相关性」的形式残留了下来。所以，不是所有交叉折叠都自动保证独立性。

顺序交叉折叠估计

不过，确实存在一个简单的算法修正，可以弥补朴素交叉折叠验证的上述缺陷。我们称之为顺序交叉折叠估计（sequential cross-fold estimation）的方法，它只按先后顺序使用训练折，从而打断了各折之间 RATE 指标的相关性。如下图所示，这套策略会给出 \(K - 1\) 个相互独立的 \(t\) 值。

这种构造会让我们的 \(t\) 值满足鞅（martingale）性质，从而可以进行合法的聚合（参见 Luedtke & van der Laan (2016) 以及 Wager (2024)）。具体步骤如下：

  1. 把数据随机分成 \(k=1,\ldots,K\) 个大小相等的折。

  2. 对于每一折 \(k=2,\ldots,K\)：

    用第 \(1,\ldots,k-1\) 折的（蓝色）\(\color{blue}{\text{training}}\) 数据，得到估计的 CATE 函数。

    用第 \(k\) 折的（红色）\(\color{red}{\text{test}}\) 数据构造 RATE 估计，并算出一个 \(t\) 统计量。

  3. 把 \(K-1\) 个不同的 \(t\) 统计量聚合起来，作为最终的检验统计量。

下面这个简单函数实现了上述流程。

# 在 K-1 个随机顺序折上估计 RATE，得到 K-1 个 t 统计量，再据此返回一个 p 值
# （针对 H0，使用这些 t 值之和）
rate_sequential = function(X, Y, W, num.folds = 5) {
  fold.id = sample(rep(1:num.folds, length = nrow(X)))
  samples.by.fold = split(seq_along(fold.id), fold.id)

  t.statistics = c()

  # 构造用于估计 RATE 的 AIPW 得分
  nuisance.forest = causal_forest(X, Y, W)
  DR.scores = get_scores(nuisance.forest)

  for (k in 2:num.folds) {
    train = unlist(samples.by.fold[1:(k - 1)])
    test = samples.by.fold[[k]]

    cate.forest = causal_forest(X[train, ], Y[train], W[train])

    cate.hat.test = predict(cate.forest, X[test, ])$predictions

    rate.fold = rank_average_treatment_effect.fit(DR.scores[test], cate.hat.test)
    t.statistics = c(t.statistics, rate.fold$estimate / rate.fold$std.err)
  }

  p.value = 2 * pnorm(-abs(sum(t.statistics) / sqrt(num.folds - 1)))

  p.value
}

如果我们把同样的检查放到「无异质性」的数据上重复，可以看到这种构造能给出正确的拒绝率（在蒙特卡洛重复次数的误差容忍范围内）：

res = t(replicate(500, {
  n = 1500
  p = 5
  X = matrix(rnorm(n * p), n, p)
  W = rbinom(n, 1, 0.5)
  Y = pmin(X[, 3], 0) + rnorm(n)

  pval.sequential = rate_sequential(X, Y, W)

  c(
    reject.sequential = pval.sequential <= 0.05
  )
}))
paste("Rejection rate:", mean(res) * 100, "%")
#> [1] "Rejection rate: 5.4 %"

既然现在有了一个能用到多折、且对处理异质性有效的检验，我们就拿一个模拟例子来试试，看看它在检出处理效应异质性时表现如何。我们对比的基线（baseline）是样本切分（sample splitting）——在 RATE 那篇论文里它已被证明是有效的，但由于只用了一部分数据做验证，其功效（power）可能较低。

下面我们基于一组合成观察性数据（Nie & Wager (2021) 中的 Setup A）来生成数据，这种情形下处理效应的异质性很难检出。请记住，在这种情况下，我们希望检验能够拒绝「无异质性」的 \(H_0\)。

res = t(replicate(500, {
  # 模拟"弱"处理异质性的合成数据
  n = 2500
  p = 5
  data = generate_causal_data(n, p, sigma.tau = 0.15, sigma.noise = 1, dgp = "nw1")
  X = data$X
  Y = data$Y
  W = data$W

  pval.sequential = rate_sequential(X, Y, W)

  # 与单次训练/测试切分做对比
  train = sample(n, n / 2)
  test = -train
  cf.train = causal_forest(X[train,], Y[train], W[train])
  cf.test = causal_forest(X[test,], Y[test], W[test])
  rate = rank_average_treatment_effect(cf.test, predict(cf.train, X[test, ])$predictions)
  tstat.split = rate$estimate / rate$std.err
  pval.split = 2 * pnorm(-abs(tstat.split))

  c(
    reject.sequential = pval.sequential <= 0.05,
    reject.split = pval.split <= 0.05
  )
}))
colMeans(res) * 100
#> reject.sequential    reject.split
#> 56.6                 47.0

令人放心的是，在这个例子中，交叉折叠估计相比基线方法，确实提升了检出处理异质性的功效（power）。

背景与解释

顺序估计如何「破解」折叠相关性？ 朴素方法失败是因为各折相关；顺序法的巧妙之处在于：第 k 步只用前面第 1…k-1 折训练、用第 k 折验证，所以每一步的测试集都与之前所有训练数据相互独立。这样得到的 \(K-1\) 个 t 统计量满足鞅（martingale）性质——每一步的新信息都和过去「正交」，因此可以像独立量一样合法地求和、再求 p 值。代价只是丢掉第一折（只能得到 \(K-1\) 个统计量而非 \(K\) 个），但换来了「拒绝率回到约 5%（有效）」且「功效高于单次切分」的双赢。读结果时关注两点：其一，模拟里拒绝率从单次切分的 47.0% 提升到 56.6%，说明更灵敏；其二，5.4% 的零拒绝率证明它没有假阳性膨胀。

启发式方法：基于单侧检验的袋外（OOB）估计

用同一批数据既去估计 CATE、又去评估异质性是否存在，其核心困难在于过拟合：说到底，我们受制于一个事实——不能简单地用同一份数据既做估计又做评估。我们已经看到，朴素交叉折叠估计由于折之间存在相关性（这会把估计值向下偏倚），并没有真正解决这个难题。要「挽救」这种朴素聚合，一个启发式办法是使用单侧 p 值。只要我们愿意事先确定一个单侧检验的方向——比如检验 RATE \(>0\)——它就能成为一个有用的策略。

不过，随机森林提供了一种比简单交叉折叠更省算力的替代方案。森林原生的「留一」估计就是袋外（out-of-bag，OOB）估计。对于第 \(i\) 个个体，OOB 估计只使用那些「没有包含第 \(i\) 个个体」的子样本所生长出来的树来构造。当我们要用全部数据同时拟合并评估异质性时，把 OOB 估计的 RATE 与单侧检验搭配起来，就是一个很有用的启发式方法。

在下面的例子中，我们比较两种做法（均在 5% 水平下）：双侧检验（RATE \(\neq 0\)）与单侧检验（RATE \(>0\)）。

res = t(replicate(500, {
  n = 1500
  p = 5
  X = matrix(rnorm(n * p), n, p)
  W = rbinom(n, 1, 0.5)
  Y = pmin(X[, 3], 0) + rnorm(n)

  c.forest = causal_forest(X, Y, W)
  tau.hat.oob = predict(c.forest)$predictions
  rate.oob = rank_average_treatment_effect(c.forest, tau.hat.oob)

  t.stat.oob = rate.oob$estimate / rate.oob$std.err
  # 计算双侧 p 值 Pr(>|t|)
  p.val = 2 * pnorm(-abs(t.stat.oob))
  # 计算单侧 p 值 Pr(>t)
  p.val.onesided = pnorm(t.stat.oob, lower.tail = FALSE)

  c(
    reject.oob = p.val <= 0.05,
    reject.oob.onesided = p.val.onesided <= 0.05
  )
}))
colMeans(res) * 100
#> reject.oob reject.oob.onesided
#> 30.4                 4.0

可以看到，单侧检验对「无效应」这一零假设的拒绝率是正确的（约 5%）。

如果我们重复上面那个简单的功效（power）实验，会发现它达到的功效基本和顺序聚合相当。

res = t(replicate(500, {
  # 模拟"弱"处理异质性的合成数据
  n = 2500
  p = 5
  data = generate_causal_data(n, p, sigma.tau = 0.15, sigma.noise = 1, dgp = "nw1")
  X = data$X
  Y = data$Y
  W = data$W

  c.forest = causal_forest(X, Y, W)
  tau.hat.oob = predict(c.forest)$predictions
  rate.oob = rank_average_treatment_effect(c.forest, tau.hat.oob)
  t.stat.oob = rate.oob$estimate / rate.oob$std.err
  # 计算单侧 p 值 Pr(>t)

  )

mean(res) * 100
#> [1] 54.0
背景与解释

如何读懂 RATE-CV 的结果（给医学研究者的实操清单）：① 先看方向：双侧检验 RATE ≠ 0 只在「有正有负」的异质性下灵敏；若你预期处理对部分亚组有效（RATE > 0），用单侧检验更省力，但方向必须在看数据之前就定好，不能先看到结果再改成单侧，否则 p 值会失真（上面双侧 30.4% 的拒绝率明显是假阳性膨胀，正是因为同一批数据既拟合又评估）。② 对比功效：顺序法约 56.6%、OOB 单侧约 54.0%，都高于单次切分的 47.0%，说明在样本有限时更值得用。③ OOB 是省算力的启发式：它免去了反复重拟合森林，代价是依赖「袋外预测近似独立」的假设，报告时应注明方法名与折数。④ 报告时务必同时给出 p 值、所用检验（单/双侧）与拒绝率来源，方便读者复现。

附录：p 值的中位数聚合

还有一种思路可以「挽救」 rate_cv_naive：保留传统的 \(K\) 折结构，但改变各折 t 统计量的聚合方式。这正是 Chernozhukov 等人（2024）采取的做法。与其基于「聚合后的 t 统计量」去算一个 p 值，不如先为每一个 t 统计量分别算出一个 p 值，再取这些 p 值的中位数——这样就能得到一个有效的检验。

# 本函数与 rate_naive 基本一致，只是返回
# 中位数 p 值。
rate_cv_median = function(X, Y, W, num.folds = 5) {
  fold.id = sample(rep(1:num.folds, length = nrow(X)))
  samples.by.fold = split(seq_along(fold.id), fold.id)

  t.statistics = c()

  nuisance.forest = causal_forest(X, Y, W)
  DR.scores = get_scores(nuisance.forest)

  for (k in 1:num.folds) {
    train = unlist(samples.by.fold[-k])
    test = samples.by.fold[[k]]

    cate.forest = causal_forest(X[train, ], Y[train], W[train])

    cate.hat.test = predict(cate.forest, X[test, ])$predictions

    rate.fold = rank_average_treatment_effect.fit(DR.scores[test], cate.hat.test)
    t.statistics = c(t.statistics, rate.fold$estimate / rate.fold$std.err)
  }

  p.value.median = median(2 * pnorm(-abs(t.statistics)))

  p.value.median
}

在 5% 的显著性水平下，这种构造能给出有效的拒绝率，但相当保守：

res = t(replicate(500, {
  n = 1500
  p = 5
  X = matrix(rnorm(n * p), n, p)
  W = rbinom(n, 1, 0.5)
  Y = pmin(X[, 3], 0) + rnorm(n)

  rate.cv.median = rate_cv_median(X, Y, W)

  c(
    reject.median = rate.cv.median <= 0.05
  )
}))
paste("Rejection rate:", mean(res) * 100, "%")
#> [1] "Rejection rate: 0.2 %"

如果我们重复上面的功效（power）模拟，遗憾的是，这个算法的功效并没有超过简单的样本切分法。这个方法的一个缺陷是：当所有 t 统计量都是正数、但各自都不显著时，rate_sequential 能把这些信号综合起来考虑，而 rate_cv_median 却做不到。

res = t(replicate(500, {
  # 模拟"弱"处理异质性的合成数据
  n = 2500
  p = 5
  data = generate_causal_data(n, p, sigma.tau = 0.15, sigma.noise = 1, dgp = "nw1")
  X = data$X
  Y = data$Y
  W = data$W

  pval.median = rate_cv_median(X, Y, W)

  # 与样本切分做对比
  train = sample(n, n / 2)
  test = -train
  cf.train = causal_forest(X[train,], Y[train], W[train])
  cf.test = causal_forest(X[test,], Y[test], W[test])
  rate = rank_average_treatment_effect(cf.test, predict(cf.train, X[test, ])$predictions)
  tstat.split = rate$estimate / rate$std.err
  pval.split = 2 * pnorm(-abs(tstat.split))

  c(
    reject.median = pval.median <= 0.05,
    reject.split = pval.split <= 0.05
  )
}))
colMeans(res) * 100
#> reject.median  reject.split
#> 14.6          47.8
