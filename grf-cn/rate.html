《用 RATE 评估异质性》

原文：Assessing heterogeneity with RATE（英文） · grf 官方文档中文译本

本篇教程简要介绍 grf 包中 rank_average_treatment_effect 函数所提供的排序加权平均处理效应（RATE，Rank-Weighted Average Treatment Effect）的用法：它可以评估"处理优先规则"（treatment prioritization rules，例如条件平均处理效应的估计值）的优劣——也就是说，看这些规则能否把处理效应不同的亚群体区分开来，以及数据中到底有没有值得关注的异质性（heterogeneity）。教程的后半部分给出医学场景下的一个完整示例，使用的是 SPRINT 与 ACCORD 两项高血压药物试验的（合成）数据。若想了解更完整的细节，以及如何用 RATE 评估增益模型（uplift model），请参阅 RATE 论文。

library(grf)
library(ggplot2)

处理优先规则

我们考虑一个大家都很熟悉的情形：在随机化试验（或满足无混杂假设的观察性研究）中，想要决定应该把二值处理（binary treatment）\(W=\{0, 1\}\) 分配给哪些个体，以及这种分配策略究竟有多大价值。给定某些个体特征 \(X_i\)，我们有一个针对个体的处理优先规则 \(S(X_i)\)，它会为每个个体打一个分数。这个优先规则应当给"我们认为处理获益很大"的个体打高分，给"处理获益很小"的个体打低分。这里说的"处理获益"，是指给定个体特征 \(X_i\) 后，接受处理带来的结局（outcome）\(Y\) 上的差异，也就是条件平均处理效应（CATE，conditional average treatment effect）

\[\tau(x) = E[Y_i(1) - Y_i(0) \,|\, X_i = x],\] 其中 \(Y(1)\) 和 \(Y(0)\) 分别是两种处理状态下对应的潜在结局（potential outcome）。

你可能会问：既然我们已经用 \(\tau(X_i)\) 来衡量获益，为什么还要绕一个弯子，去关注一个任意的规则 \(S(X_i)\)？直接用估计出来的 CATE 来做处理定向（treatment targeting）难道不是最好的吗？答案是：这种一般化的问题设定其实非常方便。因为在某些情境下，我们的数据不足以支撑一个准确的 CATE 估计器，只能依赖别的办法来做处理定向。其他办法的例子包括领域专家总结出的经验法则（heuristics），或者更简单的"风险评分"模型（其中风险定义为 \(P[Y = 1 | X_i = x]\)，且 \(Y \in \{0, 1\}\)，\(Y=1\) 表示不良结局），这类做法在临床应用中相当常见。因此，在有限样本下，有时依赖那些与 CATE 相关的、更简单的规则，反而比依赖带有噪声、结构又复杂的 CATE 估计效果更好——请记住：估计 CATE 本身是件很难的统计任务；而把问题聚焦在一个"一般规则"上，我们就可以绕开"获得精确非参数点估计"这个难题，转而只要求估计结果能按处理获益对个体进行排序。此外，即便你已经有了一个准确的 CATE 估计器，可供选择的估计器也可能有很多（神经网络 / 随机森林 / 各种 metalearner 等等）。于是问题就变成：给定一组处理优先规则 \(S(X_i)\)，我们究竟该用哪一个（如果有的话）？

我们建议在这种情况下使用的工具是 RATE 指标。它以一个优先规则 \(S(X_i)\) 作为输入——这个规则可以基于估计的 CATE、风险评分等等——并输出一个标量指标，用来评估它做处理定向的效果（它衡量的是一条优先规则的价值，至于这条规则具体是怎么得来的，它并不关心）。一个 RATE 指标由两部分构成："TOC"以及 TOC 下方的面积，我们在下一节解释。

背景与解释

RATE 想解决的根本问题是什么？在医学研究中，我们常问"这个药平均有效吗"。但平均有效，不代表对每个人都一样有效——有些人用了获益巨大，有些人几乎没差别，甚至还有人可能受损。异质性处理效应（HTE，heterogeneous treatment effect）指的就是这种"处理效应因人而异"的现象。传统做法报告一个全人群平均处理效应（ATE，average treatment effect），会把不同 subgroup 之间的差异"抹平"，从而掩盖了"哪些人特别该用药"的关键信息。

RATE 的聪明之处在于：它不要求你精确估计每个人的效应，而只要求你能把"获益大的人"排到前面、"获益小的人"排到后面。只要排序对了，就能判断优先规则是否有用、异质性是否真实存在。正因为只问排序、不问精确数值，RATE 对 CATE 估计中的噪声更鲁棒，在医学小样本场景下尤为实用。

量化处理获益：靶向作用特征曲线（Targeting Operator Characteristic）

如上一节所述，我们关心的是"是否存在异质性"，以及"利用这种异质性、按优先规则 \(S(X_i)\) 来做处理定向能带来多大获益"。这里说的"获益"，是指：与其随机挑选同等比例的人群去处理，不如把处理集中给优先分数 \(S(X_i)\) 最高的那部分人，从而期望带来的结局提升。

为了构造一个合适的指标来评估这件事，先来点直观的可视化会很有帮助。一个合理的做法是：按 \(S(X_i)\) 把人群切成若干组，然后把这些组里的 ATE 与"给所有人处理"的总体 ATE 作比较，再把结果画出来。这正是靶向作用特征曲线（TOC，Targeting Operator Characteristic）所做的事——其中每一组，就是优先分数 \(S(X_i)\) 排名前 q 比例的那部分个体。

设 \(F\) 为 \(S(X_i)\) 的分布函数，\(q \in (0, 1]\) 为被处理样本的比例，则 q 处的 TOC 定义为

\[\begin{equation*} \begin{split} &\textrm{TOC}(q) = E[Y_i(1) - Y_i(0) \,|\, S(X_i) \geq F^{-1}_{S(X_i)}(1 - q)]\\ & \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ - E[Y_i(1) - Y_i(0)], \end{split} \end{equation*}\]

其中 \(F_{S(X_i)}\) 是 \(S(X_i)\) 的分布函数。TOC 曲线的灵感来自受试者工作特征曲线（ROC，Receiver Operating Characteristic）——后者是评估分类规则表现时广为使用的指标。

作为玩具示例，假设我们令 \(\tau(X_i) = X_1\)，其中 \(X_1 \sim N(0, 1)\)。那么用 \(S(X_i) = \tau(X_i)\) 作为优先规则时，TOC 曲线长这样：

注意看：在接受处理的最初几个个体上，TOC 的值非常高。这很直观，因为我们的玩具 CATE 服从均值为 0 的正态分布；如果我们只挑出处理效应大于 \(z_{0.95}\) 的前 5% 个体来治疗，那么相比"给所有人治疗"（效应为 0），获益是很大的。但随着曲线向右延伸，越来越多处理效应较低的人混进来，我们逐渐逼近 ATE，直到 \(q=1\) 时与之相等。

RATE：TOC 下方的面积

上图自然地提示了一个总结 TOC 曲线的方式——既然 \(S(X_i)\) 的作用是按处理获益对个体排序，那么只要把曲线下方的面积加起来即可。这正是 RATE 的定义：它是 TOC 下方的面积（Area Under the TOC，简称 "AUTOC"）。

\[\textrm{RATE} = \int_0^1 \textrm{TOC}(q) dq .\] 如果 \(\tau(X_i)\) 几乎不存在异质性，那么这个面积会小到可以忽略；在 \(\tau(X_i)\) 为常数的特殊情况下，面积就是 0。再往前想一步：如果我们的估计规则 \(S(X_i)\) 能很好地识别出获益截然不同的个体，我们会预期这个指标为正；反过来，如果它表现很差，或者根本没什么可分层处理的获益，我们会分别预期它为负或接近零。

这个面积可以用不同的方式来求和，从而得到不同的 RATE 指标。我们把上面的积分称为 "AUTOC"。它对"期望处理获益最大"的那段曲线下方区域赋予更大的权重。当非零处理效应集中在一小部分人群身上时，这种加权方式在检验"尖锐零假设"（AUTOC = 0）时很有力。

求和面积的另一种方式，是用 \(q\) 给曲线上每一点加权：\(\int_0^1 q \textrm{TOC}(q) dq\)。我们把这个指标称为 "QINI"（Radcliffe, 2007）。这种加权意味着：对处理效应低的个体与处理效应高的个体赋予同样的权重。当非零处理效应在整个群体中分布得更弥散时，这种加权在检验"零效应"时往往更有检验功效。

另外值得一提：Athey 和 Wager (2019) 中使用的"高低袋外 CATE 分位数"构造，也可以看作一种 RATE——它用 Qini 的恒等加权替代为在给定分位数 q 处的点质量（point mass）。

背景与解释

怎么读 RATE？AUTOC 与 BLIP。本文主打的是 AUTOC（Area Under the TOC，TOC 下面积）——它对"受益最大的那一小撮人"所在曲线段给的权重更大，因此非常适合检验"有没有人特别受益"这种集中型异质性。与它配套的还有一种叫 BLIP（Best Linear Projection，最优线性投影）的思路：它不直接看排序，而是把估计出的 CATE 投影到一条最优线性方向上，再用经典的 Wald 检验来判断"沿这个方向的异质性是否显著不为零"。

两者的分工可以这样理解：AUTOC 问的是"按你的规则优先治疗，是否真的比随机好"（侧重实用价值）；BLIP 问的是"处理效应到底有没有系统性地随协变量变化"（侧重统计显著性）。在 RATE 论文里，二者通常一起报告：AUTOC 显著为正说明定向治疗有价值，BLIP 显著说明异质性在统计上站得住脚。如果 AUTOC 接近 0 甚至为负，往往意味着你的优先规则并没有抓到真正的异质性。

估计 RATE

上一节的概览是在一个理想化的设定下介绍的——我们假设自己已经知道了 \(\tau(X_i)\)。实际操作中这些量必须被估计出来，而相应的可行定义（以 \(S(X_i) = \hat \tau(X_i)\) 为例）是：TOC 曲线在测试集 \(X^{test}\) 上，按照在训练集上估计出的 CATE 函数 \(\hat \tau^{train}(\cdot)\) 对所有观测排序，再把由 \(\hat \tau^{train}(X^{test})\) 优先出的前 q 比例个体，其 ATE 与总体 ATE 进行比较：

\[\begin{equation*} \begin{split} &\textrm{TOC}(q) = E[Y^{test}_i(1) - Y^{test}_i(0) \,|\, \hat \tau^{train}(X^{test}_i) \geq \hat F^{-1}(1 - q)]\\ & \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ - E[Y^{test}_i(1) - Y^{test}_i(0)], \end{split} \end{equation*}\]

其中 \(\hat F\) 是 \(\hat \tau^{train}(X^{test})\) 的经验分布函数。rank_average_treatment_effect 函数借助一个在独立评估集上训练的森林，给出 TOC 与 RATE 的 AIPW 风格1双稳健（doubly robust）估计量。关于该双稳健估计量及其相应中心极限定理的推导细节，参见 Yadlowsky 等人 (2025)。

SPRINT 与 ACCORD 的一个应用

为了说明 RATE，我们考虑一个来自医学场景的示例应用。两项大规模随机试验 ACCORD（ACCORD Study Group, 2010）和 SPRINT（SPRINT Research Group, 2015）在相似的人群上开展，都旨在衡量一种高血压治疗的疗效，却得出了不同的结论：SPRINT 发现治疗有效，而 ACCORD 发现治疗无效。对此已有多种解释被提出，这里我们特别关注其中一种：即差异源于处理效应的异质性这一假设（参见 Yadlowsky 等人, 2025 的参考文献）。

这个假设在上节的基础上有一个可被检验的推论：如果确实存在显著的异质性，并且我们能用有力的 CATE 估计器有效地估计出它们，那么在 ACCORD 和 SPRINT 上估计出的 RATE 应当为正且显著。具体来说，我们的设定给出了如下"菜谱"：

  1. 在 ACCORD 与 SPRINT 数据上分别估计 CATE 函数 \(\hat \tau^{ACCORD}(\cdot)\) 和 \(\hat \tau^{SPRINT}(\cdot)\)。

  2. 用 \(\hat \tau^{ACCORD}(X^{SPRINT})\) 在 SPRINT 上评估 RATE，反之亦然：用 \(\hat \tau^{SPRINT}(X^{ACCORD})\) 在 ACCORD 上评估 RATE。

  3. 如果两个人群表现出相似的 HTE，那么有力的 CATE 估计器应当给出一个为正且显著的 RATE 估计。

就本教程示例而言，我们并不分析原始的 SPRINT/ACCORD 数据，而是使用一份较小的模拟示例，存放于 GRF 代码仓库。关于模拟器的细节，请参阅 论文配套仓库。

这项试验的结局数据是右删失（right-censored）的，因此我们不能用任何普通的"开箱即用"的 CATE 估计器来估计处理效应，而需要使用一个能考虑删失的估计器。为此我们使用 GRF 的 causal_survival_forest（详见 文档）。下图展示了这份模拟试验数据。

# 读取半合成数据，来源 https://github.com/grf-labs/grf/tree/master/r-package/grf/vignettes
load("data/synthetic_SPRINT_ACCORD.RData")
df <- data.frame(Y = c(Y.sprint, Y.accord),
                 D = c(D.sprint, D.accord),
                 data = c(rep("synthetic-SPRINT", length(Y.sprint)),
                          rep("synthetic-ACCORD", length(Y.accord))))
df$Censored <- factor(df$D, labels = c("Yes", "No"))

ggplot(df, aes(x = Y, fill = Censored)) +
  facet_wrap(data ~ .) +
  geom_histogram(alpha = 0.5, bins = 30) +
  xlab("Time until primary outcome (days)") +
  ylab("Frequency") +
  theme_classic()

SPRINT 试验因事件发生数过少而提前终止，因此删失率非常高。我们在本例中考虑的目标估计量（estimand）是条件于协变量的限制平均生存时间（RMST，restricted mean survival time）之差：

\[\tau(x) = E[T(1) \land h - T(0) \land h \, | X = x],\] 其中 \(T\) 是（删失的）生存时间，我们把 \(h\)（GRF 包中的 horizon）设为约 3 年，超过这个时点后 SPRINT 试验数据几乎不再出现事件。由于处理是随机化的，我们把倾向得分 W.hat\(=E[W_i \, | X_i = x]\) 设为接受治疗个体的平均比例。

horizon <- 3 * 365
csf.sprint <- causal_survival_forest(X.sprint, Y.sprint, W.sprint, D.sprint,
                                     W.hat = mean(W.sprint), target = "RMST", horizon = horizon)

csf.accord <- causal_survival_forest(X.accord, Y.accord, W.accord, D.accord,
                                     W.hat = mean(W.accord), target = "RMST", horizon = horizon)

tau.hat.sprint <- predict(csf.accord, X.sprint)$predictions
tau.hat.accord <- predict(csf.sprint, X.accord)$predictions

在 SPRINT 与 ACCORD 上评估 RATE，分别使用来自 ACCORD 和 SPRINT 的估计 CATE 函数，得到

rate.sprint <- rank_average_treatment_effect(csf.sprint, tau.hat.sprint, target = "AUTOC")
rate.accord <- rank_average_treatment_effect(csf.accord, tau.hat.accord, target = "AUTOC")

rate.sprint
#>  estimate  std.err             target
#>  4.762887 6.228628 priorities | AUTOC
rate.accord

#>  2.244216 11.98976 priorities | AUTOC
par(mfrow = c(1, 2))
plot(rate.sprint, xlab = "Treated fraction", main = "TOC evaluated on SPRINT\n tau(X) estimated from ACCORD")
plot(rate.accord, xlab = "Treated fraction", main = "TOC evaluated on ACCORD\n tau(X) estimated from SPRINT")

在这个半合成例子中，两个 AUTOC 在常规显著性水平下都不显著，说明这两项试验中没有证据表明存在显著的 HTE。注意：这也可能归因于 a) 检验功效不足——也许样本量不够大，检测不出 HTE；b) HTE 估计器本身未能把它们检测出来；或者 c) 沿着可观测的预测变量，处理效应的异质性可以忽略不计。关于在 SPRINT 与 ACCORD 数据集上比较不同优先策略的更广泛分析，参见 Yadlowsky 等人 (2025)。

背景与解释

怎样判断"异质性"是不是真的存在？看到 RATE 不显著（如本例），先别急着下"没有异质性"的结论。RATE（以及 AUTOC/BLIP）给出的是带有标准误的估计，判读时要看三件事：

① 估计值的正负与大小：为正说明按规则优先治疗比随机好；为负或接近 0 则说明规则没抓到真实差异。
② 标准误与置信区间：std.err 很大、置信区间跨过 0，意味着"检测不出差异"，可能是真没有，也可能是样本太小。
③ 别把"不显著"等同于"不存在"。本文明确列出三种可能：a) 检验功效不足（样本量小）；b) 估计器本身偏弱、没把异质性挖出来；c) 可观测变量上的异质性确实可忽略。换句话说，RATE 告诉你的是"用现有的规则和样本，能不能证明异质性"——它是一道"证据"题，不是"真相"题。

背景与解释

RATE 与医学"亚型发现"（subtype discovery）有什么关系？精准医学的核心诉求，就是找到"对某种治疗特别有效 / 特别无效"的患者亚型，从而实现个体化治疗。SPRINT 与 ACCORD 的"一有效一无效"矛盾，正是真实世界 heterogeneity 的典型写照：也许药对某一亚型有效、对另一亚型无效，把所有人混在一起算 ATE 就把信号抵消了。

RATE 的价值正在于此：它不先验地规定"按哪个变量分层"，而是用数据驱动的 CATE 估计（因果森林）去学习优先规则，再用 RATE 客观地检验"这条规则是否真的能区分出获益不同的人群"。这比传统"先拍脑袋定一个亚组、再去看交互项 p 值"的做法更稳健，也更能避免"亚组分析多重比较导致假阳性"。从这个角度看，RATE 是连接"异质性存在性检验"与"可落地临床分型"之间的一座桥。
