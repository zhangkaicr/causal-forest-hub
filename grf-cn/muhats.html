《估计条件均值（回归森林）》

原文：Estimating conditional means（英文） · grf 官方文档中文译本

library(grf)

条件均值与平均处理效应估计

grf 基于一种双稳健（doubly robust）校正来计算平均处理效应（average treatment effect），由此得到"增广逆概率加权平均处理效应"（augmented inverse-propensity weighted average treatment effect，简称 AIPW）。对于一个处理为二分类（binary treatment）的因果森林（causal forest），其精确的表达式如下（Athey 与 Wager，2019 年第 (8) 式）：

\(\hat \Gamma_i = \hat \tau^{(-i)}(X_i) + \frac{W_i - \hat e^{(-i)}(X_i)}{\hat e^{(-i)}(X_i)[1 - \hat e^{(-i)}(X_i)]} [Y_i - \hat \mu^{(-i)}(X_i, W_i)]\)

其中：

  1. \(\hat \tau^{(-i)}(X_i)\) 是处理效应的估计值（由 grf 的 predict 方法返回）。用潜在结果（potential outcomes）记号来写，它按定义就是 \(E[Y_i(1) - Y_i(0) | X_i] = \mu(X_i, 0) - \mu(X_i, 1)\)。

  2. \(W_i\) 是个体 \(i\) 的二分类处理指示变量（0/1）。

  3. \(\hat e^{(-i)}(X_i)\) 是个体 \(i\) 的倾向得分（propensity score），即接受处理的概率；默认情况下，它由一个拟合处理分配变量的回归森林（regression forest）来估计。

  4. \(Y_i\) 是个体 \(i\) 实际观测到的结局（realized outcome）。

  5. \(\hat \mu^{(-i)}(X_i, W_i) = \hat m^{(-i)}(X_i) + [W_i - \hat e^{(-i)}(X_i)] \hat \tau^{(-i)}(X_i)\) 是个体 \(i\) 实际条件均值（realized conditional mean）的估计，其中 \(m(X_i) = E[Y | X_i]\)（默认情况下，它用一个回归森林来估计，并在处理变量上做了边缘化（marginalizing）处理）。

背景与解释

什么是"条件均值"？ 在因果推断里，我们常关心"给定一组协变量（covariate）X 时，结局 Y 的平均取值"。这就是条件均值 m(X) = E[Y | X]。它和"预测"很像——给定病人的年龄、病情、合并症（X），预测他的血压（Y）。关键在于：条件均值不区分处理与否，它把整个人群（不管吃没吃药）混在一起估计；而后面要讲的 μ(X, 0)、μ(X, 1) 则是分别针对"不吃药"和"吃药"两种情况的条件均值。医学研究中，前者常用于风险分层/预后建模，后者才是计算处理效应所需的反事实（counterfactual）量。

上标 \(-i\) 表示交叉拟合（cross-fitting），也就是说，该估计是在把第 \(i\) 条观测"留出"（leave out）的情况下计算出来的。对于袋外（out-of-bag，OOB）森林估计而言，这一点是天然成立的。

要理解最后一个式子是怎么来的，注意到我们有：

  1. \(m(X_i)\)

    \(= E[Y | X_i]\)

    \(= E[Y_i(0) | X_i] + E[W_i [Y_i(1) - Y_i(0)] | X_i]\)

    \(= \mu(X_i, 0) + e(X_i) \tau(X_i)\)

其中最后一行成立，依据的是无混杂性（unconfoundedness）假设——在给定协变量集合 \(X_i\) 的条件下，潜在结果与处理分配相互独立。

背景与解释

为什么需要"无混杂"假设？ 第 6 步把总体条件均值 m(X) 拆成了"未处理时的均值 μ(X, 0)"＋"因为处理带来的增量 e(X)·τ(X)"。这个拆分的合法性，依赖于一个核心假设：在调整了 X 之后，是否接受处理就完全是"随机的"（即潜在结果 Y(0)、Y(1) 与处理 W 独立）。在观测性医学研究中，这通常意味着 X 已经包含了所有同时影响"是否被治疗"和"结局"的混杂因素。如果该假设不成立（比如病情更重的病人更可能被用药，而 X 里没包含病情严重度），那么这里的 μ 和条件均值估计就会有偏——这也是为什么真实研究里要反复推敲"有没有遗漏的混杂变量"。

由此，我们便得到了如下反事实响应曲面（counterfactual response surfaces）的表达式：

  1. \(\mu(X_i, 0) = m(X_i) - e(X_i) \tau(X_i)\)

  2. \(\mu(X_i, 1) = \tau(X_i) + \mu(X_i, 0) = m(X_i) + [1 - e(X_i)] \tau(X_i)\)

背景与解释

这套公式和因果森林是什么关系？ 因果森林本身只直接给出处理效应 τ(X)（即 predict(c.forest) 的输出）。但很多时候我们还需要"若不吃药，这群病人的平均结局是多少""若吃药又是多少"——也就是 μ(X, 0) 和 μ(X, 1)。第 7、8 式告诉我们，它们可以由因果森林的 τ 加上两个回归森林（一个估 m(X)=E[Y|X]，一个估倾向得分 e(X)）拼出来，而不必单独再跑一个模型。这正是 grf 内置 ATE 函数的底层思路，也是下文代码手动复现的逻辑。把它拆开有助于理解：因果森林估计效应，回归森林估计"基线水平"，二者配合才得到完整的条件均值/反事实结局。

上述这些量都由 grf 内置的 ATE 函数自动计算。下面这段代码演示了如何手动取得条件均值 \(E[Y | X_i, W_i]\) 的估计：

n <- 250
p <- 5
X <- matrix(rnorm(n * p), n, p)
W <- rbinom(n, 1, 0.5)
Y <- pmax(X[, 1], 0) * W + X[, 2] + pmin(X[, 3], 0) + rnorm(n)

# 这些是 m(X) = E[Y | X] 的估计
forest.Y <- regression_forest(X, Y)
Y.hat <- predict(forest.Y)$predictions

# 这些是倾向得分 E[W | X] 的估计
forest.W <- regression_forest(X, W)
W.hat <- predict(forest.W)$predictions

c.forest <- causal_forest(X, Y, W, Y.hat, W.hat)
tau.hat <- predict(c.forest)$predictions

# E[Y | X, W = 0]
mu.hat.0 <- Y.hat - W.hat * tau.hat
# E[Y | X, W = 1]
mu.hat.1 <- Y.hat + (1 - W.hat) * tau.hat

这段代码里，regression_forest(X, Y) 估计的是总体条件均值 m(X)；regression_forest(X, W) 估计的是倾向得分；再用二者与因果森林的 tau.hat，按公式拼出 μ(X, 0) 和 μ(X, 1)。注意这里用的是 Y.hat / W.hat 作为因果森林的"honest"估计输入——把结局和倾向的森林预测先算好再喂给因果森林，正是提升稳健性的标准做法。
