如何评估因果森林的拟合质量

原文：Evaluating a causal forest fit（英文） · grf 官方文档中文译本

library(grf)
library(ggplot2)

评估重叠性（overlap 假设）

要检验 grf 背后的可识别假设是否成立，有两种常用的诊断手段：倾向得分（propensity score）直方图，以及协变量平衡（covariate balance）图。

n <- 2000
p <- 10
X <- matrix(rnorm(n * p), n, p)
colnames(X) <- make.names(1:p)

W <- rbinom(n, 1, 0.4 + 0.2 * (X[, 1] > 0))
Y <- pmax(X[, 1], 0) * W + X[, 2] + pmin(X[, 3], 0) + rnorm(n)
cf <- causal_forest(X, Y, W)

重叠性（overlap）假设要求：每一个 \(X_i\) 都有正的接受处理的概率。也就是说，我们不应该仅凭协变量就能确定地判断某个个体是否接受了处理——这意味着估计出来的倾向得分都不应该非常接近 1 或 0。用一张直方图就能检查这一点：

hist(e.hat <- cf$W.hat)

另一种检查方法是：画出所有样本的"逆倾向加权"（inverse-propensity weighted）直方图，看看处理组（treated）和对照组（control）的协变量分布是否平衡。下面把每个特征（feature）的直方图叠加在一起（这里用 ggplot2 实现，因为它支持加权直方图）：

IPW <- ifelse(W == 1, 1 / e.hat, 1 / (1 - e.hat))

plot.df <- data.frame(value = as.vector(X),
                      variable = colnames(X)[rep(1:p, each = n)],
                      W = as.factor(W),
                      IPW = IPW)

ggplot(plot.df, aes(x = value, weight = IPW, fill = W)) +
  geom_histogram(alpha = 0.5, position = "identity", bins = 30) +
  facet_wrap( ~ variable, ncol = 2)

背景与解释

什么是"协变量平衡"（covariate balance）？在随机化试验中，因为处理是随机分配的，处理组和对照组在各协变量上应当分布相似。但 grf 处理的是观测性数据，处理并非随机——例如临床上病情更重的患者更可能接受某种治疗。如果直接用原始数据，估计出的处理效应会被这些"混杂因素"污染。逆概率加权（IPW，即上图中的权重）的目的，是把观测数据"拉"回近似随机分配的状态：加权之后，处理组和对照组在各协变量上的分布应当重合。如果加权后的直方图仍然明显分离，就说明存在未被控制的混杂，模型结果不可信。所以这张图本质上是在检验：我们是否真的像在比较两组"可比的人"。

评估拟合质量

森林（forest）的汇总函数 test_calibration 可以用来评估森林的拟合优度。如果 mean.forest.prediction 的系数为 1，说明森林对均值（即平均处理效应）的预测是准确的；如果 differential.forest.prediction 的系数为 1，说明森林已经捕捉到了底层信号中的异质性（heterogeneity）。

test_calibration(cf)
#> 
#> Best linear fit using forest predictions (on held-out data)
#> as well as the mean forest prediction as regressors, along
#> with one-sided heteroskedasticity-robust (HC3) SEs:
#> 
#>                                Estimate Std. Error t value    Pr(>t)    
#> mean.forest.prediction          1.01570    0.13296  7.6393 1.683e-14 ***
#> differential.forest.prediction  1.19482    0.10324 11.5734 < 2.2e-16 ***
#> ---
#> Signif. codes:  0 '***' 0.001 '**' 0.01 '*' 0.05 '.' 0.1 ' ' 1

这种做法和这个函数，灵感来自计量经济学文献早期的成果。一个更直观的做法是：按 CATE（条件平均处理效应）预测值的高低把样本分成亚组，再比较各组的平均处理效应（ATE）（Athey & Wager, 2019）。虽然这种方法能让我们对异质性有一些定性的认识，但这种分组方式比较"朴素"（naive）——因为用来划分亚组的双稳健（doubly robust）得分，和用来估计那些亚组 ATE 的得分并不是相互独立的。

背景与解释

怎么读懂 test_calibration 的输出？这个函数做的是一个"最佳线性投影"（best linear projection）：它把森林对每棵训练样本外（held-out / 袋外）数据的预测值当作自变量，去线性回归真实的结局，看看系数是否等于 1。具体来说：mean.forest.prediction 的系数 ≈ 1，说明森林对"平均处理效应"这个整体水平的预测是准的；differential.forest.prediction 的系数 ≈ 1，说明森林不仅抓住了平均水平，还正确刻画了效应随个体变化的"异质性"。如果两个系数都显著偏离 1（比如明显小于 1），就提示森林存在欠拟合或偏差。注意这里用了 HC3 异方差稳健标准误，且是在样本外数据上评估，因此结论比较可靠。"投影"的意思是：用一个线性模型去逼近森林的非线性预测，系数 1 代表"完美吻合"。

另一方面，RATE 函数把上述做法自动化了：它利用 CATE 预测的百分位数，对所有可能的亚组做同样的检验。如果我们用一份独立的数据去拟合 CATE 模型、再用另一份数据估计 RATE 指标，那么在没有异质性的情况下，得到的检验统计量的期望为 0；据此就能为"是否存在处理效应异质性"构造置信区间。关于这种更推荐的做法，详见 这篇 vignette。

背景与解释

RATE 与 ATOM：如何正式检验"异质性"是否存在？test_calibration 给出的 differential 系数只是粗略信号。RATE（Rank-Weighted Average Treatment Effect，排序加权平均处理效应）函数则更系统：它按 CATE 预测值从低到高排序，依次把样本切成若干分位组（quantile groups），再检验"高 CATE 组的实际 ATE 是否真的高于低 CATE 组"。如果不存在真正的异质性，这个检验统计量的期望为 0。关键在于：必须"用一份数据训练、用另一份数据评估"，否则衡量异质性的得分和评估亚组 ATE 的得分相互纠缠，会得到过于乐观、有偏的结果。配合 RATE 的"最佳线性投影"版本 ATOM，还能进一步给出正式的置信区间。对医学研究者而言，这相当于一个严谨的"亚组效应是否真实存在"的统计检验，而不只是画个图看个趋势。

Athey 等人（2017）提出了一种偏差（bias）度量，用来衡量：相对于简单地看处理组和对照组的均值差（difference-in-means），倾向模型（propensity model）和结局模型（outcome model）需要"额外做多少工作"才能得到无偏估计。其公式为：\(bias(x) = (e(x) - p) \times (p(\mu(0, x) - \mu_0) + (1 - p) (\mu(1, x) - \mu_1)\)。

tau.hat <- predict(cf)$predictions

p <- mean(W)
Y.hat.0 <- cf$Y.hat - e.hat * tau.hat
Y.hat.1 <- cf$Y.hat + (1 - e.hat) * tau.hat

bias <- (e.hat - p) * (p * (Y.hat.0 - mean(Y.hat.0))  + (1 - p) * (Y.hat.1 - mean(Y.hat.1)))

再除以结局（outcome）的标准差做标准化：

hist(bias / sd(Y))

背景与解释

为什么要用 Athey 等人（2017）的偏差公式？公式里的 bias(x) 衡量的是：在不做调整（只看简单均值差）的情况下，由于倾向得分 \(e(x)\) 偏离总体处理概率 \(p\)，以及两组结局均值 \(\mu(\cdot,x)\) 偏离整体均值，会引入多大偏差。直观地说：如果某类人的"被处理概率"和总体差不多（\(e(x)\approx p\)），且他们的结局基线也和总体接近，那么即便不做复杂调整，简单均值差也不会偏差太大，bias(x) 就接近 0；反之一旦存在"处理分配很不均匀"或"基线差异很大"的人群，bias(x) 就会变大，提醒我们倾向模型和结局模型必须好好工作才能纠偏。所谓"双稳健"（doubly robust），正是指只要倾向模型和结局模型二者之一正确，最终估计就是无偏的——这给医学研究者在建模时留了容错空间。

更多细节请参见 Athey 等人（2017）的 D 节。
