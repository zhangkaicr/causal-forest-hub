类别型协变量（因子变量）的处理

原文：Categorical covariates（英文） · grf 官方文档中文译本

在本示例中，我们将演示在使用 grf 时处理类别型变量（categorical variables，在 R 里也叫“因子 / factor”变量）的几种方法。

背景与解释

什么是类别型变量？它指的是取值来自一个有限、离散集合的变量，例如性别（男 / 女）、种族、吸烟状态（从不 / 曾经 / 当前）、基因型（AA / AG / GG）等。与之相对的是“连续型变量”，如年龄、血压、每加仑英里数（mpg）。

在医学研究中，类别型变量几乎无处不在。但 grf 这类基于树的模型只接受数值型矩阵，因此必须先把类别变量“翻译”成数字。怎么翻译，会直接影响模型能否正确地在类别之间做划分，这也是本文要解决的问题。一个常见误区是：把类别变量当成普通数字直接丢进模型——这会让模型误以为“类别之间天然存在大小顺序”（比如认为种族 3 比种族 1 大），从而得出错误的结论。

下面有一种方法依赖于 grf 的姊妹包 sufrep。我们先把它安装并加载进来。

library(grf)
install.packages("https://github.com/grf-labs/sufrep/blob/master/sufrep_0.1.0.tar.gz?raw=true", repos = NULL, type = "source")
#> Installing package into '/tmp/RtmpKkQCZj/temp_libpath1cdf78711fe0'
#> (as 'lib' is unspecified)
library(sufrep)

我们假设想要根据气缸数（cyl）、四分之一英里加速时间（qsec）以及汽车品牌名称（brand，在下方创建）来预测每加仑英里数（mpg）。

# 创建一个存放品牌名称的类别型列
df <- within(mtcars, {
  # 例如 'Mazda RX4' --> 'Mazda'
  brand <- factor(sapply(rownames(mtcars), function(x) strsplit(x, " ")[[1]][1]))
})

x <- c("cyl", "qsec") # 连续型变量
g <- c("brand")       # 类别型变量

head(df[c(x, g)])
#>                   cyl  qsec   brand
#> Mazda RX4           6 16.46   Mazda
#> Mazda RX4 Wag       6 17.02   Mazda
#> Datsun 710          4 18.61  Datsun
#> Hornet 4 Drive      6 19.44  Hornet
#> Hornet Sportabout   8 17.02  Hornet
#> Valiant             6 20.22 Valiant

上面这段代码会报错，因为 grf 要求输入的数据是数值型的。

# rf <- regression_forest(X=df[c(x, g)], Y=df$mpg)

这里我们有三种可行的处理思路。

  • 直接给每个类别赋一个整数（把 ‘AMC’ 变成 1，‘Cadillac’ 变成 2，依此类推）
  • 对类别做独热编码（one-hot encoding，为每个类别生成一列二值变量）
  • 使用类别的“充分表示”（sufficient representation）。这里我们会用到 sufrep 包里的 means（均值）方法。
背景与解释

三种编码方式到底差在哪？

① 当作整数：最简单，但隐含了一个危险假设——类别之间存在“大小顺序”。随机森林在分裂时会按数值切分（例如 brand ≤ 3），这只有在类别真的有序（如轻 / 中 / 重）时才合理。对品牌、种族这种无序（nominal）类别，这种做法没有意义，还容易误导模型。

② 独热编码（one-hot / 虚拟变量）：为每一个类别生成一列 0/1 变量（如 brand_Mazda、brand_Hornet…），彻底消除“虚假顺序”。这是回归里最常用的虚拟变量（dummy variable）编码。代价是列数会随类别数线性膨胀——若有几十种肿瘤亚型，特征维度会急剧上升。对医学里的多分类变量（如手术方式、药物种类），这点尤其要注意。

③ 充分表示（sufrep）：用连续变量在各类别内的均值来“代表”该类别，既保留信息又压低维度。直观理解：与其只告诉模型“这是 Mazda”，不如告诉它“Mazda 的车平均气缸数、平均加速时间是这样”——而这些均值本身对预测 mpg 已经非常有用。

最后一种方法，是把 brand 这一列替换为连续变量 cyl 和 qsec 按类别分组后的平均值。如果你好奇它为什么管用，或者想深入了解充分表示（sufficient representations）的理论，欢迎阅读我们的 sufrep 论文（ArXiv）。

# 方案 1：把变量转换为数值
X1 <- within(df[c(x, g)], brand <- as.numeric(brand))
rf1 <- regression_forest(X1, df$mpg)


# 方案 2：独热编码（One-hot encoding）
X2 <- model.matrix(~ 0 + ., df[c(x, g)])
rf2 <- regression_forest(X2, df$mpg)


# 方案 3：使用 'sufrep' 包的“均值”编码（'Means' encoding）
encoder <- make_encoder(df[x], df$brand, method="means")
X3 <- encoder(df[x], df$brand)
#> [1] 22  2
rf3 <- regression_forest(X3, df$mpg)

不同方法得到的森林模型表现可能不一样。

mse1 <- mean(rf1$debiased.error)
mse2 <- mean(rf2$debiased.error)
mse3 <- mean(rf3$debiased.error)

print("MSE when representing categorical variables as...")
#> [1] "MSE when representing categorical variables as..."
print(paste0("Integers: ", mse1))
#> [1] "Integers: 15.2683399761995"
print(paste0("One-hot vectors: ", mse2))
#> [1] "One-hot vectors: 14.6540876398824"
print(paste0("'Means' encoding [sufrep]: ", mse3))
#> [1] "'Means' encoding [sufrep]: 13.9976238074058"
背景与解释

为什么编码方式会改变森林表现，又和医学研究有什么关系？

随机森林在每一棵树上都通过“在某一特征上找最佳切分点”来降低预测误差。对连续变量，切分点是某个阈值；对类别变量，编码方式决定了它能怎么切：整数编码只允许“类别 ≤ k”这种切法（受限且可能不合理），独热编码允许任意类别组合，而均值编码则把类别信息浓缩进连续数值，让树更容易学到平滑的关系。从结果上看，本例三种编码的均方误差（MSE）依次下降（整数 15.27 > 独热 14.65 > 均值 13.99），说明编码选择确实有影响。

在医学场景里，这直接对应亚组（subgroup）分析：我们常想知道“某种治疗在男性 vs 女性、在某基因型患者中的效果是否不同”。如果类别变量（性别、种族、基因型等）编码不当，森林可能根本发现不了这些亚组差异，进而掩盖了重要的异质性处理效应（heterogeneous treatment effect）。因此，正确地把无序类别变量送进模型，是后续估计条件平均处理效应（CATE）的前提。
