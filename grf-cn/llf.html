局部线性森林导论

library(grf)
library(glmnet)
library(ggplot2)

本文旨在演示如何使用局部线性森林（local linear forests, LLF）。我们先从标准用法讲起，逐步梳理参数选择与方法细节，最后再讨论如何在更大数据集上使用局部线性校正。

局部线性森林：基本原理

随机森林是一种广受欢迎且强大的非参数回归方法，但当数据中存在强烈而平滑的效应时，它的表现会变差。局部线性回归很适合在低维空间中拟合相对平滑的函数，却会因维数灾难而迅速退化：它依赖欧氏距离，而欧氏距离即便在 4 维或 5 维时也很快失去"局部性"。本算法融合了两种方法的优点（随机森林的数据自适应能力，以及局部线性回归的平滑拟合），从而给出更优的预测与置信区间。关于局部线性森林（LLF）的完整理论，可参见我们在 ArXiv 上的论文。

考虑一棵由 \(B\) 棵树组成的随机森林，要对测试点 \(x_0\) 做预测。在第 \(b\) 棵树中，测试点会落入某个叶节点 \(L_b(x_0)\)。回归森林的做法是：先在 \(L_b(x_0)\) 中对所有响应取平均，再跨所有树把这些预测 \(\hat{\mu}_b(x_0)\) 平均起来。为了换个角度理解随机森林，我们可以交换求和顺序，由此把随机森林视为一种高维空间中的核（kernel）或加权方法。

\[\begin{align*} \hat{\mu}(x_0) &= \frac1B \sum_{b=1}^B \sum_{i=1}^n Y_i \frac{1\{x_i\in L_b(x_0)\}}{|L_b(x_0)|}\\ &= \sum_{i=1}^n Y_i \frac1B \sum_{b=1}^B \frac{1\{x_i\in L_b(x_0)\}}{|L_b(x_0)|} \\ &= \sum_{i=1}^n \alpha_i(x_0) Y_i, \end{align*}\] 其中森林权重 \(\alpha_i(x_0)\) 表示：在所有树中，某个观测与协变量向量的目标取值落入同一叶节点的比例。\[\begin{equation} \alpha_i(x_0) = \frac1B \sum_{b=1}^B \frac{1\{x_i\in L_b(x_0)\}}{|L_b(x_0)|} \end{equation}\]

局部线性森林在此基础上更进一步：它不再用这些权重在 \(x_0\) 处拟合一个局部平均，而是用它们来拟合一个带岭惩罚（ridge penalty）的局部线性回归，以作正则化。这等价于求解下面的最小化问题，其中 \(\mu(x)\) 是局部平均值，\(\theta(x)\) 是局部直线的斜率。\[\begin{equation} \begin{pmatrix} \hat{\mu}(x_0) \\ \hat{\theta}(x_0) \end{pmatrix} = \text{argmin}_{\mu,\theta} \left\{\sum_{i=1}^n \alpha_i(x_0) \left(Y_i - \mu(x_0) - (x_i - x_0)\theta(x_0) \right)^2 + \lambda ||\theta(x_0)||_2^2\right\} \end{equation}\]

这让我们可以做到两点：（i）在高维空间里借助有意义的核来使用局部线性回归；（ii）即便存在平滑而强烈的信号，也能用随机森林做出好的预测。

背景与解释

什么是局部线性森林？ 普通回归森林（regression forest）在每个叶节点里"一刀切"地用常数（样本均值）去近似真实函数；而局部线性森林在得到森林权重后，再做一次局部线性回归，相当于在每个点附近用一条直线（或超平面）去逼近真实关系。森林负责选出"哪些样本与我相似"（即权重），线性回归负责在相似样本内部把趋势拟合得又准又平滑。

它和回归森林、因果森林有何不同？ 回归森林只估计条件均值 \(\mu(x)\)；因果森林（causal forest）估计的是条件平均处理效应 CATE \(\tau(x)\)，本质仍是用森林权重做加权平均。局部线性森林则是把"加权平均"这一步升级为"加权局部线性回归"，因而能刻画协变量与结局之间的线性或平滑趋势。三者共用同一套森林权重框架，区别只在最后一步如何聚合叶节点里的信息。

偏差–方差权衡：常数拟合偏差大（平滑信号被阶梯化）、方差小；局部线性回归通过引入斜率项降低了偏差，岭惩罚又控制了方差。代价是需要更多样本来稳定回归系数，这也是它在小样本或强噪声下未必占优的原因。对医学研究者而言，可以把这理解为：当你相信某个连续协变量（如年龄、剂量）对结局的影响大致是线性的，LLF 比普通森林更"会用"这部分信息。

小试牛刀

我们先看一个简单的例子，说明局部线性森林在什么情况下能胜过普通随机森林。

p <- 20
n <- 1000
sigma <- sqrt(20)

mu <- function(x){ log(1 + exp(6 * x)) }
X <- matrix(runif(n * p, -1, 1), nrow = n)
Y <- mu(X[,1]) + sigma * rnorm(n)

X.test <- matrix(runif(n * p, -1, 1), nrow = n)
ticks <- seq(-1, 1, length = n)
X.test[,1] <- ticks
truth <- mu(ticks)

forest <- regression_forest(X, Y)
preds.forest <- predict(forest, X.test)$predictions

df <- data.frame(cbind(ticks, truth, preds.forest))
g1 <- ggplot(df, aes(ticks)) +
  geom_point(aes(y = preds.forest, color = "Regression Forest"), show.legend = F, size = 0.6) +
  geom_line(aes(y = truth)) +
  xlab("x") + ylab("y") + theme_bw()
g1

ll.forest <- ll_regression_forest(X, Y, enable.ll.split = TRUE)
preds.llf <- predict(ll.forest, X.test,
                     linear.correction.variables = 1)$predictions

df.llf <- data.frame(cbind(ticks, truth, preds.llf))
g2 <- ggplot(df.llf, aes(ticks)) +
  geom_point(aes(y = preds.llf, color = "Local Linear Forest"), show.legend = F, size = 0.6) +
  geom_line(aes(y = truth)) +
  xlab("x") + ylab("y") + theme_bw()
g2

背景与解释

什么时候局部线性森林更有用？ 当真实关系中存在"平滑且较强"的主趋势时，普通回归森林会把曲线切成许多小台阶（阶跃近似），在台阶内部用常数填充，因而有系统性偏差；而局部线性回归能贴合这条曲线。本例中结局基本只由第一个变量 \(x_1\) 通过平滑函数 \(\log(1+\exp(6x_1))\) 决定，所以 LLF 的预测点几乎落在真实曲线上，普通森林则明显抖动、偏离。

什么时候未必有用？ 如果真实函数是高度不规则、阶跃式的（例如分段常数、交互效应主导），或者有效变量很多且彼此纠缠，那么"局部线性"这个假设本身就不成立，森林自身的非参数拟合反而更稳。此外，样本量太小、噪声太大时，局部回归估计斜率会不稳定——这点对临床小样本研究尤其要警惕。

局部线性森林预测的参数

还有几个改动需要说明。我们先列出局部线性森林特有的训练参数（用户也可以参考 regression_forest 的全部调参项，它们在这里同样适用）。

ll.split.weight.penalty TRUE/FALSE FALSE 若使用局部线性切分，可指定是否按协方差对方岭惩罚做标准化（TRUE），还是对所有协变量施加相同惩罚（FALSE）。

背景与解释

几个关键参数怎么理解？

linear.correction.variables（线性校正变量）：这是 LLF 里最常用也最该关心的参数。它决定最后一步局部线性回归"用哪些协变量来修正"。取全部变量（1:p）最省事，但当变量很多、真正有线性趋势的只是少数时，把无关变量塞进回归只会引入噪声。本文学后面会演示用 lasso 先挑变量再喂给 LLF。

enable.ll.split（启用局部线性切分）：默认 FALSE，即建树仍用普通 CART。设为 TRUE 后，树在切分时考虑的是"岭回归残差"而非原始均值，能更聚焦于非线性/交互部分。注意它仍是实验性功能，且在大样本上很慢。

ll.lambda / ll.split.lambda（岭惩罚）：相当于岭回归里的正则化强度，数值越大越"压平"斜率、越保守。预测阶段的 ll.lambda 默认会自动调；而在大数据上自动调参极慢，需要手动给定（如 0.1）。

训练算法

n <- 600
p <- 20
sigma <- sqrt(20)

mu <- function( x ) {
  10 * sin(pi * x[1] * x[2]) + 20 * ((x[3] - 0.5) ** 2) + 10 * x[4] + 5 * x[5]
}

X <- matrix(runif(n * p, 0, 1), nrow = n)
Y <- apply(X, FUN = mu, MARGIN = 1) + sigma * rnorm(n)

X.test <- matrix(runif(n * p, 0, 1), nrow = n)
truth = apply(X.test, FUN = mu, MARGIN = 1)

# 回归森林预测
rforest <- regression_forest(X, Y, honesty = TRUE)
results <- predict(rforest, X.test)
preds <- results$predictions
mean((preds - truth)**2)
#> [1] 8.651616

我们可以通过两种方式得到局部线性森林预测：一是在普通回归森林上指定 linear.correction.variables（线性校正变量），二是直接使用 ll_regression_forest 对象。该参数指定了最后一步局部回归所用的变量，可以简单地取全部变量，也可以只取一个子集。

# 用 regression_forest 得到局部线性森林预测
results.llf <- predict(rforest, X.test, linear.correction.variables = 1:p)
preds.llf <- results.llf$predictions
mean((preds.llf - truth)**2)
#> [1] 5.792562

# 用 ll_regression_forest 得到局部线性森林预测
forest <- ll_regression_forest(X, Y, honesty = TRUE)
results.llf <- predict(forest, X.test)
preds.llf <- results.llf$predictions
mean((preds.llf - truth)**2)
#> [1] 5.78837

权重惩罚

在做局部线性森林预测时，我们可以采用标准岭回归（ll.weight.penalty 设为 FALSE），也可以按协方差矩阵做缩放（ll.weight.penalty 设为 TRUE）：\(\hat{\beta}_\text{TRUE} = (X'AX (1 + \lambda))^{-1} X'AY\)。该参数默认值为 FALSE。

results.llf.unweighted <- predict(forest, X.test,
                               ll.weight.penalty = FALSE)
preds.llf.unweighted <- results.llf.unweighted$predictions
mean((preds.llf.unweighted - truth)**2)
#> [1] 5.78837

results.llf.weighted <- predict(forest, X.test,
                               ll.weight.penalty = TRUE)
preds.llf.weighted <- results.llf.weighted$predictions
mean((preds.llf.weighted - truth)**2)
#> [1] 5.736676

残差切分

我们还要考虑局部线性森林中"建树"的作用。标准的 CART 切分会最小化"用叶节点整体均值做预测"带来的误差；而我们也可以改用残差切分（residual splits），即最小化岭回归残差上对应的预测误差。可以想见，当某些协变量带有强烈的线性信号时，这种做法会很有帮助——我们不必浪费森林的切分去建模这些线性部分，因为最后一步回归仍能把它们找出来。本质上，这让我们在知道"后面还有一次局部回归要做"的前提下，把森林的切分用得最有效率。该特性目前仍属于实验性功能。

forest <- ll_regression_forest(X, Y)
preds.cart.splits <- predict(forest, X.test)

ll.forest <- ll_regression_forest(X, Y, enable.ll.split = TRUE,
                                  ll.split.weight.penalty = TRUE)
preds.ll.splits <- predict(ll.forest, X.test)

mse.cart.splits <- mean((preds.cart.splits$predictions - truth)^2)
mse.ll.splits <- mean((preds.ll.splits$predictions - truth)^2)

mse.cart.splits
#> [1] 5.771045
mse.ll.splits
#> [1] 4.703251

岭参数选择

用户可以选择自行指定岭回归参数 ll.lambda。如果用户不设置该值，森林会通过自动调参来选定它。一般来说，我们建议让森林自动调这个参数，或者由你自己跑一轮交叉验证。唯一的例外是数据集非常大的情形。

results.llf.lambda <- predict(forest, X.test,
                             ll.lambda = 0.1)
preds.llf.lambda <- results.llf.lambda$predictions
mean((preds.llf.lambda - truth)**2)
#> [1] 5.771045

results.llf.lambda <- predict(forest, X.test) # 自动调参
preds.llf.lambda <- results.llf.lambda$predictions
mean((preds.llf.lambda - truth)**2)
#> [1] 5.771045

线性校正变量的选择

当协变量很多时，把局部回归限制为只包含少数感兴趣的变量是合理的。我们推荐使用 lasso 方法。

# 训练森林
forest <- ll_regression_forest(X, Y)

# 选择协变量
lasso.mod <- cv.glmnet(X, Y, alpha = 1)
lasso.coef <- predict(lasso.mod, type = "nonzero")
selected <- lasso.coef[,1]
selected
#> [1] 1 2 4 5

# 用全部协变量预测
llf.all.preds <- predict(forest, X.test)
results.all <- llf.all.preds$predictions
mean((results.all - truth)**2)
#> [1] 5.800366

# 仅用筛选出的协变量预测
llf.lasso.preds <- predict(forest, X.test,
                           linear.correction.variables = selected)
results.llf.lasso <- llf.lasso.preds$predictions
mean((results.llf.lasso - truth)**2)
#> [1] 4.81568

逐点置信区间

最后，我们来看方差估计与置信区间，其原理与 grf 的方差估计类似。为了便于可视化，我们沿用本文第一个数据生成过程。

mu <- function(x){ log(1 + exp(6 * x)) }
p <- 20

X <- matrix(runif(n * p, -1, 1), nrow = n)
Y <- mu(X[,1]) + sigma * rnorm(n)

X.test <- matrix(runif(n * p, -1, 1), nrow = n)
ticks <- seq(-1, 1, length = n)
X.test[,1] <- ticks
truth <- mu(ticks)

# 选择协变量
lasso.mod <- cv.glmnet(X, Y, alpha = 1)
lasso.coef <- predict(lasso.mod, type = "nonzero")
selected <- lasso.coef[,1]
selected
#> [1] 1

ll.forest <- ll_regression_forest(X, Y, enable.ll.split = TRUE)
results.llf.var <- predict(ll.forest, X.test,
                           linear.correction.variables = selected,
                           estimate.variance = TRUE)
preds.llf.var <- results.llf.var$predictions
variance.estimates <- results.llf.var$variance.estimates

# 计算 95% 区间的下界与上界
lower.llf <- preds.llf.var - 1.96*sqrt(variance.estimates)
upper.llf <- preds.llf.var + 1.96*sqrt(variance.estimates)

df <- data.frame(cbind(ticks, truth, preds.llf.var, lower.llf, upper.llf))
ggplot(df, aes(ticks)) +
  geom_point(aes(y = preds.llf.var, color = "Local Linear Forest"), show.legend = F, size = 0.6) +
  geom_line(aes(y = truth)) +
  geom_line(aes(y = lower.llf), color = "gray", lty = 2) +
  geom_line(aes(y = upper.llf), color = "gray", lty = 2) +
  xlab("x") + ylab("y") + theme_bw()

背景与解释

逐点置信区间有什么用，又要注意什么？ 设 estimate.variance = TRUE 后，predict 会额外返回每个测试点的方差估计，于是可以像上图那样画出 95% 逐点置信带（预测值 ± 1.96×标准差）。这对医学研究很实用：你不仅能报出"某亚组的预测风险"，还能给出"这个预测有多不确定"。

偏差–方差的视角：普通森林的置信带往往过宽（方差大）或形状僵硬；LLF 因为用局部线性降低了偏差，置信带更贴真实曲线、宽度也更合理。但要注意，这类方差估计依赖"局部线性回归"这一设定——如果真实关系并不平滑，"逐点"置信区间的覆盖概率可能失真，解读时勿把带子当成了总体不确定性的全部。

与其他 grf 方法的关联：因果森林、生存森林的方差估计走的也是同一套"基于森林权重的梯度/方差分解"路线，所以这里学到的置信区间画法，可以平移到处理效应（CATE）的不确定性刻画上。

关于更大数据集的说明

尽管局部线性森林通常优于普通随机森林，但当维数非常高时，训练和预测都会很耗时。原因在于：假设有 n_train 个训练点和 n_test 个测试点，我们相当于要跑 n_test 次回归，每次都用全部 n_train 个数据点。不过，有时我们仍想用随机森林并对线性趋势做校正。在这种情形下（数据量约在 10 万条及以上，当然具体还要看实际场景），选取少量线性校正变量就格外重要。目前的岭参数调参也会耗时到难以接受，因此我们建议：要么统一把该值设为 0.01，要么在数据的子集上调参，要么限制候选取值的范围，要么用小批量的浅树做交叉验证。

LLF 参数及其在大数据集下的表现。
参数 可选值 默认值 随 n、p 增大时的表现
训练参数
enable.ll.split TRUE/FALSE FALSE 当 n 和 p 都很大时，每个叶节点里的岭回归会非常耗时。因此我们建议要么不使用该功能，要么谨慎设置下面讨论的调参项。另请注意它仍是实验性功能。
ll.split.weight.penalty TRUE/FALSE FALSE 不受影响
ll.split.lambda 非负实数 0.1 不受影响
ll.split.variables 协变量下标向量 1:p 当 p 很大（超过 50）时，我们建议要么把 ll.split.variables 限制为一个子集，要么改用 CART 切分，要么设置一个足够大的切分截断值（见下）。
ll.split.cutoff 0 到 n 之间的整数 n 的平方根 调大该参数有助于加快局部线性切分，推荐在大数据上训练森林且想用局部线性切分时使用。
预测参数
ll.lambda 非负实数 默认自动调参 默认调参在大数据上会耗时很久，我们建议要么自己写一轮更短的交叉验证，要么不自动调参、直接把 ll.lambda 设成约 0.1 的默认值。
ll.weight.penalty TRUE/FALSE FALSE 不受影响
linear.correction.variables 协变量下标向量 1:p 随着 n、p 增大，限制线性校正变量是保证预测高效的关键一步。我们强烈建议在此情形下用 lasso、逐步回归、先验知识等方法，挑出数量相当少的一组线性校正变量用于局部线性森林预测。

下面这段代码目前设为不运行；预计耗时约 5–6 分钟。用全部 p 个变量做局部线性森林预测会非常慢，这种规模数据上的自动调参同样很慢。不过，我们仍然可以使用线性校正，只是需要更精心地设置参数。用户可以增加树的数量，让两种方法都获得更好的表现。

# 生成数据
n <- 5e5
p <- 20

sigma <- sqrt(20)

f <- function(x){
  10 * sin(pi * x[1] * x[2]) + 10 * (x[3] - 0.5)**2 + 10 * x[4] + 5 * x[5]
}

X <- matrix(runif(n * p, 0, 1), nrow = n, ncol = p)
Y <- apply(X, MARGIN = 1, FUN = f) + sigma * rnorm(n)

X.test <- matrix(runif(n * p, 0, 1), nrow = n, ncol = p)
truth.test <- apply(X.test, MARGIN = 1, FUN = f)

ptm <- proc.time()
forest <-regression_forest(X, Y, tune.parameters = "none", num.trees = 50)
time.train <- (proc.time() - ptm)[[3]]

ptm <- proc.time()
preds.grf <- predict(forest, X.test)$predictions
mse.grf <- mean((preds.grf - truth.test)**2)
time.grf <- (proc.time() - ptm)[[3]]

ptm <- proc.time()
ll.forest <- ll_regression_forest(X, Y, tune.parameters = "none", enable.ll.split = TRUE ,num.trees = 50)
time.train.ll <- (proc.time() - ptm)[[3]]

ptm <- proc.time()
lasso.mod <- cv.glmnet(X, Y, alpha = 1)
lasso.coef <- predict(lasso.mod, type = "nonzero")
selected <- lasso.coef[,1]
selected
time.lasso <- (proc.time() - ptm)[[3]]

ptm <- proc.time()
preds.llf <- predict(ll.forest, X.test,
                    linear.correction.variables = selected,
                    ll.lambda = 0.1)$predictions
mse.llf <- mean((preds.llf - truth.test)**2)
time.llf <- (proc.time() - ptm)[[3]]

cat(paste("GRF training took", round(time.train, 2), "seconds. \n",
          "GRF predictions took", round(time.train.ll, 2), "seconds. \n",
          "LLF training took", round(time.grf, 2), "seconds. \n",
          "Lasso selection took", round(time.lasso, 2), "seconds. \n",
          "LLF prediction took", round(time.llf, 2), "seconds. \n",
          "LLF and lasso all in all took", round(time.lasso + time.llf, 2), "seconds. \n"))

# GRF 训练耗时 342.14 秒
# LLF 训练耗时 215.64 秒
# GRF 预测耗时 20.25 秒
# Lasso 选择耗时 15.10 秒
# LLF 预测耗时 45.40 秒
# LLF 与 lasso 总共耗时 60.50 秒

cat(paste("GRF predictions had MSE", round(mse.grf, 2), "\n",
          "LLF predictions had MSE", round(mse.llf, 2)))
# GRF 预测 MSE 为 0.81
# LLF 预测 MSE 为 0.69
