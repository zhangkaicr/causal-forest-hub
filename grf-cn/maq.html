《Qini 曲线：自动成本-收益分析》

原文：Qini curves: Automatic cost-benefit analysis（英文） · grf 官方文档中文译本

library(grf)
library(maq)

本篇短文简要介绍 Qini 曲线（或称成本-收益曲线，cost curves）如何作为一种直观而有吸引力的指标，用于在"实施治疗存在成本"时对治疗规则（treatment rules）进行评估；并介绍如何将其推广到多个治疗臂（treatment arms），这些功能在配套包 maq 中实现。完整的理论细节，请参考 这篇论文。

用估计的 CATE 推导治疗分配策略

在正式介绍 Qini 曲线之前，我们先约定一些术语、复习几个核心概念。考虑一个二值处理分配 \(W_i = \{0, 1\}\) 以及我们关心的某个结局 \(Y_i\)。为了判断人群中是否存在某些亚组（subgroup）——由某些可观测特征 \(X_i\) 定义——对处理分配的反应各不相同，我们的核心关注对象是条件平均处理效应（conditional average treatment effect，简称 CATE）

\[\tau(X_i) = E[Y_i(1) - Y_i(0) \,|\, X_i = x],\]

其中 \(Y_i(1)\) 和 \(Y_i(0)\) 分别是两种处理状态下的潜在结局（potential outcomes）：治疗臂与对照组臂。

估计函数 \(\tau(X_i)\) 的方法有很多，因果森林（Causal Forest）就是其中之一。当我们已经在某个训练集上得到估计函数 \(\hat \tau(\cdot)\) 之后，下一步自然要问：在一个独立的测试集（held-out test set）上，可以用什么指标（metric）来评估它？这取决于我们的实际用途。在很多场景下，我们希望用 \(\hat \tau(\cdot)\) 来指导治疗分配。估计得到的 CATE 函数 \(\hat \tau(\cdot)\) 实际上隐含地给出了一族策略（policies），我们记为 \(\pi(\cdot)\)：它接收协变量 \(X_i\)，并把它映射为一个治疗决策 \(\{0: \text{不治疗}, 1: \text{治疗}\}\)。举例来说，假设我们的资源有限，只打算对最多 10% 的个体实施治疗。那么，"只治疗预测获益最高的前 10%"这一策略就是

\[ \pi(X_i) = \begin{cases} 1,& \text{if CATE predictions } \hat \tau(X_i) \geq \text{top 10%}\\ 0, & \text{otherwise}. \end{cases} \] 这一策略的价值为 \(E[\pi(X_i) (Y_i(1) - Y_i(0))]\)，它也可以表述为一个简单的优先规则（priority rule）：只治疗那些预测处理效应高于某个阈值的个体。这个策略价值满足一个中心极限定理——也就是说，尽管用于决定治疗分配的底层函数 \(\hat \tau(\cdot)\) 可能来自复杂的"黑盒"机器学习算法，我们仍然可以对它在真实世界中部署时的表现给出估计值和置信区间。

背景与解释

什么是 Uplift 建模（Uplift Modeling）？传统的预测模型关心"这个病人会不会康复（\(Y\)）"，而 Uplift 建模关心的是"治疗对这个病人带来了多大改变"——也就是处理效应本身。它的目标不是预测结局，而是预测"给治疗 vs. 不给治疗"的差值。这正是 CATE \(\tau(X_i)\) 的含义：在协变量 \(X_i\) 给定的条件下，干预带来的增量收益。

对医学研究者而言，这意味着我们不再问"谁病得最重"，而是问"谁最可能因治疗而获益"。举个例子：某种降压药对年轻人效果平平，但对伴有特定基因型的高血压患者效果显著。平均效应（ATE）会把这两种情况混在一起，掩盖真正该被治疗的亚组。Uplift 建模正是异质性处理效应（HTE）分析的核心思路，也是下文所有靶向治疗策略的基础。

Qini 曲线：在多个决策阈值上评估策略

为了更具一般性，现在考虑"实施治疗会产生成本"的情形，记 \(C_i(1)\) 为把第 \(i\) 个个体分配到治疗臂的成本（并假设不实施治疗没有成本，即 \(C_i(0)=0\)）。成本随个体变化的例子可以是疫苗接种：把药品送到远离医疗中心的居民那里，成本往往高于送到附近的居民。成本未必是金钱，它也可以刻画更抽象的东西，例如负外部性（negative externalities）。

现在的问题是：给定预算 \(B\)，用什么合适的方法来量化"依据估计 CATE 来分配治疗"背后的成本-收益权衡（cost-benefit tradeoff）？事实证明，把成本纳入我们在上一节勾勒的策略评估框架中，是一件很自然的事。

回顾一下，策略 \(\pi(X_i)\) 是一个把协变量 \(X_i\) 映射为治疗决策的函数，\(\pi(X_i) \in \{0: \text{不治疗}, 1: \text{治疗}\}\)。在本节中，这个函数会依赖于预算 \(B\)，我们用下标记为 \(\pi_B(X_i)\)。结果它同样可以表达为一个治疗优先规则，本质上就是："如果你有 \(B\) 的预算可用，那么当 Alice 的估计成本-收益比（CATE/成本）高于某个临界值时就治疗她"，对 Bob 等人同理。如果 Alice 的估计 CATE 为负，我们就不会考虑治疗她——因为那样既会增加成本，又会拉低收益。

背景与解释

成本-收益权衡（Cost-Benefit Tradeoff）为什么关键？在真实世界里，治疗从来不是"免费的"。一支疫苗冷链运输到偏远地区，成本远高于城市社区；一款新药即便更有效，也可能因为价格而只能覆盖一小部分患者。Qini 框架把这种"每单位花费能换来的平均处理效应"（即 CATE/成本）作为排序依据，本质上是在问：在有限预算下，先治谁最划算？

注意一个常被忽略的点：Qini 曲线并不要求"成本"和"处理效应"用同一把尺子度量（比如成本用人民币、效应用血压降幅），因为决策只取决于它们的比值。这让它在跨尺度、跨场景的卫生经济学评价中非常灵活。若某个体的估计 CATE 为负，则无论成本多低都不该治疗——因为那只会白白烧钱还拉低总体收益。

我们有一个包含 \(n\) 条观测结局与处理分配的测试集可供评估。我们想量化的是：在不同的支出水平（spend levels）\(B\) 下，依据 \(\pi_B\) 来分配治疗所能实现的期望增益（gain，用 ATE 衡量）。

在上一节，我们略去了评估一个策略的具体细节。好在它其实很简单：如果我们知道处理的随机化概率，就可以用逆倾向加权（inverse-propensity weighting，简称 IPW）来估计所实现的增益——做法是对"与策略处方相符"的测试集结局差异取平均：

\[ \frac{1}{n} \sum_{i}^{n} \pi_B(X_i) \left( \frac{W_i Y_i}{P[W_i = 1|X_i]} - \frac{(1-W_i)Y_i}{P[W_i = 0|X_i]} \right). \] IPW（括号中的项）考虑了这样一个事实：所开出的策略 \(\pi_B(X_i)\) 可能与个体 \(i\) 实际观测到的处理 \(W_i\) 并不一致。当我们改变可用预算 \(B\) 时，Qini 曲线就把上面的价值描绘出来，从而得到如下量的估计：

\[ Q(B) = E[\pi_B(X_i) (Y_i(1) - Y_i(0))] = E[\pi_B(X_i) \tau(X_i)], \] 即在各种预算 \(B\) 取值下，依据我们估计的 CATE 与成本来分配治疗所能实现的增益；并且满足约束：我们平均承担的成本 \(E[\pi_B(X_i) (C_i(1) - C_i(0))]\) 不超过 \(B\)。

背景与解释

Qini 曲线到底是什么？可以把 Qini 曲线想象成"预算 vs. 收益"的性价比图：横轴是你能花多少钱（或治疗的覆盖比例），纵轴是到该支出水平为止、按成本-收益排序后靶向治疗所能实现的累积期望增益 \(Q(B)\)。

曲线的"形状"比单一数字更有信息量：如果它明显高出那条"不看 CATE、随机分配"的虚线（基线），就说明"挑人治疗"确实比"人人都治"划算；如果它很快就进入平台期，说明再多的预算也救不回那些预测效应为负的个体。Qini 曲线最大的实用价值在于：它不仅给出点估计，还自带自助法（bootstrap）得到的置信带，让你能量化"这个靶向策略到底有多稳"。

下面的代码示例是一个玩具例子。为了让说明尽量简单，我们假设每个个体的成本都相同，治疗 Bob 和 Alice 各花费 1.0（采用某种选定的计量单位）。（Qini 作为一个评估指标有个很好的性质：它不要求成本和处置效应使用同一种计量尺度，只有它们的比值才重要。）

n <- 2000
p <- 5
X <- matrix(rnorm(n * p), n, p)
W <- rbinom(n, 1, 0.5)
Y <- pmax(X[, 1], 0) * W + X[, 2] + pmin(X[, 3], 0) + rnorm(n)

# 1) 在训练集上训练一个 CATE 函数。
train <- sample(n/2)
c.forest <- causal_forest(X[train, ], Y[train], W[train])

# 2) 在测试集上预测 CATE。
test <- -train
tau.hat <- predict(c.forest, X[test, ])$predictions

# 3) 使用逆倾向加权的测试集结局来估计 Qini 曲线。
IPW.scores <- ifelse(W[test] == 1, Y[test]/0.5, -Y[test]/0.5)
# 假设每个个体的成本相同。
cost <- 1
# 使用 maq 包拟合 Qini 曲线，用 200 次自助抽样（bootstrap）计算标准误。
qini <- maq(tau.hat, cost, IPW.scores, R = 200)

# 构建一条基线 Qini 曲线：用 ATE 而非 CATE 来分配治疗。
qini.baseline <- maq(tau.hat, cost, IPW.scores, target.with.covariates = FALSE, R = 200)

plot(qini, xlim = c(0, 1))
plot(qini.baseline, add = TRUE, lty = 2, ci.args = NULL) # 为清晰起见省略置信区间。

实线表示期望增益（纵轴）：随着我们愿意为每个个体支出的金额（横轴）增加，我们把治疗分配给"每单位花费下预测获益最大"的个体时所能获得的增益，并配有 95 % 置信带。虚线表示"不考虑 CATE"时的 Qini 曲线——也就是说，当这条线走到尽头时，预算已用尽、每个人都接受了治疗，此时增益等于 ATE，即 0.38。（因此，虚线上的每个点代表：在不同支出水平下，针对人群中任意一组个体时我们所能预期的 ATE 的比例，所以它不必是 45 度线。）

黑色实线这条 Qini 曲线，利用估计的 CATE 来预测哪些测试集受试者"每单位花费下的治疗效应"最高。当这条曲线明显地冲到那根"忽略" CATE 的虚直线上方时，说明按照估计 CATE 所暗示的那样，把治疗定向（targeting）到某个对此最敏感的亚人群是有收益的。这条曲线在 \(B=\) 0.89 处停下（或"进入平台期"），因为到那个点我们已经把治疗分配给了所有预测会获益的个体，即 \(\hat \tau(X_i) > 0\)。

我们可以通过下面的方式，在曲线上读取不同 \(B\) 处的估计值：

average_gain(qini, spend = 0.2)
#> estimate  std.err 
#>    0.288    0.044

也就是说，在平均支出 \(B=0.2\) 时，每个个体的平均收益 95% 置信区间为 0.29 \(\pm\) 0.09。（这里的标准误以估计函数 \(\hat \tau(\cdot)\) 为条件，刻画的是估计 Qini 曲线时测试集带来的不确定性。）

如果我们改用同等预算去治疗人群中的任意一组个体，估计得到的增益则为：

average_gain(qini.baseline, spend = 0.2)
#> estimate  std.err 
#>    0.075    0.019

关于策略评估的说明：只要 IPW 能解决的问题，通常都存在一个双稳健（doubly robust）方法（这里是增强型 IPW，即 Augmented-IPW）能在统计功效上做得更好。本篇为简洁起见仍采用 IPW 评估，但请注意：在 GRF 中，你可以额外训练一个测试集森林，并通过函数 get_scores(forest) 取得双稳健的测试集得分，用它来代替 IPW.scores，从而得到 Qini 曲线的双稳健估计。

题外话：Qini 曲线与 TOC 曲线的区别

到目前为止，我们已经介绍了两条曲线，它们看起来都在服务于相似的目的。区别何在？这取决于具体应用场景。仔细看就会发现，哪条曲线有用，取决于我们想要回答的问题。下图并列展示了 TOC 与 Qini 曲线在如下情形下的样子：ATE 为正，但人群中存在治疗效应既为正也为负的亚组（Qini 图中虚线代表 ATE）。

TOC 把"某个评分规则各分位数上的平均处理效应"与"整体平均处理效应"进行比较。而 Qini 曲线刻画的是：当我们改变每个个体支出的预算约束时，每单位所对应的平均处理效应。

所以：如果你关心的是"是否存在一组人比平均而言从治疗中获益更多"，那么 TOC 曲线很有用。如果成本并不直接相关，而你更想检测异质性（heterogeneity）是否存在，TOC 就很有帮助，因为它能清晰地揭示"靶向治疗在哪里起作用"的那个分位数。因此，TOC 是一种衡量异质性的通用工具。

如果你所处的场景天然适合做某种成本-收益分析，那么 Qini 曲线就很有用。它的好处在于能清晰地揭示：在给定各种预算分配水平下，通过把治疗定向到"最敏感"的个体，每单位支出所能实现的期望增益。Qini 曲线的另一个优势是它更自然地被推广到多个治疗臂——因为成本要素延续了类似的"成本-收益权衡"，只不过现在它同时跨越"治疗臂"和"个体"两个维度。

关于恒定成本的说明：对于单一治疗臂，当每个个体的成本相同，即 \(C_i(X_i) = 1\) 时，我们也可以把上面 Qini 曲线图的横轴理解为"接受治疗的比例"（treated fraction）。

多臂治疗情形下的 Qini 曲线

现在考虑我们有 \(k = 0,\ldots K\) 个可用治疗臂的情形，其中 \(k=0\) 是零成本的对照组臂。例如，\(k=1\) 可以是低成本的药，\(k=2\) 可以是成本更高但效果更好的药（\(k=0\) 可以是安慰剂对照）。

给定估计的处理效应 \(\hat \tau(\cdot)\) 与成本 \(C(\cdot)\)（注意，这些对象现在是向量值（vector-valued）的，即 \(\hat \tau(X_i)\) 的第 \(k\) 个元素，是针对协变量为 \(X_i\) 的个体、第 \(k\) 个治疗臂的 CATE 估计1）——我们接下来要问：如何像上面那样，在改变可用预算的同时，依据估计的 CATE（与成本）来最优地分配治疗？

结果表明，要做这件事，我们需要求解一个带约束的优化问题，因为底层的策略对象 \(\pi_B(X_i)\) 现在必须为每个个体在多个（成本各异的）潜在治疗臂中做出最优选择。例如，在每个支出水平上，我们都要决定：是给 Alice 分配某个初始治疗臂，还是说——如果 Bob 已经被分配了一个臂——我们应该把 Bob 升级到一个成本更高但效果更好的臂。

maq 包能高效地完成这一计算（通过一个定制算法来求解解路径，solution path），这里我们直接跳到一个包含 2 个治疗臂和 1 个对照组的玩具例子。我们模拟一个简单情形：其中一个治疗臂（编号 2）平均效果更好，但成本也更高。我们假设把任何个体分配到第一个臂的成本是 0.2（采用某种选定的计量单位），分配到第二个臂的成本是 0.5（成本也可以依据某些已知特征随个体变化，此时可以把下面的 cost 参数设为一个矩阵）。

# 模拟两个治疗臂（1 和 2）以及一个对照组臂 0。
n <- 3000
p <- 5
X <- matrix(runif(n * p), n, p)
W <- as.factor(sample(c("0", "1", "2"), n, replace = TRUE))
Y <- X[, 1] + X[, 2] * (W == "1") + 1.5 * X[, 3] * (W == "2") + rnorm(n)

# 1) 在训练集上训练一个 CATE 函数。
train <- sample(n/2)
c.forest <- multi_arm_causal_forest(X[train, ], Y[train], W[train])

# 2) 在测试集上预测 CATE。
test <- -train
tau.hat <- predict(c.forest, X[test, ], drop = TRUE)$predictions

# 3) 基于 IPW 构建多臂 Qini 曲线（maq 包内置的便捷函数）。
IPW.scores <- get_ipw_scores(Y[test], W[test])

# 第 1 和第 2 臂的成本。
cost <- c(0.2, 0.5)

# 针对多臂策略的 Qini 曲线。
ma.qini <- maq(tau.hat, cost, IPW.scores, R = 200)

# 一条"基线" Qini 曲线：忽略协变量。
ma.qini.baseline <- maq(tau.hat, cost, IPW.scores, target.with.covariates = FALSE, R = 200)

多臂策略对应的 Qini 曲线如下图所示：

plot(ma.qini)
plot(ma.qini.baseline, add = TRUE, lty = 2, ci.args = NULL)

虚线代表一条 Qini 曲线：它只依据 tau.hat 的平均值来把治疗分配到各个臂。这条曲线在 \(B=0.2\) 处有一个拐点（kink）：第一段描绘的是低成本臂的 ATE，第二段则是成本更高、但平均更有效臂的 ATE。这条曲线上的点，代表针对任意一组个体时每单位的平均收益2。

实线展示的是某策略的估计 Qini 曲线：该策略利用 tau.hat 和 cost，在某个给定支出下，把治疗臂分配给"预测成本-收益最高"的个体。我们可以通过估计虚线与实线之间的差距，来评估"同时使用两个臂进行靶向"相对于"随机分配治疗"的价值。例如，在 \(B=0.3\) 处，这个垂直距离为：

difference_gain(ma.qini, ma.qini.baseline, spend = 0.3)
#> estimate  std.err 
#>    0.235    0.049

我们还可以通过 predict 取得底层多臂策略 \(\pi_B\) 的估计，例如在 \(B=0.3\) 时：

pi.hat <- predict(ma.qini, spend = 0.3)
head(pi.hat)
#>      [,1] [,2]
#> [1,]    1    0
#> [2,]    1    0
#> [3,]    1    0
#> [4,]    1    0
#> [5,]    0    1
#> [6,]    0    0

\(\pi_B(X_i)\) 现在是一个 \(K\) 维向量，即：在上面第 \(i\) 行中，若我们在该支出水平下把第 \(k\) 个臂分配给该个体，则第 \(k\) 列为 1；若分配的是对照组臂，则所有元素均为 03。

我们还可以通过为每个臂分别计算 Qini 曲线，来与单臂治疗策略做比较。

qini.arm1 <- maq(tau.hat[, 1], cost[1], IPW.scores[, 1], R = 200)
qini.arm2 <- maq(tau.hat[, 2], cost[2], IPW.scores[, 2], R = 200)

plot(ma.qini, ci.args = NULL) # 为清晰起见省略置信区间。
plot(qini.arm1, add = TRUE, col = "blue", ci.args = NULL)
plot(qini.arm2, add = TRUE, col = "red", ci.args = NULL)
legend("topleft", c("both arms", "arm 1", "arm 2"),
       col = c("black", "blue", "red"), lty = 1)

蓝线（臂 1）在支出水平约 0.2 处进入平台期，因为一旦达到这个支出水平，我们已经把治疗给了所有被认为会从臂 1 获益的个体（即 \(\hat \tau_1(X_i) > 0\)），因此无法再通过增加支出获得更多增益。

针对单臂治疗规则的 Qini 曲线，有助于评估"使用某个特定臂或某种特定靶向函数"的价值。多臂 Qini 的推广则让我们可以回答这样的问题："在某一特定支出水平下，相比只用单个臂，同时使用两个臂进行最优靶向能带来多大的增益提升？"我们把 \(\hat Q(B)\) 记为多臂策略的估计 Qini 曲线，把 \(\hat Q_2(B)\) 记为臂 2 的估计 Qini 曲线。在 \(B = 0.3\) 处，差值 \(\hat Q(B) - \hat Q_2(B)\)（即上图中绿色竖线所示）为：

difference_gain(ma.qini, qini.arm2, spend = 0.3)
#> estimate  std.err 
#>    0.154    0.073

在这个例子中，多臂策略通过给每个测试集个体分配"最具成本-收益"的治疗，获得了比仅用臂 1 的策略更大的增益（任意两条曲线上的点都可以用这个函数比较，得到成对标准误，它考虑了在同一测试数据上拟合的 Qini 曲线之间的相关性）。

我们还可以在一系列支出水平上比较不同的靶向策略。函数 integrated_difference 估计两条 Qini 曲线之间的面积。下面阴影区域（积分 \(\int_{0}^{0.3} \left(Q(B) - Q_2(B)\right)dB\)）的估计值为：

integrated_difference(ma.qini, qini.arm2, spend = 0.3)
#> estimate  std.err 
#>   0.0087   0.0575
背景与解释

Qini 曲线与精准医疗（Precision Medicine）/ 靶向治疗的关系。精准医疗的愿景是"对正确的患者，在正确的时间，用正确的治疗"。多臂 Qini 曲线恰好把这句话变成了可计算、可比较、可置信的决策工具：当我们有便宜但温和的药（臂 1）和昂贵但强效的药（臂 2）时，Qini 框架能告诉你"在某个预算下，应该把谁升级到贵药"，并给出相比"只用一种药"或"随机分配"的增益提升（difference_gain / integrated_difference）。

对临床研究者而言，这意味着 RCT 之后还能走得更远：不再只报一个"整体有效"，而是量化"如何把有限的药物资源精准投到最获益的亚组"，并给出置信区间支撑卫生决策。这也是从"证据是否存在"走向"证据如何落地"的关键一步。
