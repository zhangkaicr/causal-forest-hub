把平均处理效应迁移到新目标人群

原文：Estimating ATEs on a new target population（英文） · grf 官方文档中文译本

本篇简要介绍如何使用广义随机森林（GRF）来估计某个新目标人群上的平均处理效应（average treatment effect，ATE）。这里的目标人群由一组协变量 \(X_{test}\) 来定义。第一部分给出问题设定和一个双稳健（doubly robust）估计量的概览，第二部分给出一个用 GRF 实现该估计量的完整代码示例。

迁移问题概览

给定一个已有试验得到的估计值，要在某个新的目标人群上做统计推断，这个一般性问题被称为"迁移问题"（transport problem），相关文献非常多。本篇采用 Dahabreh 等人（2020）提出的设定与双稳健估计量。

背景与解释

外部效度与"可推广性"。 一篇论文里算出的处理效应，能不能套用到另一群人身上？这就是统计学与流行病学常说的外部效度（external validity）问题，也叫可推广性 / 可外推性（generalizability）。随机对照试验（RCT）内部做得再严谨，它的受试者往往和真实世界里要用药的患者不一样（比如更年轻、合并症更少），所以"试验里有效"不等于"在目标人群里也有效"。

把试验结果迁移（transport）到目标人群，正是为了解决上述问题。医学语境下，它和"真实世界证据（RWE）""目标试验模拟（target trial emulation）"一脉相承：我们手里有试验数据（知道处理、结局、协变量），还有一批目标人群的代表性抽样（只知道协变量），想知道后者若接受处理会怎样。注意"迁移（transport）"与"可推广性（generalizability）"在文献里常混用，但严格说前者强调把已估计的效应搬到新人群，后者更泛指把任何结论外推；本篇二者含义一致。

问题设定

我们把总体记为第 \(i = 1 ... n\) 个个体。其中有一个子集 \(RCT\) 来自一次随机化（或观察性）试验/研究，对这部分我们拿得到完整数据：共有 \(n_{RCT}\) 条观测，包括基线协变量 \(X_i\)、二值处理指示 \(W_i=\{0, 1\}\) 以及结局 \(Y_i\)。此外我们还掌握剩下的子集 \(obs\)，对这部分只观察到了 \(n_{obs}\) 条基线协变量 \(X_i\)（且 \(n_{RCT} + n_{obs}=n\)）。我们将前一部分称为"参加了试验"，记为 \(S_i = 1\)；后一部分"没参加"，记为 \(S_i = 0\)。我们关心的是未参加者（即"目标"人群）中的平均处理效应，也就是：

\[E[Y(1) - Y(0) | S = 0],\]

其中 \(Y(1), Y(0)\) 是分别对应两种处理状态下的潜在结局（potential outcomes）。

一般而言，这个平均值并不等于试验参与者人群中的 ATE，即 \(E[Y(1) - Y(0) | S = 1]\)，因为处理效应的修饰因子（treatment effect modifiers）在参与者与未参与者中的分布可能不同。

下面的表格展示了这一设定：

人群 个体 S X Y W
试验人群 1 1 \(X_1\) \(Y_1\) \(W_1\)
试验人群 … 1
试验人群 \(n_{RCT}\) 1 \(X_{n_{RCT}}\) \(Y_{n_{RCT}}\) \(W_{n_{RCT}}\)
目标人群 \(n_{RCT}\) + 1 0 \(X_{n_{RCT}+1}\) ? ?
目标人群 … 0 ? ?
目标人群 \(n_{RCT} + n_{obs}\) 0 \(X_{n_{RCT}+n_{obs}}\) ? ?
背景与解释

为什么"平均"会骗人：处理效应异质性与目标人群加权。 上表目标人群那一栏的 Y 和 W 都是问号——我们既不知道他们接受处理后的结局，也没给他们施加处理。难点就在于：试验里测出的是"试验参与者的平均效应"，而目标人群里效应修饰因子的分布不同。比如某药对年轻人效果强、对老年人弱，而目标人群老年人更多，那么把试验的平均效应直接搬过去就会高估。

这正是异质性处理效应（heterogeneous treatment effect，HTE）的核心：效应不是常数，它随协变量 X 变化。GRF 的因果森林恰好能给出每个 X 处的条件平均处理效应（CATE） \(\tau(x)\)。迁移估计的本质，就是用目标人群的协变量分布 \(X_{test}\) 去对 \(\tau(x)\) 做加权（重新加权 / reweighting）求和——相当于把试验估计"按目标人群的样子"重新拼装一遍。后文的双稳健公式正是这种加权的一种稳健实现。

识别假设

在已经估计出 \(E[Y(1) - Y(0) | S = 1]\) 的前提下，要再去估计 \(E[Y(1) - Y(0) | S = 0]\)，除了观察性/随机化试验中因果推断的标准识别假设外，还需要两条额外假设：

  1. 关于 S 的条件可交换性（均值意义下）。在给定基线协变量后，潜在结局的均值与是否参加试验无关：\(E[Y(W) | X = x, S = 1] = E[Y(W) | X = x, S = 0]\)。

  2. 试验参与的正定性（positivity）。在用于保证可交换性的那些协变量条件下，参加试验的概率为正：\(P[S = 1 | X = x] > 0\)。

条件 1 被称为迁移条件（transport condition），它很重要，却无法从数据中检验。条件 2 本质上要求：目标人群中出现过的所有协变量组合，在试验人群中也都应当有样本；这一点可以通过查看 \(P[S = 1 | X = x] > 0\) 的估计值是否都大于 0 来大致判断。

背景与解释

两条假设分别"能不能检验"。 条件 1（迁移条件 / 条件可交换性）说的是：在协变量 X 相同的层内，参不参加试验的人，其潜在结局均值一样。换句话说，只要把 X 控制住，剩下的选择偏倚就没有了。这是整个方法的基石，但它是不可检验的——因为目标人群里我们根本没观测到他们的处理结局 Y，无法拿数据去验证。医学研究者做这类分析时，必须靠领域知识 + 敏感性分析来为它辩护（例如论证"试验排除标准不会造成效应异质性"）。

条件 2（正定性）相对友好：它要求目标人群里每一类协变量组合，试验人群里都至少有一例。如果某类人在试验里完全不存在（比如试验排除了重度肾损患者，而目标人群有），那这类人的效应就无从借力，公式里会出现除以接近 0 的情况。它可以部分检验——把试验参与概率 \(P[S=1\mid X=x]\) 拟合出来画直方图，若尾部出现极小的取值，就是正定性亮红灯的信号（见下文 Algorithm 末尾的提醒）。

估计量

先交代几个记号。 \(\hat \tau^{(-i)}(X_i)\) 是条件平均处理效应 \(E[Y_i(1) - Y_i(0) | X_i = x]\) 的估计值。 \(\hat p^{(-i)}(X_i)\) 是条件试验纳入概率 \(P[S = 1 | X_i = x]\) 的估计值。 \(\hat e^{(-i)}(X_i)\) 是处理倾向（propensity）\(E[W_i | X_i = x]\) 的估计值，而 \(\mu^{(-i)}(X_i, W_i)\) 是条件结局响应 \(E[Y_i | W_i = w, X_i = x]\) 的估计值。上标 (-i) 表示交叉拟合（cross-fitting），即第 \(i\) 个个体的估计值，在估计时并没有用到它自己。 \(n_{RCT}\) 是参加试验的个体数，\(n_{obs}\) 是目标人群中的个体数。

目标人群上 ATE 的一个双稳健估计量为：

\[\begin{equation} \begin{split} & \hat \tau_{target} = \frac{1}{n_{obs}} \sum_{i \in obs} \hat \tau^{(-i)}(X_i) + \\ & \frac{1}{n_{obs}} \sum_{i \in RCT} \left(\frac{1 - \hat p^{(-i)}(X_i)}{\hat p^{(-i)}(X_i)}\right) \left(\frac{W_i - \hat e^{(-i)}(X_i)}{\hat e^{(-i)}(X_i)(1-\hat e^{(-i)}(X_i))}\right) \left(Y_i - \hat \mu^{(-i)}(X_i, W_i) \right). \end{split} \end{equation}\]

这是 Dahabreh 等人（2020）中公式 (4) 的对照（contrast）形式写法。这个估计量所需的全部零件都能很方便地从 GRF 中得到。它与传统的"试验参与者内部"双稳健 ATE 估计量最大的区别，在于多出了迁移概率 \(\hat p^{(-i)}(X_i)\)，它以"胜率倒数"（inverse odds）的形式出现。其中的 \(\mu^{(-i)}(X_i, W_i)\) 可以由一个因果森林拟合得到，细节见这篇 vignette。我们同样可以用这套构造来估计标准误。一般来说，双稳健估计量对 nuisance 成分具有 oracle 性质（即"神谕性质"）：我们可以用代入式（plug-in）估计去替代真实值，仍保留某种一阶等价性，并直接算出这个表达式的方差（在这种情况下，方差会化简为两项独立分量之和）。

背景与解释

双稳健（doubly robust）与去偏 / 正交化到底强在哪。 这个估计量由两块相加而成：第一块只在目标人群上对各点的 CATE \(\hat\tau(X_i)\) 直接取平均（这要求 CATE 估计无偏）；第二块是一个"去偏修正项"，用试验数据把第一块的偏差扳回来。关键在于双稳健：只要下面两组模型中有一组估计正确——要么处理倾向 \(\hat e\) 与条件结局 \(\hat\mu\) 都对，要么 CATE 模型 \(\hat\tau\) 对——整体估计量就是一致的。错一个还有另一个兜底，所以比"只靠一个模型"稳健得多。

这种"用残差做修正、对 nuisance 误差只敏感一阶"的思路，在近年因果机器学习里叫正交化 / 去偏（orthogonalization / debiasing），也是 GRF 能做推断的理论底座（cross-fitting 上标 (-i) 就是为了切断过拟合带来的偏差而设计）。方差能化简成"两项独立分量之和"，意味着我们可以像普通均值方差那样直接给置信区间，无需复杂的 bootstrap。

实现算法

下面这个函数实现了上述估计量，它接受一个用二值处理训练好的普通因果森林（或因果生存森林）作为输入。

输入：

  1. forest：一个已训练好的因果森林。
  2. X.test：用于计算 ATE 的协变量矩阵 \(X\)。
  3. p.hat：可选项，试验参与个体对应的试验纳入概率 \(P[S = 1 | X = x]\) 的估计值。若不提供，则用一个回归森林（regression forest）来估计。

输出：测试集上 ATE 的双稳健估计值，以及对应的标准误。

average_treatment_effect_test <- function(forest, X.test, p.hat = NULL) {
  Y.hat <- forest$Y.hat
  Y.orig <- forest$Y.orig
  W.hat <- forest$W.hat
  W.orig <- forest$W.orig
  n.rct <- length(Y.orig)
  n.obs <- nrow(X.test)

  if (is.null(p.hat)) {
    S.forest <- regression_forest(X = rbind(forest$X.orig, X.test),
                                  Y = c(rep(1, n.rct), rep(0, n.obs)),
                                  num.trees = 500)
    p.hat <- predict(S.forest)$predictions[1:n.rct]
  }

  tau.hat.test <- predict(forest, X.test)$predictions
  tau.hat.train <- predict(forest)$predictions
  debiasing.weights <- (1 - p.hat) / p.hat * (W.orig - W.hat) / (W.hat * (1 - W.hat))
  Y.residual <- Y.orig - (Y.hat + tau.hat.train * (W.orig - W.hat))

  tau.hat <- mean(tau.hat.test) + sum(debiasing.weights * Y.residual) / n.obs
  sigma2.hat <- var(tau.hat.test) / n.obs + sum(Y.residual^2 * (debiasing.weights / n.obs)^2)

  c(estimate = tau.hat, std.err = sqrt(sigma2.hat))
}

注意，估计量里包含对迁移概率 \(\hat p^{(-i)}(X_i)\) 的除法，如果它太小就会出问题。一般建议把这些估计值画成直方图，借此判断是否存在正定性（positivity）问题。

一个示例

本节我们模拟一个简单的例子：处理效应修饰因子（\(X_1\)）在随机试验和目标人群中的分布不同（也就是说，试验的纳入概率依赖于某个效应修饰因子）。把模拟出的潜在结局画出来，两群人的分布大致如下：

蓝色分布是我们想求它的 ATE 的目标人群，红色分布是我们手头能用的 RCT。虚线表示各自的均值。下面我们从这套设定中抽取一个样本，然后估计目标人群的 ATE 并算出 95% 置信区间，同时把它和"朴素（naive）"做法——也就是直接在测试集上把预测值取平均——作比较。

n <- 2000
p <- 5
X.population <- matrix(rnorm(n * p), n, p)
trial.inclusion.prob <- 1 / (1 + exp(-X.population[, 1] / 2))
S <- rbinom(n, 1, trial.inclusion.prob)

X.test <- X.population[S == 0, ]

X <- X.population[S == 1, ]
W <- rbinom(nrow(X), 1, 0.5)
tau <- X[, 1] + 1
Y <- X[, 2] + tau * W + rnorm(nrow(X))

forest <- causal_forest(X, Y, W, W.hat = 0.5)
ate.test <- average_treatment_effect_test(forest, X.test)
estimate <- ate.test[1]
std.err <- ate.test[2]

sprintf("Estimate: %1.2f", estimate)
#> [1] "Estimate: 0.81"
sprintf("95%% CI: (%1.2f, %1.2f)", estimate - 1.96 * std.err, estimate + 1.96 * std.err)
#> [1] "95% CI: (0.66, 0.96)"
sprintf("Naive estimate: %1.2f", mean(predict(forest, X.test)$predictions))
#> [1] "Naive estimate: 0.87"
sprintf("True mean: %1.2f", mean(X.test[, 1] + 1))
#> [1] "True mean: 0.78"

附录：估计 E[Y | X.test]

如果我们只想要条件均值 \(E[Y | X_{test}]\) 的估计值，它也可以看作上面这套迁移流程的一个特例。不过还有一个更简单的做法：只用一个带"哑处理（dummy treatment）"指示的普通因果森林就能实现。记原始训练数据为 \((X_{train}, Y_{train})\)，新测试数据为 \(X_{test}\)。按如下方式用哑处理与哑响应变量 \((X, Y, W)\) 把数据拼接起来：\((X_{train}, Y_{train}, 1)\) 与 \(X_{test}, 0, 0)\)。然后，在这个拼接数据上拟合因果森林，其"对照组上的平均处理效应"（ATC，average treatment effect on controls）就会给出 \(E[Y | X_{test}]\) 的估计：因为我们"定义"了潜在结局 \(Y(1) = Y\) 且 \(Y(0) = 0\)，于是有 \(E[Y(1) - Y(0) | X_{test}] = E[Y | X_{test}]\)。

n <- 2000
p <- 5
X <- matrix(rnorm(n * p), n, p)
S.hat <- 1 / (1 + exp(-X[, 1] / 2))
S <- rbinom(n, 1, S.hat)
Y <- 1 + X[, 1] + X[, 2] + rnorm(n)

X.train <- X[S == 1, ]
Y.train <- Y[S == 1]
X.test <- X[S == 0, ]

X.aug <- rbind(X.train, X.test)
Y.aug <- c(Y.train, rep(0, nrow(X.test)))
W.aug <- c(rep(1, nrow(X.train)), rep(0, nrow(X.test)))
cf <- causal_forest(X.aug, Y.aug, W.aug, num.trees = 500)

ate <- average_treatment_effect(cf, target.sample = "control")
estimate <- ate[1]
std.err <- ate[2]

sprintf("Estimate: %1.2f", estimate)
#> [1] "Estimate: 0.74"
sprintf("95%% CI: (%1.2f, %1.2f)", estimate - 1.96 * std.err, estimate + 1.96 * std.err)
#> [1] "95% CI: (0.64, 0.85)"
sprintf("True mean: %1.2f",  mean(Y[S == 0]))
#> [1] "True mean: 0.79"
