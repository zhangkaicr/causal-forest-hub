策略学习：用最优决策树做处置分配

原文：Policy learning via optimal decision trees（英文） · grf 官方文档中文译本

library(grf)
library(policytree)

借助 GRF，我们可以非参数地估计一个条件平均处理效应（CATE）函数 \(\hat \tau(\cdot)\)，然后把它当作处置分配策略（policy）来用——比如，凡是预测值 \(\hat \tau(X_i)\) 为正的个体，就给他治疗。我们用符号 \(\pi\) 来表示这个策略：它是一个函数，输入是描述个体特征（协变量）的 \(X_i\)，输出是一个处置决策，其中 \(0\) 表示不治疗、\(1\) 表示治疗，即

\[ \pi(\cdot) \mapsto \{0, 1\} \]

如果直接用估计出来的 CATE 来分配治疗，我们可以把策略简单地写成 \(\pi(X_i) = 1(\hat \tau(X_i) > 0)\)。关于 Qini 曲线的文档（vignette）里给出了一些例子，介绍如何在留出测试集（held-out test set）上构造指标来评估这个策略，以及如何纳入预算约束。

背景与解释

什么是"策略学习"（Policy Learning）？估计 CATE 只是回答了"对谁有效、效应多大"的问题，而策略学习更进一步：它要直接学出一个分配规则 \(\pi\)，把每个个体的特征 \(X_i\) 映射成"治"或"不治"，目标是让整体福利（期望结局）最大化。最简单的"插件式"（plug-in）规则就是"预测效应为正就治"，即 \(\pi(X_i)=1(\hat\tau(X_i)>0)\)。但它有两个隐患：一是 CATE 估计本身有噪声，正负号可能判错；二是它只追求局部"谁该治"，未必是整个人群层面的全局最优分配。策略学习把"估计效应"和"做最优决策"拆开成两步——先用森林得到可靠的评分，再用树去学一个可解释、可落地的规则。这种"先估计、后决策"的框架在医学、政策评估中特别重要，因为最终要落到"给这个人开不开药"的具体动作上。

但在某些场景下，用这种方式分配治疗并不合适。举个例子：一项福利项目向人们提供职业培训技能。如果政策制定者希望项目资格有透明、可解释的标准，那么依据一个复杂的"黑箱"CATE 函数来筛选谁能参加，就很不理想。同样，如果申请人得知自己被拒之门外，仅仅因为某个黑箱算法预测他"获益不够多"，也会引发公平性质疑。在诸如此类的场景下，我们更想要可解释的策略（interpretable policy）。也就是说，我们希望得到一条简单的规则：看看个体的特征 \(X_i\)，就能给出治疗与否的决策。比如："Alice 被分配到治疗组，因为她不到 25 岁，且住在资源匮乏的社区"。像浅层决策树里内嵌的规则，就是这类可解释策略的一个例子。

背景与解释

个体化治疗规则（ITR）在临床中的意义。"个体化治疗规则"（Individualized Treatment Rule，ITR）指的是：不再对所有病人一刀切地用同一种方案，而是根据病人的基线特征，为每个人推荐最有利的治疗。它成立的前提是存在处理效应异质性（HTE）——也就是说，同一种药对不同亚组的效果确实不同。临床上这类需求很常见：肿瘤靶向治疗要看基因突变位点，降压药要看年龄和合并症，抗凝治疗要看出血风险评分。ITR 的价值在于把"平均有效"细化到"对这群人有效"。但要注意两点：一是只有效应真的异质时，个体化才值得做，否则反而增加复杂度、引入噪声；二是对临床医生而言，一条"若 A 且 B，则用方案 X"的浅规则，远比一个黑箱模型更容易被信任和采纳——这正是下文用浅层决策树、而非深度森林去做最终分配的原因。

基于树的治疗分配规则

要从实验数据或观测数据中学习出一个策略 \(\pi\)，我们需要一个高效的评分规则（scoring rule），以及一个搜索树的算法。GRF 所采用的方法是"双稳健"（doubly robust）评分，配合一棵以经验福利（empirical welfare）最大化为目标的决策树，这套做法由 policytree 包实现。要学到一棵"好"的浅层决策树，关键是在每一层都选对分支方式。常见的决策树学习方法（比如 CART）基于贪心准则，未必能学到全局最优的分支决策；而 policytree 包采用了计算量更大、但能找到全局最优决策树的建树方法。1

背景与解释

双稳健评分 + 为什么追求"全局最优"决策树？"双稳健"（doubly robust）评分的好处是：它把结局回归和倾向得分两部分结合在一起，只要其中之一建模正确，得到的评分就一致（consistent），比只依赖单一模型更稳健——这对观测数据尤为重要。把这层评分交给 GRF 去算，树只负责"怎么分群最划算"，目标函数就是经验福利（即各组预期结局的加权平均）。

那为什么不直接用大家熟悉的 CART？CART 在每一层只做"当前这一步看起来最好"的贪心分裂，容易陷入局部最优——上层一个当时不显眼、但为下层腾出空间的分裂点可能被错过。policytree 的做法是：在限定树深（如 depth = 2）的前提下，精确搜索所有可能的分裂组合，从而保证在"该深度下"达到全局最优。代价是计算量随深度指数增长，所以实际中通常只用很浅的树（深度 2–3），这也正符合"可解释"的初衷。

下面这个简短示例演示了如何用因果森林得到的双稳健评分，来学习一棵深度为 2 的树。其中的 policy_tree 和 double_robust_scores 两个函数都属于 policytree 包。

# 拟合一个因果森林（causal forest）。
n <- 15000
p <- 5
X <- round(matrix(rnorm(n * p), n, p), 2)
W <- rbinom(n, 1, 1 / (1 + exp(X[, 3])))
tau <- 1 / (1 + exp((X[, 1] + X[, 2]) / 2)) - 0.5
Y <- X[, 3] + W * tau + rnorm(n)
c.forest <- causal_forest(X, Y, W)

# 计算双稳健评分。
# （在观测性研究中，通常建议先画出估计的倾向得分
#   （`hist(c.forest$W.hat)`），以确认是否满足足够的重叠条件）
dr.scores <- double_robust_scores(c.forest)
head(dr.scores)
#>         control    treated
#> [1,] -0.1539377  0.5839477
#> [2,]  0.1551353  2.3079034
#> [3,] -0.5674259 -0.5864615
#> [4,]  0.6370039 -1.2796316
#> [5,]  2.0428953  0.5937339
#> [6,] -3.6164526 -0.2545393

# 在双稳健评分上拟合一棵深度为 2 的树。
tree <- policy_tree(X, dr.scores, depth = 2)

# 打印并绘制这棵树 —— 动作 1 对应对照组，2 对应治疗组。
print(tree)

#>     (6) * action: 2 
#>     (7) * action: 1
plot(tree)
背景与解释

policytree 包与 grf 的关系。policytree 与 grf 同出一门（都由 grf-labs 维护），但职责不同：grf 负责"估计"——它用广义随机森林给出每个个体的（双稳健）评分或 CATE；policytree 则负责"决策"——它接收一个评分矩阵（每行一个个体、每列一种处置臂的得分），去学一棵浅层、可解释、且在该深度下全局最优的策略树。二者是松耦合的：policytree 并不依赖 grf 内部实现，你完全可以用其它方法（例如其它因果机器学习模型）产出的评分喂给它。代码里 double_robust_scores(c.forest) 就是把因果森林的输出"翻译"成 policytree 能吃的格式——返回的两列 control / treated 分别对应"不治疗"和"治疗"两种臂的预期收益评分，树要做的，就是给每个叶子节点挑出分数更高的那一个臂作为动作。

下面这张图里的 45 度斜线，把效应为负的个体（线以上）和效应为正的个体（线以下）分隔开来。

# 预测每个样本的处置分配 {1, 2}。
predicted <- predict(tree, X)
plot(X[, 1], X[, 2], col = predicted)
legend("topright", c("control", "treat"), col = c(1, 2), pch = 19)
abline(0, -1, lty = 2)

此外，predict 还可以返回每个样本落入的叶节点（leaf node），我们可以据此为每一组计算一些统计量，比如平均处理效应（average treatment effect）。注意：为了避免过拟合，这类统计量应当在"留出测试集"上计算，且该测试集要与学习策略时用的数据分开；这样一来，它就成了对拟合策略做"训练集/测试集"评估的一种实用手段。

node.id <- predict(tree, X, type = "node.id")

# 每个叶节点下所有处置臂的取值（含标准误）。
values <- aggregate(dr.scores, by = list(leaf.node = node.id),
                    FUN = function(x) c(mean = mean(x), se = sd(x) / sqrt(length(x))))
print(values, digits = 2)
