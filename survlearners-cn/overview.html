survlearners：生存结局的 Meta-learner（R 包总览）

译自 som-shahlab.github.io/survlearners（R 包首页）｜作者：斯坦福医学院 SOM ShahLab｜许可：GPL-3｜本页为个人学习用途的非官方中文译本，引用请以英文原文为准

本仓库（R 包 survlearners）提供了五种主流 meta-learner 的扩展实现，用于生存结局的异质处理效应估计。Meta-learner 是一类特殊的元算法，它借助预测模型（例如机器学习模型）来完成"估计处理异质性（treatment heterogeneity）"这一因果任务。虽然 meta-learner（S-、T-、X-、M- 和 R-learner）原本是为无删失的连续或二分类数据开发的，survlearners 通过逆概率删失加权（inverse probability of censoring weighting, IPCW），并结合两种流行的机器学习策略（Lasso 与广义随机森林），给出了它们在生存设定下的改造实现。

🔍
背景与解释

这个包解决什么问题？临床试验与观察性研究中，"平均处理效应"往往不足以指导个体化决策：同一个治疗对 A 患者获益明显、对 B 患者可能无效甚至有害。异质处理效应（heterogeneous treatment effect, HTE）估计的目标就是刻画这种因人而异的效应——通常用条件平均处理效应 \(\tau(x)=\mathbb{E}[Y(1)-Y(0)\mid X=x]\) 表示。

当结局是生存时间（如总生存期、无进展生存期）时，问题变得棘手：一部分患者被删失，我们只知道他"到某个时点仍未发生事件"。survlearners 的答案是：把结局固定为"是否存活超过预设时点 \(t_0\)"，再用 IPCW 把删失带来的选择性损失校正回来，从而让原本面向连续/二分类结局的 meta-learner 可以直接套用。

关于这些 meta-learner 的数学原理教程，请参阅《Handbook of Matching and Weighting Adjustments for Causal Inference》中题为 Treatment heterogeneity for survival outcomes（生存结局的处理异质性） 的一章。此外，该章还包含一个基准比较研究：通过全面的模拟研究评估数据生成过程中若干重要因素对估计性能的影响，这些因素包括① 基线风险函数的复杂程度、② CATE 函数的复杂程度、③ 处理效应异质性的大小、④ 删失机制、⑤ 治疗组与对照组的不平衡程度。这些关于如何选择与应用 meta-learner 及机器学习模型进行 HTE 估计的总结性建议与注意事项，已被整合进 survlearners 包中。

背景与解释

这五个"影响因素"为什么重要？它们是判断某种方法在你的数据上会不会失效的检查清单：

① 基线风险函数复杂度——低风险人群的绝对获益天然更小，若基线风险随协变量高度非线性变化，线性/Cox 类模型容易误设；② CATE 函数复杂度——若真实效应只是少数几个协变量的简单函数，Lasso 这类稀疏方法占优；若效应是复杂交互，森林类更合适；③ 异质性的量级——真实异质性很弱时，所有方法都会把估计收缩到 0，此时解释个体化估计要格外谨慎；④ 删失机制——删失是否与预后相关、删失率高低，直接决定 IPCW 权重的稳定性；⑤ 组间不平衡——治疗组人数很少时，T-learner 的对照侧模型会不稳定，而 X/R-learner 会自动给少数组更大权重。

安装

当前版本的 survlearners 可以从源码安装，使用 remotes 包：

remotes::install_github("som-shahlab/survlearners", subdir = "r-package/survlearners")
背景与解释

安装说明。该包尚未发布到 CRAN，因此要用 remotes::install_github() 从 GitHub 安装，且需指定 subdir（包源码位于仓库的 r-package/survlearners 子目录）。安装前需要确保本机的 R 工具链可用（Windows 上为 Rtools，macOS 上为 Xcode command line tools），因为包内含需要编译的 C++/Fortran 依赖。

它依赖的几个关键 R 包是：glmnet（Lasso Cox 模型）、grf（广义随机森林、随机生存森林与因果森林）、survival（生存分析基础函数与 KM 估计）。因此安装时间可能较长；若只需要画图，ggplot2 需另外加载。

用法示例

下面的脚本演示如何应用 R-learner（配合随机生存森林与 Lasso）来估计绝对差异尺度上的异质处理效应，即中位随访时间处的生存概率之差。若需要其他类型 meta-learner 的示例，请参阅 R 函数文档。

library(survlearners)

# 生成模拟数据
n <- 1000; p <- 25
t0 <- 0.2
Y.max <- 2
X <- matrix(rnorm(n * p), n, p)
W <- rbinom(n, 1, 0.5)
numeratorT <- -log(runif(n))
T <- (numeratorT / exp(1 * X[ ,1, drop = FALSE] + (-0.5 - 1 * X[ ,2, drop = FALSE]) * W)) ^ 2
failure.time <- pmin(T, Y.max)
numeratorC <- -log(runif(n))
censor.time <- (numeratorC / (4 ^ 2)) ^ (1 / 2)
Y <- pmin(failure.time, censor.time)
D <- as.integer(failure.time <= censor.time)
n.test <- 500
X.test <- matrix(rnorm(n.test * p), n.test, p)

# 条件平均处理效应（CATE）
# 用 R-learner 训练 CATE 模型：随机生存森林（RSF）+ Lasso
# RSF 用于估计干扰参数，例如平均结局与删失权重
# Lasso 用于估计目标参数 CATE
fit <- surv_rl_grf_lasso(X, Y, W, D, t0, W.hat = 0.5, cen.fit = "survival.forest")

# 估计测试样本的条件平均处理效应
cate <- predict(fit, X.test)
背景与解释

这段示例代码在做什么？① 先模拟 1000 例"患者"、25 个协变量，随机分配治疗（W），并生成生存时间与删失时间，得到观测随访时间 Y 与事件指示 D；② 调用 surv_rl_grf_lasso() 训练 R-learner：用随机生存森林（cen.fit = "survival.forest"）估计干扰参数（平均结局、删失权重），用 Lasso 估计目标参数 CATE；③ 用 predict() 对 500 例新患者给出个体化的 CATE 预测。

几个关键参数：t0 是关注的时点（本例 0.2，实际分析中常取中位随访时间或有临床意义的时间点，如 1 年、5 年）；W.hat 传入倾向得分——随机对照试验中它是已知的随机化概率（本例 0.5），观察性研究中则需要先用协变量估计出来；cen.fit 指定删失模型的估计方式（"KM" 适用于完全独立删失，"survival.forest" 允许删失依赖于协变量与治疗）。

背景与解释

结果如何解读？cate 向量的每个元素是一位测试集患者"接受治疗 vs. 不接受治疗"在 \(t_0\) 时刻生存概率之差的点估计：正值表示该患者从治疗中获益（活过 \(t_0\) 的概率提高），负值表示受损。数值范围在 \([-1,1]\) 内，例如 0.10 表示"活过该时点的概率提高 10 个百分点"。

这是绝对尺度的效应，可直接用于"值不值得治"的决策与"治疗获益人数"的测算；它不同于风险比 HR。在应用分析中，建议先报告 CATE 的分布与排序分组后的平均效应，再解释极端个体，避免对单个高维预测过度解读。
