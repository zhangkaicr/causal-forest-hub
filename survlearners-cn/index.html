survlearners 中文译本：生存结局的异质处理效应估计

R 包 survlearners 官方教程的非官方中文译本｜原文：som-shahlab.github.io/survlearners｜作者：斯坦福医学院 SOM ShahLab｜许可：GPL-3｜引用请以英文原文为准

一句话定位：survlearners 解决的是这样一个问题——当结局是生存时间、且存在右删失时，如何用机器学习估计因人而异的治疗效应：它把五种主流 meta-learner（S-、T-、X-、R-、M-learner）通过逆概率删失加权改造到生存数据上，估计"活过某个预设时点 \(t_0\) 的概率之差"这一绝对尺度的条件平均处理效应（CATE）。

背景与解释

先搞清楚我们要估计的量是什么。本译本中的 CATE 一律定义在绝对尺度上：\[\tau(x)=\mathbb{E}[Y_i(1)-Y_i(0)\mid X_i=x],\qquad Y_i(w)=\mathbb{1}\{T_i(w)>t_0\},\] 即"特征为 \(x\) 的患者，若接受治疗 vs. 不接受治疗，活过 \(t_0\) 的概率之差"。取值在 \([-1,1]\)，例如 0.10 表示"活过该时点的概率提高 10 个百分点"。

这与临床上熟悉的 Cox 风险比 HR \(\mathrm{HR}=h_1(t)/h_0(t)\) 不是一回事：HR 是相对尺度且依赖比例风险假设；绝对差（以及另一常用指标 RMST 之差，\(\mathrm{RMST}(t_0)=\int_0^{t_0}S(u)\,du\)）在比例风险不成立时依然可解释，也更适合回答"这个患者值不值得治"、"每治疗 100 人能多救几个人"这类问题。

术语对照（英文 → 中文）

英文术语中文译名简要说明
metalearner（S-/T-/X-/R-/M-learner）元学习器一套"把因果问题拆成若干预测问题"的元算法，不是具体模型；可搭配任意机器学习预测器。
survival outcome生存结局以"发生事件的时间"为结局（死亡、复发、进展等），通常伴随删失。
censoring / right censoring删失 / 右删失只知道真实事件时间"晚于某时点"，而不知道确切时间（失访、研究结束时仍存活/未进展）。
complete case完整病例在 \(t_0\) 前已发生事件，或随访到 \(t_0\) 仍未发生事件、因而 \(Y_i\) 可确定的受试者。
IPCW（inverse probability of censoring weighting）逆概率删失加权用 \(\hat K_i=1/\hat S^C(\min\{U_i,t_0\},X_i,W_i)\) 为完整病例加权，使其能代表被删失的同类患者，从而消除删失偏倚。
IPW（inverse propensity weighting）逆概率（治疗）加权用倾向得分的倒数加权以平衡协变量；M-learner 的伪结局即基于此（Horvitz–Thompson 变换）。
RMST（restricted mean survival time）限制平均生存时间\(\mathbb{E}[\min(T,t_0)]\)，即生存曲线下 0 到 \(t_0\) 的面积；其组间差值是不依赖比例风险假设的绝对效应指标。
CATE（conditional average treatment effect）条件平均处理效应给定协变量 \(X=x\) 时的平均处理效应 \(\tau(x)\)，即"个体化/亚组效应"的估计目标。
HTE（heterogeneous treatment effect）/ treatment heterogeneity异质处理效应 / 处理异质性治疗效应随个体特征而变的现象；CATE 随 \(x\) 变化即存在异质性。
potential outcome潜在结局同一个体在接受（\(T_i(1)\)）与不接受（\(T_i(0)\)）治疗下的两种假想结局，实际最多只能观测到一个。
propensity score \(e(x)\)倾向得分给定协变量下接受治疗的概率 \(\mathbb{P}[W_i=1\mid X_i=x]\)；RCT 中为已知的随机化概率。
overlap / positivity重叠性 / 正性要求 \(\eta\le e(x)\le 1-\eta\)：每种特征的患者都有机会被分到任一处理组，否则该处效应不可识别。
nuisance parameter干扰（ nuisance）参数为目标参数服务、但本身不是研究对象的中间量，如结局模型 \(m(x)\)、倾向得分、删失分布。
cross-fitting / out-of-bag estimation交叉拟合 / 袋外估计估计第 \(i\) 个人的干扰参数时不使用其自身数据，避免机器学习过拟合，是 CATE 有效推断的前提。
SuperLearner / ensemble超级学习器 / 集成学习把多个候选预测模型（含 Lasso、森林等）按交叉验证表现加权集成；本包中对应的是 Lasso 与随机生存森林两种候选。
Lasso（Cox-Lasso）Lasso（惩罚回归）\(L_1\) 惩罚的（Cox）回归，可做变量选择，适合高维、效应稀疏、需要可解释性的场景。
random survival forest / generalized random forest随机生存森林 / 广义随机森林基于树集成的非参数方法，可处理删失并刻画复杂非线性与交互（grf 包实现）。
causal forest / causal survival forest因果森林 / 因果生存森林直接以 CATE 为目标函数的森林方法（R-learner 家族），生存版采用双重稳健删失校正。
shrinkage / regularization-induced bias收缩 / 正则化诱导偏倚惩罚类模型把估计向 0 收缩，或两组模型惩罚不一致导致差值有偏，表现为估计值系统性偏小。
doubly robust双重稳健只要结局模型与（删失/治疗）模型之一正确，估计即一致的一类校正方法。
Kaplan–Meier estimatorKM 估计量生存函数的非参数估计；本包中用于在"完全独立删失"假定下估计删失分布 \(S^C\)。
背景与解释

SuperLearner 与"两种机器学习策略"的关系。原文提到 survlearners 把 meta-learner 与"两种流行的机器学习策略（Lasso 与广义随机森林）"结合。这里的思路与因果推断中常用的 SuperLearner（超级学习器）一致：先用交叉验证比较多个候选预测器的表现，再据其加权集成，从而降低"选错单一模型"的风险。本包没有内置 SuperLearner 集成，而是把选择权交给使用者：每种 meta-learner 都提供 _lasso、_grf、_grf_lasso 三种实现，实践中可比照交叉验证误差挑选，或直接用混合版（森林估干扰参数 + Lasso 估 CATE）。

背景与解释

为什么生存数据不能直接套用普通 CATE 方法？两个障碍叠加：① 删失——被删失者的 \(Y_i\) 未知，只能用 \((U_i,\Delta_i)\)，直接把随访时间 \(U_i\) 当连续结局回归会把"还没发生事件"误当成"结局很小"，产生偏倚；② 因果推断的根本问题——每个个体最多只能观测到一个潜在结局，因此"个体效应" \(Y_i(1)-Y_i(0)\) 永远无法直接计算。

survlearners 的两个补丁分别是：用 IPCW 解决删失（把完整病例加权后代表全人群），用 meta-learner 的伪结局（M 的 IPW 变换、X 的交叉差、R 的残差比）解决潜在结局缺失。理解这两步，整套方法就通了。

背景与解释

五种 meta-learner 怎么选（速查）。S-learner：一个模型、把治疗当普通协变量，最简但易把 CATE 压向 0；T-learner：分两组各建模型，灵活但每组只用一半样本，组间悬殊时不稳定，且两个模型的惩罚不一致会带来正则化偏倚；M-learner：直接用 IPW 伪结局对 CATE 建模，最简单但方差大（\(e\) 接近 0 时尤甚）；X-learner：交叉相减 + 按组间比例加权合并，组间不平衡时表现好；R-learner：对 \(W\) 与 \(Y\) 双残差化，对干扰参数误设稳健（正交性），通常是最稳妥的默认选择。

预测器怎么选：协变量多而效应稀疏、需要可解释性 → Lasso；基线风险或 CATE 高度非线性 → 随机生存森林/因果森林；不确定 → 用 _grf_lasso 混合版，或按交叉验证误差比较。

背景与解释

报告结果时的注意事项。① 报告删失比例、\(t_0\) 处仍在风险集的人数，以及 IPCW 权重的分布（有无极端值）；② 观察性研究报告倾向得分的重叠性（overlap 图）与协变量平衡；③ 不要只报"最优/最差"个体的估计，应先报告 CATE 分布与排序分组后的平均效应，并用整体异质性检验确认异质性确实存在；④ 记住惩罚类方法会把估计向 0 收缩——散点图中点云比 \(y=x\) 参考线更"平"，通常意味着低估了真实的效应异质性。
