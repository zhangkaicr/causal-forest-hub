《用 Caret / SuperLearner 做样本分割》

原文：Sample Splitting with Caret/SuperLearner（英文） · evalITR 官方文档中文译本

用 Caret 训练模型

我们可以用 caret 包来训练模型（关于 caret 的更多介绍，请参阅其官网）。为了加快计算速度，这里采用了并行计算。

背景与解释

什么是 caret？ caret（Classification And REgression Training）是 R 里一个统一的机器学习"训练框架"，它把梯度提升、随机森林、lasso 等上百种算法封装成一致的接口，并统一管理交叉验证、超参数调优与并行计算。对 ITR 来说，我们并不拘泥于具体用哪种算法，而是希望借助灵活的机器学习去拟合"谁该接受治疗"的规则；caret 让我们只需换一个算法名就能切换模型。并行计算（doParallel）则能显著缩短调参耗时——调参往往要在多组超参数上反复做交叉验证，非常消耗算力。

# 并行计算
library(doParallel)
cl <- makePSOCKcluster(5)
registerDoParallel(cl)

# 计算结束后关闭集群
stopCluster(cl)

下面的例子展示了如何用 caret 包配合梯度提升机（gradient boosting machine, GBM）来估计 ITR。请注意，我们已经加载了数据，并按照《样本分割（Sample Splitting）》中的方式指定了处理变量、结局变量和协变量。由于我们使用的是 caret 包，因此需要指定 trainControl 和/或 tuneGrid 参数：trainControl 用于设定交叉验证的方式，tuneGrid 用于设定调参网格。关于这些参数的更多细节，请参阅 caret 官网。

在这个例子里，我们只用一种机器学习算法（GBM）来估计 ITR，并用 evaluate_itr() 函数对 ITR 做评估。若要计算 PAPDp，则需要把 algorithms 参数指定为包含 2 个以上机器学习算法的向量。

library(evalITR)
library(caret)

# 设定 trainControl 方法
fitControl <- caret::trainControl(
  method = "repeatedcv", # 3 折交叉验证
  number = 3, # 重复 3 次
  repeats = 3,
  search='grid',
  allowParallel = TRUE) # 网格搜索

# 设定调参网格
gbmGrid <- expand.grid(
  interaction.depth = c(1, 5, 9), 
  n.trees = (1:30)*50, 
  shrinkage = 0.1,
  n.minobsinnode = 20)

# 估计 ITR
fit_caret <- estimate_itr(
  treatment = "treatment",
  form = user_formula,
  trControl = fitControl,
  data = star_data,
  algorithms = c("gbm"),
  budget = 0.2,
  split_ratio = 0.7,
  tuneGrid = gbmGrid,
  verbose = FALSE)
#> 在样本分割下评估 ITR ...

# 评估 ITR
est_caret <- evaluate_itr(fit_caret)
#> 无法计算 PAPDp
背景与解释

样本分割如何与 caret 自带的 cross-validation 配合？ 这里有两层"切分"容易混淆。第一层是 evalITR 的样本分割（split_ratio = 0.7）：把数据分成训练集和测试集，用训练集学习规则、用测试集无偏地评估——避免用同一批数据既训练又打分导致的过拟合。第二层是 caret 在训练集内部用 trainControl 做的重复 K 折交叉验证，目的是给 GBM 挑选最优超参数（如树深度、迭代次数）。两者分工明确：交叉验证用于"调参"，样本分割用于"评估"。这正是因果推断里保证 ITR 评估无偏的关键设计。

我们可以从 caret 中提取训练好的模型，并查看其表现。其他 caret 函数也可以直接作用在这个训练模型上。

# 提取最终模型
caret_model <- fit_caret$estimates$models$gbm
print(caret_model$finalModel)
#> 一个采用高斯损失函数的梯度提升模型。
#> 模型共执行了 100 次迭代。
#> 共有 53 个预测变量，其中 24 个具有非零影响。

# 查看模型表现
trellis.par.set(caretTheme()) # 主题
plot(caret_model) 

# 热力图
plot(
  caret_model, 
  plotType = "level",
  scales = list(x = list(rot = 90)))

用 SuperLearner 训练模型

另外，我们也可以用 SuperLearner 包来训练模型（关于 SuperLearner 的更多介绍，请参阅其官网）。SuperLearner 采用集成（ensemble）方法，通过对多种机器学习算法取最优加权平均来提升模型表现。

背景与解释

什么是 SuperLearner（集成学习）？ SuperLearner 是一种集成（ensemble）方法：它不依赖单一算法，而是同时训练多个"基学习器"（这里用 SL.library 指定，如 SL.ranger 随机森林、SL.glmnet 弹性网络），再对这些算法的预测做"最优加权平均"，权重由交叉验证自动决定。直觉上，没有哪种算法永远最好，集成能取长补短、降低方差，通常比单个模型更稳健。在 ITR 场景里，治疗效应的异质性往往很强，集成学习能更可靠地捕捉"不同人需要不同治疗"的模式，因此常被用作估计 ITR 的默认选择。

我们将比较用 causal_forest 与 SuperLearner 估计得到的 ITR 的表现。

library(SuperLearner)

fit_sl <- estimate_itr(
  treatment = "treatment",
  form = user_formula,
  data = star_data,
  algorithms = c("causal_forest","SuperLearner"),
  budget = 0.2,
  split_ratio = 0.7,
  SL_library = c("SL.ranger", "SL.glmnet"))
#> 在样本分割下评估 ITR ...

est_sl <- evaluate_itr(fit_sl)

# 汇总估计结果
summary(est_sl)

背景与解释

怎么读这份汇总结果？ summary() 把几种核心指标并列列出，方便横向比较。PAPE/PAPEp 给出采用 ITR 的总体（带预算约束）平均获益，AUPEC 衡量在不同预算下获益的累积曲线（类似 uplift/Qini 曲线下面积），GATE 则按协变量把人群分成若干组、观察各组的处理效应。值得留意的是 PAPDp（处方效应差异）：当 algorithms 指定了多个算法时，它会直接比较两套 ITR 谁的获益更高——这里就是 causal_forest 与 SuperLearner 的差异。若只放一种算法（如前面只用 GBM），工具会提示 "Cannot compute PAPDp"，这正对应了前文"至少 2 个算法才能算 PAPDp"的说明。

我们绘制了写作得分（writing score）的估计处方效应曲线下面积（AUPEC），针对不同的预算约束取值分别展示，并把用 causal_forest 与 SuperLearner 估计得到的两个 ITR 分开画了出来。

# 绘制 AUPEC
plot(est_sl)
