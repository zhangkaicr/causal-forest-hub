安装 evalITR

原文：Installation（英文） · evalITR 官方文档中文译本

安装

你可以从 CRAN 安装 evalITR 的发布版本，命令如下：

# 从 CRAN 安装发布版本（更新 evalITR 也用这条命令）
install.packages("evalITR")
背景与解释

在 R 里安装包主要有两条渠道。CRAN（Comprehensive R Archive Network，R 综合典藏网）是官方包仓库，里面托管的是经过审核、带版本号的稳定发布版；用 install.packages("evalITR") 安装的就是它，并且日后要升级到新发布版，同样还是这条命令，无需记忆别的写法。CRAN 上的包对普通 Windows / macOS / Linux 用户最省心——依赖会自动一并装好。对医学研究者来说，日常分析优先用 CRAN 发布版最稳妥，可复现性也最好。

或者，你也可以从 GitHub 安装 evalITR 的开发版本，命令如下：

# 若尚未安装 devtools，请先运行：install.packages("devtools")
devtools::install_github("MichaelLLi/evalITR", ref = "causal-ml")
背景与解释

为什么要从 GitHub 装开发版？ 开发版（development version）是托管在 GitHub 上的最新源码，往往比 CRAN 发布版更早包含新功能、新算法或 bug 修复，但也可能还没经过充分测试。命令里的 ref = "causal-ml" 指定了要安装的具体分支（branch）名；evalITR 的因果机器学习相关更新就放在 causal-ml 这个分支上。装开发版需要用到 devtools 包（它本身也要先从 CRAN 安装）；如果你的电脑还没装，就先运行那条被注释掉的 install.packages("devtools")。注意：开发版更新频繁，做正式论文分析前最好确认所用的版本是可复现的。

如果你想使用包的最新版本，可以通过在 devtools::install_github 中指定分支名来安装 evalITR 的开发版本。

并行计算

（可选）如果你有多核处理器，我们建议使用 multisession futures 进行并行计算。这样可以提升计算效率，缩短模型拟合所需的时间。

library(furrr)
library(future.apply)

# 查看可用的 CPU 核心数
parallel::detectCores()

# 设置要使用的核心数
nworkers <- 4
plan(multisession, workers =nworkers)
背景与解释

并行计算与依赖包的作用。 评估个体化治疗规则（ITR）时通常要做样本分割（sample splitting）与交叉验证，要把模型在多个数据折（fold）上反复拟合，计算量比普通回归大得多，因此用多核并行能明显提速。上面这段用到的 furrr 和 future.apply 就是负责并行调度的依赖包：future.apply 提供底层的"未来（future）"执行框架，furrr 在其之上把 purrr 风格的映射函数并行化；plan(multisession, workers = nworkers) 则是告诉 R「开多个独立的 R 进程（multisession）来并行跑，用 nworkers 个核心」。先用 parallel::detectCores() 看机器有几核，再把 nworkers 设成合适的数值（一般留一两个核给系统，别占满全部核心）。这一步是可选的——不配置也能跑，只是会更慢。
