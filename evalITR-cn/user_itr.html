《用户自定义个体化治疗规则（ITR）》

原文：User Defined ITR（英文） · evalITR 官方文档中文译本

如果不使用由 evalITR 模型估计得到的 ITR，我们也可以自己定义一套个体化治疗规则（ITR），并用 evaluate_itr 函数评估它的表现。该函数接受以下参数：

背景与解释

在 evalITR 里，ITR 通常有两种来源。一种是「数据驱动的估计 ITR」：你用 estimate_itr() 等函数，让机器学习模型从数据中「学」出一套分配规则（例如用 SuperLearner、因果森林去拟合「谁更可能从治疗中获益」）。另一种就是本篇讲的「用户自定义 ITR」：规则不是模型学出来的，而是研究者自己手写一个函数——比如「城市学校给 0.3 分、乡村学校给 0.4 分」，分数高低代表该单元更该被治疗。后者常见于：检验某个现成的临床规则好不好、做敏感性分析，或作为基线（baseline）与数据驱动的规则做对比。两者最终都用 evaluate_itr() 评估，区别只在于规则的来源不同。

参数 说明
user_itr 由用户自定义的函数，返回用于决定治疗分配的「个体层面（unit-level）连续分值」。我们约定：分值小于 0 的个体不给予治疗。
data 一个数据框。
treatment 一个字符串，指定 data 中的处理变量。
outcome 一个字符串，指定 data 中的结局变量。
budget 一个数值，指定在预算约束下最多可以接受治疗的人群比例上限。
背景与解释

这里的关键是 user_itr 函数返回的是个体层面（unit-level）的连续分值，而不是简单的「是/否」二分。约定很朴素：函数给每个样本算出一个分数，分数 ≥ 0 的个体被建议给予治疗，分数 < 0 的个体不给予治疗。所以你写规则时，只要在「该治」的人群上返回正值、在「不该治」的人群上返回负值（或零）即可。上例用 case_when() 给不同学校类型赋 0.1~0.4 的正分，意味着所有学校类型都会被治疗——如果你想「不治疗」某一类人，就在对应分支返回负数。

函数会返回一个对象，其中包含该用户自定义 ITR 的估计结果：GATE（分组平均处理效应）、ATE（总体平均处理效应）与 AUPEC（处方效应曲线下面积）。

# 用户自定义的 ITR
score_function <- function(data){

  data %>% 
    mutate(score = case_when(
      school_urban == 1 ~ 0.1, # 市中心
      school_urban == 2 ~ 0.2, # 郊区
      school_urban == 3 ~ 0.4, # 乡村
      school_urban == 4 ~ 0.3, # 城市
    )) %>%
    pull(score) -> score
    
  return(score)
}

# 评估 ITR
user_itr <- evaluate_itr(
  user_itr = score_function,
  data = star_data,
  treatment = treatment,
  outcome = outcomes,
  budget = 0.2)

# 汇总估计结果
summary(user_itr)

背景与解释

evaluate_itr() 返回的对象里装着四类核心评估结果：GATE（分组平均处理效应，按规则分出的若干组分别看处理效应）、ATE（总体平均处理效应），以及 AUPEC（处方效应曲线下面积）。示例中 summary() 打印的 PAPE、PAPEp、PAPDp 分别是「无预算约束下的总体平均处方效应」及其带预算约束（p）的版本。注意示例输出里 PAPE 估计为 0、PAPDp「无法计算」——这是因为本例没有设定对照规则，属正常现象，不必惊慌；重点看 GATE 各行（不同组效应正负不一）和 AUPEC：估计为 -0.91、p 值 0.028（在 0.05 水平上显著为负），说明这条手写规则的整体处方效应显著低于「不分配」的基线，即该规则反而让总体变得更差。

我们可以从 est 对象中提取估计结果。下面的代码演示了如何用因果森林（causal forest）算法提取写作分数（writing score）对应的 GATE 估计值。我们还可以用 plot_estimate() 函数将估计结果绘图，并通过参数指定要绘制的估计类型（GATE、PAPE、PAPEp、PAPDp）。

# 绘制 GATE 估计图
library(ggplot2)
gate_est <- summary(user_itr)$GATE

plot_estimate(gate_est, type = "GATE") +
  scale_color_manual(values = c("#0072B2", "#D55E00"))

我们绘制了用户自定义 ITR 在一系列预算约束下，写作分数（writing score）对应的处方效应曲线下面积（AUPEC）估计值。

背景与解释

plot(user_itr) 画出的是 AUPEC 随预算约束变化的曲线：横轴是「最多能治疗的人群比例」（budget，0~1），纵轴是对应预算下处方效应曲线下面积。曲线越往左上越好——在更少资源（更小预算）下取得更大的总体获益。它让你直观比较「如果只有 20% 的资源（如本例 budget=0.2），按这条规则治疗，比随机治疗好多少」。这在医疗资源有限、只能覆盖部分患者的真实临床场景中尤其有用。
