样本分割（Sample Splitting）

原文：Sample Splitting（英文） · evalITR 官方文档中文译本

本文通过一个真实的教育数据集（STAR 小班教学研究），演示如何用 evalITR 包在样本分割框架下估计并评估一条个体化治疗规则（ITR）。核心要点：训练模型用一批数据，评估效果必须用另一批相互独立的测试数据——否则估计出的"获益"会明显偏乐观。

本例使用 star 数据集（如需了解该数据集的更多信息，请输入 ?star 查看帮助文档）。

我们先从一个简单的例子入手：只使用一个结局变量（写作成绩）和一种机器学习算法（因果森林，causal forest）。之后会进一步纳入多个结局变量，并用多种机器学习算法比较模型表现。

首先，我们载入数据，并指定模型要用到的结局变量和协变量。接着，我们使用随机森林算法来构建一个个体化治疗规则（Individualized Treatment Rule, ITR），用于估计"小班额"对学生写作成绩产生的异质性影响。由于干预措施在大多数政策项目中往往成本不菲，我们考虑一个带 20% 预算约束的情形（budget = 0.2）——模型会挑出最可能从干预中获益的前 20% 个体，并将干预分配给他们。我们通过样本分割（sample splitting）来训练模型，训练集与测试集之间的划分比例由 split_ratio 参数决定。具体地，我们把 70% 的数据用于训练模型，其余 30% 作为测试数据（split_ratio = 0.7）。

背景与解释

什么是样本分割？样本分割（sample splitting）就是"把数据一分为二"：一部分用来训练模型（拟合出那条个体化治疗规则），另一部分（测试集）留作评估模型在"没见过的数据"上的表现。本文用 split_ratio = 0.7，即 70% 训练、30% 测试。

这和医学里的"训练集 / 验证集"是同一个思想。临床预测模型研究中，医生们很早就明白：用同一批病人既建模又检验，得出的判别能力（如 AUC）会被严重高估。正确做法是把病人随机拆成两批——一批用来开发模型，另一批（验证集）用来检验。evalITR 里的样本分割，就是把这条流行病学/临床变量筛选的"训练–验证"思路，原样搬到了个体化治疗规则的评估上。本文的 70/30 划分只是示例，实际比例（如 50/50 或 80/20）可根据样本量灵活调整。

library(dplyr)
library(evalITR)

# 指定结局变量
outcomes <- "g3tlangss"

# 指定处理变量
treatment <- "treatment"

# 指定数据（剔除其他结局变量）
star_data <- star %>% dplyr::select(-c(g3treadss,g3tmathss))

# 指定模型公式
user_formula <- as.formula(
  "g3tlangss ~ treatment + gender + race + birthmonth + 
  birthyear + SCHLURBN + GRDRANGE + GKENRMNT + GKFRLNCH + 
  GKBUSED + GKWHITE ")


# 估计 ITR
fit <- estimate_itr(
  treatment = treatment,
  form = user_formula,
  data = star_data,
  algorithms = c("causal_forest"),
  budget = 0.2,
  split_ratio = 0.7)
#> 在样本分割下评估 ITR ...


# 评估 ITR
est <- evaluate_itr(fit)
#> 无法计算 PAPDp

summary() 函数会输出以下汇总统计量：

统计量 说明
PAPE 总体平均处方效应（population average prescriptive effect）
PAPEp 带预算约束的总体平均处方效应（population average prescriptive effect with a budget constraint）
PAPDp 带预算约束的总体平均处方效应差异（population average prescriptive effect difference with a budget constraint，该指标在使用超过 2 种机器学习算法时才会被计算）
AUPEC 处方效应曲线下面积（area under the prescriptive effect curve）
GATE 分组平均处理效应（grouped average treatment effects）

关于这些评估指标的更多细节，请参阅 Imai and Li (2021) 与 Imai and Li (2022)。

背景与解释

为什么必须把"训练模型"和"评估效果"分成两批数据？——乐观偏差与过拟合。

机器学习模型（如因果森林）会不遗余力地"记住"训练数据里的噪声和偶然规律，这叫过拟合（overfitting）。如果用训练集本身去打分，模型对自己的"作品"当然给出高分——这种"自己考自己"导致的系统性高估，称为乐观偏差（optimism bias）。

对个体化治疗规则（ITR）而言，这个问题尤其要命：ITR 的目的是把治疗精准分配给"真正获益"的人。如果评估偏乐观，研究者会误以为一条糟糕的规则能带来巨大总体获益，进而把它用进临床或政策，造成资源浪费甚至伤害。evalITR 的 estimate_itr() 只在训练集上拟合规则，evaluate_itr() 则只在那 30% 的测试集上"盲测"——这样得到的 PAPE、AUPEC 等指标才是对真实推广效果（样本外表现）的无偏估计。简言之：训练集负责"学规矩"，测试集负责"判成绩"，两者绝不能混用。

背景与解释

样本分割与交叉验证（cross-validation）是什么关系？

本文用的是单次样本分割（70/30 一刀两断），简单直观，但有两个小缺点：测试集只有 30%，估计的方差较大；而且"哪 30% 被抽中"会影响结果，结论对随机种子有点敏感。

交叉验证可以看作样本分割的"加强版"：把数据切成 K 折，轮流用其中 K−1 折训练、剩下 1 折测试，重复 K 次后取平均。这样既用上了全部数据做评估、降低方差，又减弱了对某次随机划分的依赖。evalITR 同样支持用交叉验证来估计与评估 ITR——本质上仍是"训练 / 评估必须分离"这条铁律，只是把"分一次"升级成了"分多次、轮流盲测"。本文先用最简单的单次分割把原理讲清楚，再扩展到交叉验证水到渠成。

背景与解释

在医学 / 流行病学研究中，这套思路意味着什么？

个体化治疗规则（ITR）的本质，就是一条"给谁治、不给谁治"的临床决策规则——和医生凭经验制定"哪些病人该用某种药"高度相似。医学界早已用"训练集 / 验证集 / 外部验证队列"来保证临床预测模型不过拟合；evalITR 把同一套纪律用到 ITR 上：

  • 训练集：用随机化试验的这批数据，找出"哪类协变量特征的人更可能获益"的规律；
  • 测试集：用另一批独立数据，老实检验这条规则推广到新病人时到底能多获益多少（PAPE、AUPEC）；
  • 预算约束：对应真实医疗的"资源有限"——比如只有 20% 的药量/经费，规则就只挑获益最大的人优先给。

牢记一点：本文 70/30 是教学演示。真实临床场景里，若想把规则用到本院甚至外院病人身上，理想情况下还应做外部验证（external validation）——用一套完全独立、不同来源的数据再盲测一次，才敢说这条规则真的靠谱。这正是样本分割思想最朴素也最重要的延伸。
