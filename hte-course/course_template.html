一个数字，两种命运

为什么"总体无效"的研究，仍然可能藏着一个 NNT 只有 7.5 的人群？

本堂课的核心冲突：同一项治疗，在同一批"符合适应证"的患者里， 平均只带来 3.3 个百分点的死亡率下降（统计学上不算显著）； 但当研究者按入院乳酸与意识水平（GCS）把人群切开， 角落里那一格的数字是 13.3 个百分点——每救活 1 人只需治疗 7.5 人。 异质性治疗效应（HTE）关心的正是这个"角落"怎么找、怎么验证、以及怎么避免把自己骗了。

第 1 章

研究背景：输血比例的"未解之争"

为什么同样是"高血浆比例"，不同研究结论不一？

临床问题

严重创伤大出血患者常需大量输血。理论上，早期补充血浆（FFP）可纠正创伤性凝血病， 改善预后。因此临床普遍关注 FFP:RBC 输注比例—— 高比值（> 1，接近 1:1）是否优于低比值（≤ 1，接近 1:2）。

然而证据并不统一：标志性 RCT（如 PROPPR）总体未显示 1:1:1 优于 1:1:2 的 24 小时死亡率差异；观察性研究则多有阳性结果。面对"总体平均效应"的分歧， 一个自然的追问是：

研究问题（原文 Background）
在需要输血的严重钝性创伤患者中，评估高 FFP:RBC 输血比例的 异质性治疗效应（HTE），并识别获益最大的亚组。

研究目标拆解（PICO）

要素定义（原文）
P 人群日本创伤数据库（JTDB）2019–2023 登记的成人严重钝性创伤（ISS ≥ 16）且接受输血者；推导队列 2019–2021（n = 3,918），验证队列 2022–2023（n = 2,761）
E 暴露高 FFP 组：FFP:RBC > 1
C 对照低 FFP 组：FFP:RBC ≤ 1
O 结局主要结局：院内死亡（in-hospital mortality）
第 2 章

研究设计与分析蓝图

看懂 Fig.1 与 Fig.2，就掌握了这篇论文 80% 的骨架。

2.1 分析概念模型（原文 Fig.1）

这是本课的总路线图：先在推导队列（derivation cohort，2019–2021）里用因果森林 "发现"异质性并圈定治疗靶点；再到验证队列（validation cohort，2022–2023）里 "确认"这个靶点的效应。

左半边：发现（Derivation）

  • 因果森林估计每位患者的 CATE
  • 按 CATE 五分位分层（Q1–Q5）
  • AIPW 估计组特异 ATE 并做校准检验
  • 乳酸 × GCS 的 3×3 热图 → 圈定候选靶点

右半边：验证（Validation）

  • 把靶点定义套用到独立时段队列
  • IPTW 加权估计风险差（RD）与 NNT
  • 三个敏感性分析交叉确认稳健性
为什么必须"发现"与"验证"分开？ 如果在同一批数据上既挑选最优切点、又报告该切点的效应， 这个效应会被系统性高估（选择性推断 / 过拟合）。 用时间上独立的队列验证，是这类研究最基本也最容易被忽略的防线。

2.2 数据来源与患者筛选（原文 Fig.2）

数据来自 JTDB（Japan Trauma Data Bank，日本创伤数据库）2019–2023 登记。 纳入标准：成人、钝性创伤、ISS ≥ 16、接受过输血。排除穿透伤、年龄 < 18 岁、 未输血者。最终 N = 6,679。

第 3 章

缺失数据与 missForest 插补

创伤登记数据的现实：越危重的指标，越容易缺失。

3.1 方法选择

原文 Methods 明确说明：协变量缺失采用非参数单一插补（missForest）处理， 并在推导队列与验证队列中分别独立进行—— 这一步"分别插补"很重要，避免用验证队列的信息去帮助插补推导队列， 从而保持两个队列的独立性。 

# 每个队列独立插补（原文做法）
for (cc in c("derivation", "validation", "sa2")) {
  d    <- filter(dat_raw, cohort == cc)
  xmis <- d[, COVARS]                      # 18 个协变量

  imp  <- missForest::missForest(xmis, maxiter = 5, ntree = 100,
                                 backend = "randomForest", verbose = FALSE)
  d[, COVARS] <- imp$ximp
}
为什么用 missForest 而不是均值/多重插补？
① 非参数：不假设线性或正态分布，能捕捉协变量间复杂交互；
② 混合类型：连续（乳酸、血压）与分类（损伤机制）可同时处理；
③ 自带精度诊断：OOB 误差（连续变量 NRMSD、分类变量 PFC）可直接报告。
代价是计算慢，且单一插补未纳入插补不确定性——因此在敏感性分析中值得再检查。

第 4 章

因果森林：估计"这个人"的疗效

从 ATE 到 CATE：把"平均人"拆成一个个具体的病人。

4.1 估计目标的升级

量符号含义回答的问题
平均治疗效应ATE = E[Y(1) − Y(0)]整人群的平均效应"这个疗法整体上有效吗？"
条件平均治疗效应CATE = E[Y(1) − Y(0) | X = x]特征为 x 者的效应"这类患者获益多少？"
个体治疗效应ITE = Y(1) − Y(0)单个人的效应"这个患者获益多少？"（永远不可直接观测）
一句话理解：ITE 无法观测（同一个人不能同时接受和不接受治疗）， 所以只能退而求其次估计 CATE——把特征相似的人"借"来当反事实。 因果森林做的，就是在协变量空间里自适应地寻找这些"相似的人"。

4.2 森林为什么能做因果推断（重点）

普通预测森林优化预测精度；因果森林改造成估计处理效应，关键点有三：

  1. 诚实分割（honest splitting）：把样本随机分成两半，一半用来 决定树怎么长（在哪里分裂），另一半用来估计叶子里的处理效应。 这样"分裂点"与"效应估计"用的数据互不重叠，避免了同一份数据既选结构又估数值带来的偏倚。
  2. 正交化 / 局部矩估计：先用交叉拟合的回归分别去除 Y 与 W 中由 X 解释的部分（即 nuisance：m(x)、e(x)）， 再用残差构造"双倍稳健"的目标，使效应估计对 nuisance 估计误差不敏感。
  3. 袋外（OOB）预测：每棵树只用部分样本训练， 用没参与该树训练的样本做预测，天然形成交叉验证， 从而可以给出 CATE 的置信区间与校准检验。
课堂用类比：把因果森林想成"会分科室的会诊团"。 每个医生（树）只看自己那批病人（子样本）， 并凭经验把病人按病情特征分到不同的诊疗路径（分裂规则）； 但对某条路径上的疗效判断，他要请另一批没参与分流的医生来下结论（诚实性）。 最后全体投票，得到每个病人个体的疗效估计与不确定度。

4.3 grf 一行拟合（论文设定）

论文原话：训练 5,000 棵树，采用诚实结构， 其余超参数使用 grf 包默认值。 

library(grf)

# X: 协变量设计矩阵（18 个协变量，分类变量自动哑变量化）
# Y: 结局（院内死亡）   W: 暴露（高 FFP:RBC = 1）
set.seed(SEED + 30L)
cf <- grf::causal_forest(
  X         = X_der,
  Y         = Y_der,
  W         = W_der,
  num.trees = 5000L,        # 论文设定
  honesty   = TRUE,         # 诚实分割（grf 默认开启）
  seed      = SEED + 30L
)

cate_oob <- predict(cf)$predictions   # 袋外 CATE 预测
三个必须讲清的识别假设： ① 一致性（consistency）：观察到的结局就是其接受治疗对应的潜在结局； ② 可交换性 / 无未测量混杂：给定 X，治疗分配与潜在结局独立（观察性研究中最脆弱的一条）； ③ positivity：0 < P(W=1|X) < 1，每个特征组合都有机会接受或不接受治疗。 本课 IPTW 部分正是在检验 ② 与 ③。
第 5 章

结果①：异质性真的存在吗？（CATE 分布）

原文 Fig.3 是整个 HTE 论证的第一块基石。

怎么读这张图（讲课脚本）

  • 横轴 CATE：单位是风险差（本复现中换算为百分点 pp）。
  • 负值 = 获益：因为结局是死亡，负值意味着高 FFP 组死亡风险更低。
  • 双峰的意义：如果不存在异质性，分布应当是围绕 ATE 的单峰； 出现第二个峰，说明确实有一批人的效应明显不同于平均。
  • 警惕：双峰也可能来自过拟合噪声，因此必须再做校准检验与独立队列验证。

热图最初给出的候选靶点是乳酸最高三分位（T3）合并 GCS 最低或中间三分位（T1、T2）， 对应 乳酸 ≥ 4.6 mmol/L 且 GCS ≤ 13。 但作者随后把切点就近取整为临床常用阈值： 乳酸 ≥ 4.5 mmol/L 且 GCS ≤ 12，以提升可解释性与可操作性。

请学生判断：这一步是"提升实用性"，还是"引入研究者自由度（researcher degrees of freedom）"？ 如果换成 ≥ 4.0 且 ≤ 13，效应会变大还是变小？这正是预注册与 敏感性分析存在的理由。

第 10 章

讨论、局限与教学要点

方法学上，这篇论文真正值得学习（和警惕）的地方。

10.1 原文讨论要点（Key observation）

  • 在需要输血的严重钝性创伤患者中，高 FFP:RBC 比例存在异质性治疗效应。
  • 识别出的治疗靶点（GCS ≤ 12 且乳酸 ≥ 4.5 mmol/L）死亡率下降显著更大。
  • 用常规可得的临床指标来指导输血策略，可能改善预后。

10.2 优势与临床意义

  • 用因果森林超越"平均值分析"，探索效应异质性。
  • 与传统亚组方法不同：机器学习方法无需预先定义分层，即可发现个体层面的变异。
  • 把复杂输出翻译成可操作的阈值（≥ 4.5 与 ≤ 12），便于临床落地。
  • 可实现靶向血浆复苏，改善预后并优化血液制品资源使用。

10.3 机制解释（Interpretation）

高乳酸 → 休克/低灌注

提示组织低灌注与休克，通过内皮活化、炎症反应与糖萼降解， 成为创伤性凝血病的主要触发因素，导致凝血障碍与出血风险升高。

意识障碍 → 创伤性脑损伤（TBI）

很可能反映 TBI：以组织因子释放与纤溶亢进为特征， 这种早发凝血病可能需要以血浆为基础的复苏。

10.4 局限性（课堂辩论材料）

  1. 观察性研究：基于登记数据，不能直接推断因果。 作者认为"足以实质性扭曲结果的强未测量混杂不太可能"， 但仍存在时间依赖性未测量混杂—— 例如：存活时间更长的患者，更可能接受更多 FFP。
  2. ISS 的实用性限制：ISS ≥ 16 虽然被验证有效， 但入院时无法立即获得，限制了实时使用。 真实世界启动输血主要依赖医生判断（损伤机制、生命体征等早期指标）。
  3. 外推性：数据来自日本全国创伤登记，向其他医疗体系外推需谨慎。
重点讲解：第 1 条局限里的"存活时间更长 → 更可能接受更多 FFP"。 这正是 永恒时间偏倚（immortal time bias） 与 时间依赖性混杂 的经典场景： 要接受"高 FFP:RBC"，患者必须先活着撑到输完足够的血制品。 早期死亡者被自动归入"低比例组"，于是高比例组"看起来"预后更好—— 哪怕治疗本身毫无作用。

原文的应对：时间上独立的验证队列 + 多个敏感性分析（尤其 SA1 排除 120 min 内死亡）。 更强的做法：目标试验模拟（target trial emulation）， 在 time zero 对齐 eligibility 与治疗策略，并配合克隆-删失-加权或 g-methods 处理时间依赖性混杂。

10.5 三大偏倚与永恒时间偏倚（本课的"防骗清单"）

偏倚本质本课案例中的表现防线
选择偏倚 进入分析的人群不能代表目标人群 限定 ISS ≥ 16 且输血者；ISS 入院时不可得 SA2 用"2 h 内开始输血"重定义人群
信息/测量偏倚 变量测量不准确 乳酸缺失达 17%，且与病情严重度相关（MAR） missForest 非参数插补 + 按队列分别插补
混杂偏倚 治疗与结局共享共同原因 病情越重越可能给高 FFP，也更可能死亡 倾向评分 + IPTW 加权 + 平衡诊断（SMD）
永恒时间偏倚 需要"存活"才能进入治疗组的时间被错误计入 早期死亡者无法累积 FFP:RBC 比值 SA1 排除 ≤ 120 min 死亡；更优：TTE + g-methods
给学生的三句话总结：
① 平均效应回答"群体是否受益"，CATE 回答"谁受益"；
② 发现与验证必须分离，否则就是自我实现的预言；
③ 观察性 HTE 的结论止于"可用于生成假设"，确认仍需 RCT。
