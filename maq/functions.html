maq 函数参考

本页整理 maq（R 包，版本 0.6.1）的全部公开函数，译自官方函数手册（man 页）。示例与完整参数说明见 maq 包总览。

函数总览

函数功能
maq()拟合多臂 Qini 曲线。
average_gain()给定支出水平，获取增益估计。
difference_gain()给定支出水平，获取两条 Qini 曲线的增益之差（配对标准误）。
integrated_difference()获取两条 Qini 曲线之间的面积（配对标准误）。
get_ipw_scores()用逆概率加权（IPW）构造评估评分。
get_aipw_scores()用增广逆概率加权（AIPW）构造评估评分。
scale_maq()对 Qini 曲线做缩放（换算单位）。
predict()获取给定支出水平下的处理分配矩阵。
plot()绘制 Qini 曲线（含置信区间带）。
summary()输出构成 Qini 曲线的数据框。
print()打印 maq 对象。

maq()：拟合多臂 Qini 曲线

maq(reward, cost, DR.scores, budget = NULL, target.with.covariates = TRUE,
    R = 0, paired.inference = TRUE, sample.weights = NULL,
    clusters = NULL, tie.breaker = NULL, num.threads = NULL, seed = 42)

参数：

  • reward：n × K 矩阵，每个个体在每个处理臂上的 CATE 估计（相对于对照臂）。
  • cost：n × K 矩阵，把某臂分配给某个体所产生的成本；也接受标量，表示所有臂统一成本。
  • DR.scores：n × K 评估评分矩阵（如 AIPW 或 IPW 评分），用于估计策略价值。
  • budget：最大预算 B̄；默认取能达到的最大平均支出。
  • target.with.covariates：是否在目标策略中使用协变量（TRUE 时按 τ̂ 与 cost 的凸包路径分配）。
  • R：bootstrap 重复次数，用于标准误与置信区间；默认 0（不做推断）。
  • paired.inference：对两条曲线做差异推断时是否使用配对 bootstrap（默认 TRUE）。
  • sample.weights、clusters：样本权重与聚类变量（加权/聚类推断）。
  • tie.breaker：预算路径中出现并列时的个体打破平局次序。
  • num.threads、seed：线程数与随机种子（默认 42）。

返回：一个 maq 对象，包含整条解路径 Q(B) 及（若 R > 0）逐预算水平的标准误。

评估评分：get_ipw_scores() 与 get_aipw_scores()

get_ipw_scores(Y, W, W.hat = NULL)
get_aipw_scores(Y, W, mu.hat, W.hat = NULL)

get_ipw_scores()：用逆概率加权从结果 Y、处理分配 W 与（可选的）倾向估计 W.hat 构造评估评分。适用于随机化概率已知的实验数据。get_aipw_scores()：用增广逆概率加权（双鲁棒）构造评分，额外需要一个 outcome 回归预测 mu.hat（n × K 矩阵）；在倾向估计不可信时仍能保持半参数效率。两个函数都返回 n × K 的评分矩阵，可直接作为 maq() 的 DR.scores 参数。

增益读取：average_gain()、difference_gain()、integrated_difference()

average_gain(object, spend)
difference_gain(object.lhs, object.rhs, spend)
integrated_difference(object.lhs, object.rhs, spend)

average_gain()：在给定支出水平 B 处返回 Q(B) 的估计及标准误。difference_gain()：给定两条 Qini 曲线 Q_a 与 Q_b，返回某支出水平 B 处的增益之差 Q_a(B) − Q_b(B) 及配对标准误——用于比较「两套 CATE 估计/两种成本假设」下的策略表现。integrated_difference()：返回两条曲线在 [0, B̄] 上的积分差 ∫₀^B̄ (Q_a(B) − Q_b(B))dB 及配对标准误，即两曲线之间的面积，是「整体谁更优」的一个汇总量。

预测与可视化：predict()、plot()、scale_maq()

predict(object, spend, type = c("matrix", "vector"))
plot(x, ..., add = FALSE, horizontal.line = TRUE, ci.args = list(), grid.step = NULL)
scale_maq(object, scale = 1)

predict()：返回给定支出水平下的最优分配——type = "matrix"（默认）给出 n × K 的分配矩阵（每行只有一个 1，其余为 0），type = "vector" 给出每个个体被分配的臂编号。plot()：绘制 Qini 曲线；add = TRUE 可把第二条曲线叠加到已有图上，horizontal.line = TRUE 画出「不分配任何处理」的水平基准线，grid.step 控制置信区间带的网格步长，ci.args 传递区间绘制的图形参数。scale_maq()：把策略价值与预算整体乘以一个系数，用于把「每单位支出」换算成应用单位（如从比例换算为「500 个名额」）；示例：plot(scale_maq(qini, 500), xlab = "Units treated")。

汇总与打印：summary()、print()

summary()：返回构成估计 Qini 曲线的数据框，列为 [B, Q(B), std.err(Q(B)), i, k]——i 与 k 表示在支出水平 B 下最优分配的个体与处理臂。print()：打印 maq 对象的简要信息。
