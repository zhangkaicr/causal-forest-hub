maq：多臂 Qini 曲线（Multi-Armed Qini）

官方仓库：github.com/grf-labs/maq ｜ 官方文档：grf-labs.github.io/maq ｜ 安装来源：CRAN（install.packages("maq")）

背景与解释（译者注）：maq 是 GRF Labs 组织下的第 4 个核心仓库，与 grf、policytree、sufrep 同属一个体系。它回答的问题是：当不同的处理（药物、项目、干预）成本不同、且预算有限时，如何评估一个「在预算约束下最优地分配多种处理」的策略？本库 grf 教程中的《Qini 曲线：自动成本-收益分析》 是该方法背后论文（Sverdrup、Wu、Athey、Wager，发表于 Journal of Computational and Graphical Statistics，2025）的完整译文；本页则是 maq 软件包自身的官方文档译本，两者互为对照。

简介

maq 是一个用广义 Qini 曲线评估处理分配策略的 R/Python 包。给定估计的条件平均处理效应（CATE）、处理成本与评估评分，maq 会在一系列预算水平上计算最优处理分配，并估计由此产生的策略价值。底层优化利用了分配问题中「线性多选背包」的结构，可以高效地算出整条解路径。

常见用法是：在一个训练样本上用 grf 的 multi_arm_causal_forest 拟合 CATE 估计器，再在留出的评估样本上计算双鲁棒（AIPW）评分，最后用 maq 拟合 Qini 曲线并读出「每多花一单位预算能换来多少增益」。

安装

最新发布版可从 CRAN 安装：

install.packages("maq")

开发版可以这样安装：

devtools::install_github("grf-labs/maq", subdir = "r-package/maq")

（从源码安装需要 C++ 编译器。）Python 绑定见官方仓库的 python-package 目录。

使用示例

下面是官方文档的完整示例：三分支处理（一个对照臂 + 两个处理臂），处理成本由协变量给出，评估评分用 AIPW：

library(maq)

# 在训练样本上拟合 CATE 估计器。
n <- 3000
p <- 5
X <- matrix(runif(n * p), n, p)
W <- as.factor(sample(c("0", "1", "2"), n, replace = TRUE))
Y <- X[, 1] + X[, 2] * (W == "1") + 1.5 * X[, 3] * (W == "2") + rnorm(n)
train <- sample(1:n, n/2)

tau.forest <- grf::multi_arm_causal_forest(X[train, ], Y[train], W[train])

# 在留出的评估数据上预测 CATE。
test <- -train
tau.hat <- predict(tau.forest, X[test, ], drop = TRUE)$predictions

# 假设成本等于个体的处理前协变量——下面只是一个玩具示例。
cost <- cbind(X[test, 4] / 4, X[test, 5])

# 拟合一个评估森林，在测试集上计算双鲁棒（DR）评分。
eval.forest <- grf::multi_arm_causal_forest(X[test, ], Y[test], W[test])
DR.scores <- grf::get_scores(eval.forest, drop = TRUE)

# 在评估数据上拟合 Qini 曲线，用 200 次 bootstrap 重复构造置信区间。
ma.qini <- maq(tau.hat, cost, DR.scores, R = 200)

# 绘制 Qini 曲线。
plot(ma.qini)
legend("topleft", c("All arms", "95% CI"), lty = c(1, 3))

# 在给定的单位支出水平上获得增益估计及标准误。
average_gain(ma.qini, spend = 0.2)

# 获得给定单位支出水平下的处理分配矩阵。
pi.mat <- predict(ma.qini, spend = 0.2)

# 如果处理的随机化概率已知，可以用逆概率加权（IPW）评分
# 作为 AIPW 评分之外的另一种评估方式。
W.hat <- rep(1/3, 3)
IPW.scores <- get_ipw_scores(Y[test], W[test], W.hat)
mq.ipw <- maq(tau.hat, cost, IPW.scores)

数学细节

设 τ̂(·) 是一个估计的 CATE 函数，其第 k 个元素度量第 i 个个体 X_i 在处理臂 k = 1, …, K（k = 0 为对照臂）上的条件平均处理效应 E[Y_i(k) − Y_i(0) | X_i]。设 C(·) 是给第 i 个个体分配某一处理臂的已知成本函数。maq 给出如下 Qini 曲线的估计：

\[ Q(B) = E\big[\langle \pi_B(X_i),~ \tau(X_i)\rangle \big] \]

即在任意预算约束 B 下的期望增益：策略 π_B（利用给定的 τ̂(·) 与 C(·)）最优地决定「给哪个个体分配哪个臂」，使得平均成本不超过 B。策略 π_B 是一个线性规划的解：maq 通过一个利用多选背包结构的算法，沿递增的预算水平 B 计算出整条分配解路径。算法概览见本库 《MAQ 算法参考》 一页。
