tidyhte 中文译本：用 tidyverse 语法估计异质性处理效应

原文：ddimmery.github.io/tidyhte · 作者：Drew Dimmery（与 Edward Kennedy 合作） · 方法论文：Kennedy (2023), Electronic Journal of Statistics, doi:10.1214/23-EJS2157 · 许可：MIT License · 本页为个人学习用途的非官方中文译本，引用请以英文原文为准

tidyhte 解决的是这样一个问题：平均处理效应（ATE）告诉你「这个干预总体上有效」，但临床上真正需要回答的是「对谁有效、对谁无效、甚至有害」。它把 Kennedy（2023）提出的双重稳健（doubly-robust）异质性处理效应学习器包装成一套 tidyverse 风格的流水线：你只需用一份「配方（recipe）」说明倾向得分怎么估、结果模型怎么估、效应要怎样汇总，然后用管道依次跑完 交叉验证切分 → 干扰函数估计 → 伪结局构造 → 目标量估计，最后得到一张整洁（tidy）的 tibble，可以直接喂给 ggplot2。

背景与解释

什么是异质性处理效应（heterogeneous treatment effect, HTE）？在医学研究中，我们早已习惯做「亚组分析（subgroup analysis）」：按性别、年龄、基线疾病严重度、生物标志物分层，看疗效是否不同。HTE 估计是亚组分析的现代化形式——它不再依赖研究者事先猜哪些变量重要，而是用机器学习从数据中学习「疗效如何随协变量变化」的函数 \(\tau(x)\)，同时给出有效的标准误和置信区间。

需要注意一个常见误区：传统亚组分析往往是「先分组、再在组内做 t 检验」，多重比较会严重膨胀假阳性；而 tidyhte 采用的是先把效应函数估出来、再对平滑后的效应曲线做推断，并且全流程使用交叉拟合（cross-fitting），从而避免了「用同一份数据既挑模型又做推断」带来的选择性偏差。

为什么要用 tidyhte？

异质性处理效应估计在应用研究中越来越重要，但现有工具往往要求使用者具备相当深厚的统计学功底才能正确实现：研究者必须自己在交叉验证、模型选择、有效推断之间做复杂的取舍。tidyhte 通过以下几点来应对这些困难：

  1. 实现当前最先进的双重稳健方法，并自动完成交叉验证；
  2. 使用 R 用户熟悉的、直观的「配方（recipe）」语义；
  3. 可以从单个结局与调节变量平滑地扩展到多个结局与调节变量；
  4. 提供内置的模型质量诊断；
  5. 以 tidy 格式返回结果，便于可视化。

这样一来，现代的 HTE 方法就对应用研究者敞开了大门——他们需要理解处理效应的变异，却不必是因果推断与机器学习的专家。

背景与解释

「双重稳健（doubly robust, DR）」在流行病学里意味着什么？估计处理效应需要两个「干扰函数（nuisance function）」：倾向得分 \(\pi(x)\) 与结果回归 \(\mu_a(x)\)。如果只依赖其中一个（例如只用倾向得分做逆概率加权，或只用结果回归做插补），那么该模型一旦设定错误，效应估计就会有偏。

双重稳健估计量（如 AIPW / DR-Learner）把两者组合起来，其误差大致正比于两个模型误差的乘积。这意味着：只要其中任意一个模型估计得足够好（收敛速度足够快），最终效应估计就仍然是一致的。对医学研究者而言，这相当于给模型误设上了一道「双保险」。

另一个关键点：交叉拟合（cross-fitting）。如果直接用同一批数据拟合 \(\hat\pi, \hat\mu\) 再代入二阶回归，机器学习模型的过拟合会污染推断，导致置信区间失效。tidyhte 先做样本切分，在「A 折」上训练干扰函数、在「B 折」上评估，再对折间结果取平均，从而让二阶回归的误差与「真实个体疗效对协变量的神谕回归」的误差同阶——这正是 Kennedy（2023）定理 2 的核心结论。

研究应用场景

tidyhte 被设计用于支持多个领域中「理解处理效应变异」至关重要的研究：

  • 临床试验（Clinical Trials）：识别从某种治疗中获益最大的患者亚群；
  • 政策评估（Policy Evaluation）：理解政策干预对哪些人群影响最大；
  • 技术与 A/B 测试（Technology & A/B Testing）：为不同用户群体优化产品功能；
  • 经济学（Economics）：研究经济政策在不同人口学群体中的异质性效应；
  • 教育学（Education）：评估教育干预的差异化影响。

从 CRAN 安装已发布的正式版本：

install.packages("tidyhte")

快速上手

学习如何使用 tidyhte，最好的起点是那两篇从头到尾跑通完整示例分析的小品文（vignette）：vignette("experimental_analysis") 与 vignette("observational_analysis")。此外还有一篇总结方法与实现细节的文章 vignette("methodological_details")，其中包含一个基于 Palmer Penguins 数据集的准真实世界示例。

最小示例

如果想用默认设置快速开始，只需使用 basic_config()：

library(tidyhte)

# 全部使用默认设置 —— 干扰函数采用线性模型
results <- data %>%
  attach_config(basic_config()) %>%
  make_splits(user_id) %>%
  produce_plugin_estimates(outcome, treatment, x1, x2, x3) %>%
  construct_pseudo_outcomes(outcome, treatment) %>%
  estimate_QoI(x1, x2)
背景与解释

这条管道每一步在干什么？把它翻译成流行病学语言：

attach_config() —— 把「分析方案」贴到数据上，相当于预先写好统计分析计划（SAP）；make_splits() —— 划分交叉验证折（若有多行属于同一个体，会自动分到同一折，避免「同一个人的信息泄漏到验证折」）；produce_plugin_estimates() —— 拟合干扰函数，即倾向得分模型与结果模型（也就是 T-learner 的插件估计）；construct_pseudo_outcomes() —— 把干扰函数组合成「伪结局（pseudo-outcome）」，即 AIPW 形式的未中心化影响函数；estimate_QoI() —— 对伪结局做二阶平滑回归，产出你真正关心的目标量（MCATE、VIMP、诊断）。

注意最后一步是廉价的：干扰函数已经估计完毕，换一个调节变量或换一个目标量，只需重跑 estimate_QoI()，不需要重新训练任何机器学习模型。

模型选择指南

在为集成模型挑选机器学习算法时，可以结合你的学科专业知识，按下面这样的递进顺序考虑：

  • 从简单开始："SL.glm"（线性模型），用于初步探索；
  • 加入交互："SL.glm.interaction"，当你预期处理效应会随协变量变化时；
  • 正则化："SL.glmnet"，适用于维度较高的数据（例如大量交互项，另见 SL.glmnet.interaction），或者当你担心过拟合时；
  • 灵活模型："SL.ranger"（随机森林）或 "SL.xgboost"（梯度提升），适用于关系较为复杂的情形。

SuperLearner 集成会自动为这些模型分配权重。建议先用 2–3 个算法，再按需增加复杂度。所有可用选项参见 SuperLearner::listWrappers()。

背景与解释

为什么要用集成学习 SuperLearner，而不是挑一个「最好的」模型？在预测建模里，我们通常比较几个候选模型后挑 CV 误差最小的那个。这种做法的问题在于：模型选择本身引入了额外的不确定性，而「赢者通吃」的离散选择会让最终预测器不稳定。

SuperLearner 的做法是凸组合：把所有候选模型（含同一算法的不同超参数版本）作为「基学习器」，再用约束最小二乘（权重非负且和为 1）学出一组权重，使得集成后的交叉验证风险（如 MSE）最小。理论上，它的表现渐近不劣于最好的单个基学习器（Van der Laan 等，2007）。

对医学研究者的实际意义：你不必在「逻辑回归 vs 弹性网络 vs 随机森林」之间下赌注。把它们都放进集成，让交叉验证去决定权重；同时你可以从输出的「系数图」里看到哪些算法拿到了非零权重，这本身就是关于数据结构的诊断信息（例如随机森林权重高，往往提示存在重要的非线性或交互）。

配置一份分析方案（Recipe）

要建立一份简单的配置，直接使用 Recipe API 即可，非常直观。包含完整数据的示例请参阅 vignette("experimental_analysis") 与 vignette("observational_analysis")。

library(tidyhte)
library(dplyr)

hte_cfg <- basic_config() %>%
  add_propensity_score_model("SL.glmnet") %>%
  add_outcome_model("SL.glmnet") %>%
  add_moderator("Stratified", x1, x2) %>%
  add_moderator("KernelSmooth", x3) %>%
  add_vimp(sample_splitting = FALSE)

basic_config 内含若干默认设置：它把处理模型与结果模型的 SuperLearner 集成都以线性模型（"SL.glm"）作为起点。

运行一次分析

data <- data %>%
  attach_config(hte_cfg) %>%
  make_splits(userid, .num_splits = 12) %>%
  produce_plugin_estimates(
    outcome_variable,
    treatment_variable,
    covariate1, covariate2, covariate3, covariate4, covariate5, covariate6
  ) %>%
  construct_pseudo_outcomes(outcome_variable, treatment_variable)

results <- data %>%
  estimate_QoI(covariate1, covariate2)

如果还想获取某个此前未纳入的调节变量上的 CATE 估计，只需重跑最后一行：

results <- data %>%
  estimate_QoI(covariate3)

把这套分析复用到一个新结局上，也同样简单，无需重新配置：

results <- data %>%
  attach_config(hte_cfg) %>%
  produce_plugin_estimates(
    second_outcome_variable,
    treatment_variable,
    covariate1, covariate2, covariate3, covariate4, covariate5, covariate6
  ) %>%
  construct_pseudo_outcomes(second_outcome_variable, treatment_variable) %>%
  estimate_QoI(covariate1, covariate2)

这也让我们可以很方便地把多个结局的分析串联起来：

library("foreach")

data <- data %>%
  attach_config(hte_cfg) %>%
  make_splits(userid, .num_splits = 12)

foreach(outcome_str = list_of_outcome_strs, .combine = "bind_rows") %do% {
  data %>%
    produce_plugin_estimates(
      .data[[outcome_str]],
      treatment_variable,
      covariate1, covariate2, covariate3, covariate4, covariate5, covariate6
    ) %>%
    construct_pseudo_outcomes(outcome, treatment_variable) %>%
    estimate_QoI(covariate1, covariate2) %>%
    mutate(outcome = outcome_str)
}

函数 estimate_QoI 以 tibble 格式返回结果，因此非常便于进一步处理或绘图。

背景与解释

这个设计对医学研究有什么实际好处？一项随机对照试验通常有多个结局（主要结局、次要结局、安全性指标），也可能有多个对照（标准治疗 vs 安慰剂、高剂量 vs 低剂量）。传统做法是为每个结局重写一遍分析代码，很容易在复制粘贴中出错。

tidyhte 把「分析方案（recipe）」与「具体变量」解耦：方案只写一次，变量在运行时指定。于是「把同样的分析在 12 个结局上各跑一遍」就退化成一个 foreach 循环，并且结果天然带有一致的数据结构，可以直接 bind_rows 后画森林图。

谨慎提醒：跑 12 个结局意味着 12 次推断。如果这是验证性（confirmatory）分析，请事先确定主要结局并考虑多重比较校正；把 HTE 分析用于探索性（exploratory）假设生成是恰当的，但据此下确证性结论则需要独立的验证队列或预先注册的分析计划。

性能考虑

带有交叉验证与集成机器学习的 HTE 估计可能计算密集。对于较大的数据集或结局很多的分析，请提前做好规划。

目前包本身不直接管理并行计算，但可以很方便地借助 foreach 的并行后端来支持：

library(doParallel)
registerDoParallel(cores = 4)

foreach(outcome_str = outcome_list_str, .combine = "bind_rows") %dopar% {
  data %>%
    produce_plugin_estimates(.data[[outcome_str]], treatment, covariates) %>%
    construct_pseudo_outcomes(.data[[outcome_str]], treatment) %>%
    estimate_QoI(moderators)
}

术语对照

以下按「英文 → 中文 → 在本包语境下的含义」排列，供阅读原文与源码时参照。

  • heterogeneous treatment effect（HTE，异质性处理效应）：处理效应随个体协变量而变化的现象；本包要估计的对象。
  • conditional average treatment effect（CATE，条件平均处理效应）：\(\tau(x)=\mu_1(x)-\mu_0(x)\)，即在协变量 \(X=x\) 的子人群上的平均效应。
  • MCATE（marginal CATE，边际条件平均处理效应）：把所有其他协变量边际化掉，只留下一个协变量后得到的效应曲线／分层效应。这是本包默认报告的量。
  • PCATE（partial CATE，部分条件平均处理效应）：把其他变量「控制住」后得到的效应。注意：若不假设处理与协变量联合随机化，PCATE 没有令人满意的因果解释——这正是 tidyhte 默认报告 MCATE 而非 PCATE 的原因。
  • propensity score（倾向得分）：\(\pi(x)=\mathbb{P}(A=1\mid X=x)\)，给定协变量时接受处理的概率。在随机对照试验中它通常已知（等于随机化概率），在观察性研究中需要用模型估计。
  • nuisance function（干扰函数）：\(\pi(x)\) 与 \(\mu_a(x)\) 的统称。它们本身不是研究目标，但估计效应时必须要用到。
  • outcome regression / T-learner（结果回归 / T-学习器）：分别在治疗组与对照组各拟合一个结果模型，再相减得到效应，即 \(\hat\mu_1(x)-\hat\mu_0(x)\)。tidyhte 称之为 plugin（插件）估计。
  • pseudo-outcome（伪结局）：由干扰函数变换得到的一个「假」结局 \(\hat\psi(Z)\)，其条件期望近似等于真实 CATE。对它做回归就等价于对（永远观测不到的）个体疗效做回归。
  • doubly-robust learner（DR-Learner，双重稳健学习器）：Kennedy（2023）的三步算法，即 估计干扰函数 → 构造伪结局 → 二阶平滑回归。
  • AIPW（augmented IPW，增广逆概率加权）：兼具 IPW 与结果回归的双重稳健估计量；伪结局本质上就是 AIPW 的未中心化影响函数。
  • influence function（影响函数）：半参数理论中的核心工具，刻画估计量对单个观测的敏感度；其方差给出有效率界与标准误。
  • cross-fitting / sample splitting（交叉拟合 / 样本分割）：把样本分成若干折，在部分折上训练模型、在其余折上评估，再对折间结果取平均，用于消除过拟合对推断的污染。
  • cross-validation（交叉验证）：用于选择超参数、估计泛化误差的折外评估机制；本包还用分块（blocking）来构造更低方差的切分。
  • SuperLearner / ensemble（超级学习器 / 集成学习）：把多个基学习器按非负、和为 1 的权重做凸组合，权重由交叉验证风险最小化确定。
  • hyperparameter（超参数）：如弹性网络的混合参数 alpha；本包会对所有超参数取完整笛卡尔积，把每一个组合都作为一个基学习器纳入集成。
  • regularization / glmnet（正则化）：岭回归与 LASSO 的连续混合（弹性网络，Zou & Hastie 2005）；惩罚强度由 cv.glmnet 自动调优。
  • VIMP（variable importance，变量重要性）：基于 Williamson 等（2021）的方法，衡量每个调节变量对「效应联合模型」均方误差下降的贡献，并附带标准误。
  • QoI（quantity of interest，目标量）：最终报告给使用者的统计量，本包包括 MCATE、VIMP 与各类诊断。
  • moderator（调节变量 / 效应修饰因子）：处理效应在其上发生变化的协变量；流行病学中常称「效应修饰因子（effect modifier）」。
  • kernel smoothing / local polynomial regression（核平滑 / 局部多项式回归）：对连续型调节变量，用 nprobust（Calonico、Cattaneo & Farrell）做局部线性回归，得到平滑的效应曲线；默认在协变量取值域上的 100 个分位数网格上求值。
  • stratified estimate（分层估计）：对离散型调节变量，在其每一个水平上取条件效应的平均。
  • effect surface（效应曲面）：在所有协变量上联合建模得到的 CATE 函数，是 VIMP 的计算基础。
  • diagnostics（诊断）：包括 MSE、AUC 等单值摘要，也包括回归 ROC 曲线（RROC）与 SuperLearner 集成系数。
  • RROC（regression ROC，回归 ROC 曲线）：横轴为「高估量」、纵轴为「低估量」的曲线，用于诊断结果模型的拟合质量——曲线越贴近坐标轴，说明模型的正向／负向残差都越小。
  • CV risk（交叉验证风险）：各子模型在折外数据上的损失（如 MSE），SuperLearner 据此分配权重。
  • consistency（一致性）：识别假设之一，\(Y_i=Y_i(A_i)\)，即观测到的结局等于该个体实际接受处理所对应的潜在结局；流行病学中常与 SUTVA（无干扰、处理版本唯一）一起讨论。
  • no unmeasured confounding / ignorability（无未测量混杂 / 可忽略性）：\(A\perp (Y(1),Y(0))\mid X\)，即在观测到的协变量 \(X\) 之后，处理分配与潜在结局独立。观察性研究中这条假设无法用数据检验，只能依赖学科知识论证。
  • positivity / overlap（正值性 / 重叠性）：存在 \(\epsilon>0\) 使得 \(\epsilon\le\pi(x)\le 1-\epsilon\) 几乎处处成立。它保证每一个协变量profile 都有机会被分配到治疗组与对照组，等价于流行病学里说的「协变量分布要有重叠」。
  • clustered data（聚类数据）：处理在群组层面分配、测量在个体层面进行的情形（例如整群随机试验中按村落/乡镇分配），此时标准误应按分配层级聚类。
  • population weights（人群权重）：用于让样本更接近目标人群的抽样／校准权重，在 produce_plugin_estimates() 中指定。
  • blocking（分块切分）：基于协变量距离把相似单位聚成块，再在块内随机分配折号，以降低各折之间的分布差异。
  • listwise deletion（成列删除）：本包处理缺失值的方式——删除任一分析变量缺失的行；暂不支持多重插补等更复杂的方法。

建议阅读顺序

  1. 先读本页，建立对整条流水线的整体印象，并浏览上面的术语对照。
  2. 读实验数据分析教程。随机对照试验中倾向得分已知，因此可以先把注意力集中在「伪结局 + 二阶平滑 + 诊断图怎么读」上，而不必分心于混杂控制。
  3. 读观察性数据分析教程。它与上一篇结构完全平行，唯一实质差别是倾向得分需要估计——请特别留意这对标准误（明显变大）与识别假设的影响。
  4. 读方法细节。当你想搞清楚「为什么可以这样算」「定理保证了什么」「各诊断量在数学上是什么」，就来这里。
  5. 动手：用自己的数据，先跑 basic_config() 的默认线性模型版本，确认流水线跑通、结果结构符合预期，再逐步加入 SL.glmnet、SL.ranger 等更灵活的基学习器。
背景与解释

把本包用于医学研究时的三点提醒。

第一，识别优先于算法。无论集成学习多先进，观察性数据中的无未测量混杂假设都无法由数据验证。请先花力气论证协变量集 \(X\) 的充分性（例如用有向无环图 DAG 梳理混杂路径），并检查正值性——若某些协变量组合的倾向得分接近 0 或 1，那里的效应估计将极度不稳定。

第二，把 MCATE 曲线当作假设生成工具。平滑后的效应曲线会显示出「效应在哪里变强/变弱」，但它不是对某个 cut-point 的检验。若想据此定义「获益亚群」，需要预先设定 cut-point 或采用正式的亚群识别方法，并在独立数据中验证。

第三，务必看诊断。VIMP 图告诉你哪些变量驱动了效应异质性；SuperLearner 系数与风险图告诉你集成是否有效；RROC 图告诉你结果模型是否系统性高估或低估。这些图不是可选项，而是判断「这套 HTE 分析是否可信」的必要依据。
