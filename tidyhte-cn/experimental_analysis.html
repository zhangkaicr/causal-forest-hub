这一篇是 tidyhte 的随机对照试验（RCT）场景教程：从模拟数据出发，依次完成「定义配方 → 估计干扰函数 → 构造伪结局 → 估计目标量 → 画图诊断」。因为数据来自随机化实验，倾向得分是已知的，这让我们可以先专注于理解流水线本身与各类诊断图的读法。

简介

在这个示例分析中，我将演示如何使用 Kennedy（2023）的方法，在一项随机对照试验中开展异质性处理效应（HTE）分析。由于数据来自随机化实验，倾向得分（propensity score）是已知的，因此估计通常是无偏的。

本分析的重点是：使用机器学习集成（通过 SuperLearner）来估计干扰函数（nuisance function），然后给出一张包含条件处理效应估计值及其相应标准误的 tibble。

背景与解释

为什么「随机化」在本教程里这么关键？在随机对照试验中，处理分配概率由研究设计决定（例如 ps = 0.3，即每个人以 30% 的概率被分到治疗组），因此它不需要估计、也不可能被估计错。这意味着本教程里的倾向得分模型误差为零。

相比之下，观察性数据分析教程中的处理分配取决于个体的协变量（例如病情更重的患者更可能接受新药），此时倾向得分必须用模型估计，并且估计的可靠性完全依赖三条识别假设：

① 一致性（consistency） \(Y_i=Y_i(A_i)\)：观测到的结局就是该个体实际接受处理所对应的潜在结局；② 无未测量混杂（no unmeasured confounding） \(A\perp(Y(1),Y(0))\mid X\)：在观测到的协变量 \(X\) 之后，处理分配与潜在结局独立；③ 正值性（positivity） \(\epsilon\le\pi(x)\le1-\epsilon\)：每种协变量组合都有机会被分配到两组。

前两条在 RCT 中由设计保证，在观察性研究中则只能靠学科知识论证；第三条在两种设计中都需要检查。正是这个差别，使得观察性分析的标准误会明显更大（本教程中 MCATE 的标准误约为 0.13–0.17，而观察性教程中约为 0.21–0.56）。

模拟数据

如果使用真实数据，只需把这一段替换成相应的 readr::read_csv 调用（或等价方式），创建一个 tibble 即可。下文将假定这个 tibble 被存为 data。

请注意：数据类型既可以是连续型也可以是离散型，并且 tibble 中允许存在不被纳入任何后续分析的列。

set.seed(100)
n <- 500
data <- tibble(
  uid = 1:n
) %>%
  mutate(
    a = rbinom(n, 1, 0.3),
    ps = rep(0.3, n),
    x1 = rnorm(n),
    x2 = factor(sample(1:4, n, prob = c(1 / 100, 39 / 100, 1 / 5, 2 / 5), replace = TRUE)),
    x3 = factor(sample(1:3, n, prob = c(1 / 5, 1 / 5, 3 / 5), replace = TRUE)),
    x4 = (x1 + rnorm(n)) / 2,
    x5 = rnorm(n),
    y = (
      a + x1 - a * (x1 - mean(x1)) + (4 * rbinom(n, 1, 0.5) - 1) * a * (x2 == 2) +
        a * (x2 == 3) + 0.5 * a * (x2 == 4) +
        0.25 * rnorm(n)
    ),
    w = 0.1 + rexp(n, 1 / 0.9)
  )
背景与解释

这份模拟数据里「埋」了什么真实结构？结局 y 的构造方式决定了真实的 CATE 函数 \(\tau(x)\)：效应随连续变量 x1 线性下降（项 - a * (x1 - mean(x1))），并在离散变量 x2 上发生分层跳跃（x2 == 2、x2 == 3、x2 == 4 各有不同的额外效应），而 x3、x4、x5 不参与效应异质性。

因此，等一下看图时你应该期待：x1 的 MCATE 曲线是一条向下倾斜的直线，x2 的分层 MCATE 在各水平间有明显差异，而 x3/x4/x5 的 MCATE 应接近水平线、置信带覆盖 0。这正好为「读图」提供了一个有标准答案的练习场。

另外注意 x2 的抽样概率里 1/100 这一项——它制造了一个极稀疏的水平，这正是后文报错信息的来源，也模拟了临床数据中「罕见亚型」的现实困境。

定义配方（Recipe）

倾向得分模型

在本例中，倾向得分是已知的，因为数据来自一项随机化实验。我们不需要为倾向得分估计模型。

对于离散型调节变量上的 CATE，这意味着我们的估计将直接等价于 AIPW 估计量，因而继承其无偏性。对于连续型调节变量，类似地，只要 CATE 函数是光滑的，我们就能以非参数方式一致地恢复出真实函数。

背景与解释

为什么「倾向得分已知」就能得到无偏性？这里的核心是 AIPW（增广逆概率加权）估计量的结构。伪结局可以写成

\(\hat\psi(Z)=\dfrac{A-\hat\pi(X)}{\hat\pi(X)(1-\hat\pi(X))}\bigl(Y-\hat\mu_A(X)\bigr)+\hat\mu_1(X)-\hat\mu_0(X)\)

右边的第二项（结果回归之差）是插件估计，第一项是对它的「纠偏项」。当 \(\hat\pi=\pi\)（即真实随机化概率）恰好正确时，第一项的条件期望为 0，于是伪结局的条件期望就等于真实 CATE，偏差仅来自 \(\hat\mu\)；而由于用的是交叉拟合，\(\hat\mu\) 的估计误差与残差相互独立，偏差进一步被抵消。

这也解释了为什么 RCT 里的 HTE 分析「容错性」更高：即便你不小心把结果模型设定得比较简单，估计仍然无偏，只是效率（标准误）有所损失。

结果模型

我们使用一组机器学习模型的集成来估计结局（T-learner）的插件估计，模型复杂度覆盖从线性模型、GAM 到正则化回归的广泛范围。在本例中，为了控制运行时间，没有纳入非线性模型，但只要把相应行取消注释，就可以轻松加入。

模型的每一个组件都提供一组超参数，算法会对这些超参数取完整的笛卡尔积（cross-product），并估计所有由此产生的模型。例如，SL.glmnet 会扫描一个超参数（岭回归与 LASSO 之间的混合参数）；每一个超参数取值下的模型都会被估计并纳入集成。注意，SL.glmnet 会使用 cv.glmnet 自动调优正则化参数，因此它不作为一个超参数出现。

背景与解释

「T-learner」与「超参数笛卡尔积」是什么意思？T-learner（「T」取自 two / treatment）是最朴素的 HTE 思路：分别在治疗组（\(A=1\)）与对照组（\(A=0\)）各拟合一个结果模型 \(\hat\mu_1,\hat\mu_0\)，然后相减得到 \(\hat\tau(x)=\hat\mu_1(x)-\hat\mu_0(x)\)。这种做法直观，但它的误差等于两个结果模型误差之和，没有双重稳健保护，也不保证二阶推断有效——所以 tidyhte 只把它当作插件估计，后续还要用伪结局做纠正。

关于超参数：像 alpha = c(0, 1) 这样写，表示把 alpha=0（纯岭回归）与 alpha=1（纯 LASSO）两个版本都训练出来，一起交给 SuperLearner 竞争。若同时指定多个超参数，则会取所有组合的笛卡尔积。这样做的好处是把「调参」变成了集成的一部分：你不需要事先赌一个 alpha，交叉验证会决定谁拿到权重。

医学场景提示：当协变量个数接近或超过样本量时（例如纳入了大量交互项、或使用了高维组学特征），务必保留 SL.glmnet 这类正则化学习器；纯线性模型 SL.glm 在这种情况下会严重过拟合。

目标量（Quantities of Interest）

目标量（QoI）决定了结果以何种方式呈现给使用者。你可以把它理解为：决定了结果在最终图表中应当如何绘制。

为简洁起见，本例只以下面两种方式之一给出结果：

  • 离散型协变量：按层（stratified）估计，在该协变量的每一个不同水平上绘制条件效应。
  • 连续型协变量：使用 Calonico、Cattaneo 与 Farrell（2018）的 nprobust，通过局部线性回归（local-linear regression）估计效应曲面。类似地，可参考 Kennedy、Ma、McHugh 与 Small（2017）对这一做法的理论论证。结果在该协变量取值域上的 100 个分位数网格上给出。

此外提供的另一个目标量是：在一个（覆盖所有协变量的）条件效应联合模型上学习得到的变量重要性（variable importance）。所实现的方法见 Williamson、Gilbert、Carone 与 Simon（2020）。

hte_cfg <- basic_config() %>%
  add_known_propensity_score("ps") %>%
  add_outcome_model("SL.glm.interaction") %>%
  add_outcome_model("SL.glmnet", alpha = c(0, 1)) %>%
  add_outcome_model("SL.glmnet.interaction", alpha = c(0, 1)) %>%
  add_outcome_diagnostic("RROC") %>%
  add_effect_model("SL.glm.interaction") %>%
  add_effect_model("SL.glmnet", alpha = c(0, 1)) %>%
  add_effect_model("SL.glmnet.interaction", alpha = c(0, 1)) %>%
  add_effect_diagnostic("RROC") %>%
  add_moderator("Stratified", x2, x3) %>%
  add_moderator("KernelSmooth", x1, x4, x5) %>%
  add_vimp(sample_splitting = FALSE)

背景与解释

这段配方到底声明了什么？逐行来看：add_known_propensity_score("ps") 告诉包「随机化概率已经存在 ps 这一列里，不用建模」；三行 add_outcome_model() 指定了结果模型的集成成员（含交互项的线性模型、弹性网络、含交互项的弹性网络）；add_outcome_diagnostic("RROC") 要求为结果模型输出回归 ROC 曲线诊断；三行 add_effect_model() 指定了效应曲面模型（即二阶回归）的集成成员；add_effect_diagnostic("RROC") 为效应曲面输出同样的诊断；两行 add_moderator() 决定了调节变量的呈现方式——"Stratified" 用于离散变量（x2, x3），"KernelSmooth" 用于连续变量（x1, x4, x5）；最后 add_vimp(sample_splitting = FALSE) 要求计算变量重要性，并且不使用额外的样本分割（即复用已有的交叉验证结构）。

MCATE 与 PCATE 的差别在这里体现得很清楚：add_moderator() 每次只列出一个调节变量，报告的是边际条件平均处理效应（MCATE）——把其他所有协变量边际化掉，只留下这个变量的效应曲线。这与「把其他变量控制住」的部分 CATE（PCATE）不同；PCATE 若不假设处理与协变量联合随机化，就没有令人满意的因果解释。

核平滑（kernel smoothing）在这里起什么作用？二阶回归的输入是伪结局 \(\hat\psi(Z)\)，它噪声很大（因为它包含逆概率加权项）。直接用散点去看是看不出趋势的。核平滑／局部线性回归的作用，是在协变量取值域上做带偏差校正的局部加权平均，把噪声压下去、把真实的效应曲线 \(\tau(x)\) 显现出来，同时给出稳健的标准误（这正是 nprobust 的 robust bias-corrected inference）。

估计模型

要真正执行估计，下面这些代码就足够了。请注意，由于在文档开头配置协变量名称的方式，这里的写法因为大量花括号（{}）与叹号（!!）而显得稍微复杂一些。

prepped_data <- data %>%
  attach_config(hte_cfg) %>%
  make_splits(uid, .num_splits = 3) %>%
  produce_plugin_estimates(
    y,
    a,
    x1, x2, x3, x4, x5,
  ) %>%
  construct_pseudo_outcomes(y, a)

results <- prepped_data %>%
  estimate_QoI(x1, x2, x3, x4, x5)

背景与解释

那两行 Error 要不要紧？信息是 factor x2 has new levels 1，含义是：某个模型在训练集上从未见过 x2 == 1 这个水平，于是当它拿到含有该水平的验证折去预测时，model.frame 无法构造设计矩阵而报错。回顾模拟数据：x2 的水平 1 的抽样概率只有 1/100，在 500 人、3 折交叉验证下，某一折的训练集里完全可能一个水平 1 都没有。

在真实医学数据中，这对应一个非常常见的困境：罕见亚型、罕见基因型、或某个中心只入组了个位数患者。tidyhte 对此的处理是优雅降级——该基学习器在受影响折上被丢弃（集成权重相应调整），其余部分继续运行，最终仍然产出了完整的 839 行结果。但如果你的研究问题恰恰是关于这个罕见亚群的，那么请不要忽视它：这意味着该亚群的效应估计缺乏数据支撑，应在论文中明确说明，或考虑合并稀疏水平（例如把 x2 == 1 与其他水平合并）。

怎么读这张结果表？六列分别是：estimand（目标量类别，如 MCATE / SATE / VIMP / SL risk / RROC）、term（所指的协变量或模型名）、value（数值型的细分位置，连续型调节变量用这一列）、level（分类型的细分位置，离散型调节变量用这一列）、estimate（点估计）、std_error（标准误）。

上表前 10 行是 x1 的 MCATE：value 从 −1.80 递增到 −1.16（协变量 x1 的取值分位点），对应的 estimate 从 3.22 递减到 2.56，std_error 约 0.13–0.17。效应随 x1 增大而下降，且标准误远小于效应量，说明这条下降趋势是清晰的——与模拟数据的真实结构一致。

顺带一提：这 839 行里，x1/x4/x5 各占 100 个网格点（300 行），x2 有 4 个水平、x3 有 3 个水平（7 行），再加上 VIMP、SL 系数、SL 风险、RROC 等诊断行与 ATE 行。

绘图

绘制集成系数

filter(results, grepl("SL coefficient", estimand)) %>%
  mutate(level = factor(level, levels = c("Control Response", "Treatment Response"))) %>%
  ggplot(aes(
    x = reorder(term, estimate),
    y = estimate,
    ymin = estimate - 1.96 * std_error,
    ymax = estimate + 1.96 * std_error
  )) +
  geom_abline(intercept = 0, slope = 0, linetype = "dashed") +
  geom_pointrange() +
  expand_limits(y = 0) +
  scale_x_discrete("Model name") +
  scale_y_continuous("Coefficient in SuperLearner Ensemble") +
  facet_wrap(~level) +
  coord_flip() +
  ggtitle("SuperLearner Ensemble") +
  theme_minimal()

背景与解释

怎么读这张 SuperLearner 集成系数图？纵轴（翻转后显示为横轴方向）列出所有基学习器的名字，横轴是它在集成中的系数（即权重），误差棒是 ±1.96 倍标准误。两幅小图分别对应「对照组结果模型（Control Response）」与「治疗组结果模型（Treatment Response）」——因为 T-learner 需要在两组各拟合一个结果模型，所以各有一次独立的集成。

读图要点：① 所有系数非负，且总和约为 1（这是 SuperLearner 的约束最小二乘要求）；② 系数接近 0 的学习器基本被「淘汰」，说明交叉验证认为它对预测没有增量贡献；③ 拿到最大权重的那一两个学习器，反映了数据中最主要的信号形式——若 SL.glm_All（含全部主效应的线性模型）权重最高，提示关系近似线性；若 SL.glmnet_... 或含交互项的版本权重高，提示存在需要正则化或交互的结构；④ 误差棒跨越 0 的系数说明「这个学习器要不要进来」在统计上并不确定，这是正常的，因为你关心的不是单个权重，而是集成整体的预测性能。

不要把这张图当作「哪个模型最好」的统计检验。它是一个诊断工具，用途是让你确认：集成确实在工作（不是退化成单一模型），并且你加入的基学习器里没有被完全浪费的。

背景与解释

怎么读这张风险（risk）图？横轴是各基学习器的交叉验证风险——对连续结局而言就是折外均方误差（CV MSE）。三个分面分别是：对照组结果模型、治疗组结果模型、以及效应曲面（即二阶回归，对伪结局的平滑模型）。

三条实用判读规则：① 风险越小越好，最右侧（翻转后靠上）的是表现最好的学习器；② 把各学习器的风险与「集成整体」的风险作比较——如果集成的风险已经接近最好的单个学习器，说明集成工作正常；反过来，如果每个学习器的风险都很高、彼此差别也很大，提示这个结局很难预测，此时效应估计的方差也会偏大；③ 第三幅「Effect Surface」分面尤其值得看：它衡量的是二阶平滑模型对伪结局的拟合好坏。若这里风险很高，说明 MCATE 曲线噪声大、异质性信号弱，你对「效应随某变量变化」的结论就要更保守。

把这张图与上一张系数图对照着看会更清楚：通常风险最低的学习器会拿到最高的系数权重。若出现「风险低但权重接近 0」的情况，往往是因为它与另一个学习器高度相关（共线性），贡献被后者吸收了——这本身不是问题。

医学解读提示：风险值是尺度依赖的（结局若以克为单位，MSE 就是「克²」），所以不要跨结局、跨研究比较风险绝对值；只在同一张图内部横向比较即可。

  ggtitle("Regression ROC Curves") +
  theme_minimal()

背景与解释

RROC 图（Regression Receiver Operating Characteristic）怎么看？它是 ROC 曲线在回归问题上的类比。设想给模型的预测值加上一个平移量 s：当 s 很大时模型系统性高估，当 s 很小时系统性低估。对每个 s，我们计算总的「高估量（over-estimation，正残差之和）」与「低估量（under-estimation，负残差绝对值之和）」，把前者画在横轴、后者画在纵轴，就得到这条曲线。

判读规则：曲线越贴近坐标轴原点方向越好。一个理想模型在 s = 0 处就同时达到高估量与低估量都很小，曲线会紧紧贴着两条轴。反之，若曲线明显向外鼓出、离原点很远，说明残差的整体量级很大，模型预测精度有限。曲线上的圆点标记的是 s = 0（即模型不做任何平移）时的位置，也就是模型原始状态下的高估/低估情况——请重点看这个点。

更重要的诊断信息是不对称性：如果 s = 0 处「高估量」远大于「低估量」，说明模型系统性偏高，反之则系统性偏低。在临床预测模型的语境下这很关键——一个系统性高估疗效的模型，会让基于它做的获益-风险评估过于乐观。coord_flip() 只是把坐标轴翻转以便阅读，不改变这个判断。

本图同样按「对照组结果模型 / 治疗组结果模型 / 效应曲面」三个分面呈现。看第三个分面时请记住：伪结局本身噪声很大，因此效应曲面的 RROC 通常比前两个分面「难看」一些，这是正常的，不必过度紧张。

绘制变量重要性（VIMP）

ggplot(filter(results, estimand == "VIMP")) +
  geom_abline(intercept = 0, slope = 0, linetype = "dashed") +
  geom_pointrange(
    aes(
      x = term,
      y = estimate,
      ymin = estimate - 1.96 * std_error,
      ymax = estimate + 1.96 * std_error
    )
  ) +
  expand_limits(y = 0) +
  scale_x_discrete("Covariate") +
  scale_y_continuous("Reduction in R² from full model") +
  coord_flip() +
  ggtitle("Covariate Importance") +
  theme_minimal()

背景与解释

VIMP 图在临床上该怎么解读？横轴的数值是「把某个协变量从效应联合模型中去掉后，\(R^2\) 下降了多少」（Reduction in \(R^2\) from full model），误差棒是 ±1.96 倍标准误。换句话说，它衡量的是这个变量对解释「疗效差异」贡献了多少，而不是对解释「结局本身」贡献了多少——这一点极易混淆。

判读要点：① 数值越大，说明该变量越能解释疗效的异质性；② 只有误差棒完全在 0 右侧的变量，才可以说「有证据表明它修饰了疗效」——误差棒跨过 0 的变量（本例中预期是 x3、x4、x5）没有统计学证据支持其效应修饰作用；③ VIMP 可以为负（模型加入该变量后反而变差），此时通常直接视为「无贡献」。

与 MCATE 图配合使用的思路是：VIMP 负责「筛选」（哪些变量值得看），MCATE 负责「刻画」（效应怎么随它变）。先扫一眼 VIMP 找出有证据的效应修饰因子，再去读对应变量的 MCATE 图，是最有效率的阅读顺序。

两个必须避免的误读。第一，VIMP 小不等于该变量不重要——它可能是很强的预后因素（能预测结局），却不是预测性因素（不能预测疗效差异）。区分「预后因子（prognostic factor）」与「预测因子（predictive factor）」是精准医学的核心，VIMP 衡量的是后者。第二，VIMP 是联合模型的指标：两个高度相关的变量（例如 BMI 与腰围）可能各自 VIMP 都不显著、重要性被对方稀释，此时不能断言二者都不重要。

背景与解释

怎么读连续变量的 MCATE 曲线？实线是效应 \(\hat\tau(x)\) 的边际条件平均处理效应曲线，阴影带是逐点的 95% 置信带（estimate ± 1.96 × std_error），水平虚线是「无效线」（\(\tau = 0\)）。横轴是该协变量的取值（100 个分位数网格）。

三张图对照着看：x1 的曲线明显单调下降且整条曲线连同置信带都在 0 以上，说明疗效随 x1 增大而减弱，但在整个观测范围内仍然有效；x4 与 x5 的曲线基本水平，与模拟数据的真实结构一致（这两个变量不参与效应异质性）。

三个读图纪律。① 看趋势，不要看单点：平滑曲线上任意一点都不构成一次假设检验，逐点看会产生大量假阳性；要看整条曲线是否偏离水平，以及置信带是否整体偏离无效线。② 警惕两端：核平滑在数据稀疏的尾部（最低/最高的几个分位数）方差会明显变大，置信带变宽是正常现象，那里的视觉「翘起」往往是噪声而非真实信号。③ 只有当某一段区间整段的置信带都不与无效线相交时，才可以有把握地说「在这个取值范围内，处理是有效（或有害）的」。

临床表述示例：「在本试验人群中，治疗的绝对获益随基线 x1 升高而降低（从 x1≈−1.8 时的约 3.2 单位降至 x1≈1.2 时的约 2.6 单位），但在全部观测范围内获益均为正。」——注意这里描述的是效应如何变化，而不是「把 x1 降到某个阈值以下就能获益更多」，后者需要另外的因果假设与独立验证。

背景与解释

怎么读离散变量的分层 MCATE 图？离散变量不做平滑，而是分层（stratified）：在该变量的每一个水平上直接给出条件效应的点估计与 95% 置信区间，因此用点加误差棒（geom_pointrange）而不是曲线加阴影带。

判读要点：① 先看每个水平各自的区间是否与无效线（虚线）相交——以此判断「在这个亚组内治疗是否有效」；② 再比较各水平之间——如果两个水平的置信区间几乎不重叠，提示存在效应修饰；③ 水平 1 的区间明显更宽（在 x2 图上尤其明显），这正是上文 factor x2 has new levels 1 那两行报错的后果：该水平样本极少，估计极不精确。请不要把「区间宽」误读为「效应特别大或特别小」。

关于亚组比较的统计陷阱：本图给出的每个区间都是亚组内部的置信区间，不是亚组间差异的置信区间。若想正式检验「水平 2 与水平 4 的疗效是否不同」，需要对两者之差构造估计量与标准误（例如用 estimate_QoI 的结果做对比，或在 bootstrap 框架下处理），而不能仅凭两个区间是否重叠来判断——区间轻微重叠时差异仍可能显著，反之亦然。

这也正是 HTE 分析相对传统亚组分析更可靠的地方：整个流程是交叉拟合的，各水平的效应估计不会因为「我们挑了看起来差异最大的亚组」而产生选择偏差；但反过来，用本图「发现」的亚组去下确证性结论，仍然需要在独立数据中验证。
