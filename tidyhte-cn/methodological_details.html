摘要

在这篇文章中，我们介绍用于从观察性或实验性数据中估计异质性处理效应（HTE）的 tidyhte 包。该包实现了 Kennedy（2020）的方法，并通过 tidy 风格的用户接口将其呈现出来。支撑本包的设计原则是：

  1. API 应当 tidy-friendly（对 tidyverse 友好）；
  2. 分析应当易于通过微小改动来复现；
  3. 为干扰函数指定复杂集成应当直截了当；
  4. 合理的诊断应当易于获取。

结果的绘图与格式化则留给最终使用者自行定制。

概述

本文档详述 tidyhte 如何构造异质性处理效应的估计。它将展示本包的诸多特性，并讨论支撑这些特性的数学原理。

在简要介绍 Kennedy（2020）的 HTE 估计方法之后，行文结构大体遵循 tidyhte 的估计 API：首先讨论交叉验证折的构造，然后介绍干扰函数估计，接着进行 Kennedy（2020）提出的「伪结局」构造，最后演示几类目标量（Quantities of Interest）的计算——也就是最终使用者真正想要的统计量。

预备知识

问题设定

我们的数据由三元组 \(Z_i = (X_i, A_i, Y_i)\) 定义，其中 \(X \in \mathbb{R}^d\)、\(Y \in \mathbb{R}\)、\(A \in \{0, 1\}\)。定义如下干扰函数（nuisance function）：

\[ \pi(x) \equiv \mathbb{P}(A = 1 \mid X = x) \\ \mu_a(x) \equiv \mathbb{E}(Y \mid X = x, A = a) \]

异质性处理效应定义为处理组与对照组条件期望之差，即 \({\tau(x) \equiv \mu_1(x) - \mu_0(x)}\)。全文将始终维持以下假设：

  1. 一致性（Consistency）：\(Y_i = Y_i(A_i)\)
  2. 无未测量混杂（No Unmeasured Confounding）：\(A \perp (Y(1), Y(0)) \mid X\)
  3. 正值性（Positivity）：\(\epsilon \leq \pi \leq 1 - \epsilon\)，以概率 \(1\) 成立

在这些假设之下，\(\tau(x) = \mathbb{E}[Y(1) - Y(0) \mid X = x]\)。

背景与解释

这三条假设在流行病学里分别对应什么？

① 一致性 \(Y_i=Y_i(A_i)\)：你观测到的结局，就是这个病人实际接受的那种治疗所对应的潜在结局。它通常与 SUTVA（stable unit treatment value assumption）一起被提及：要求个体的结局不受其他个体接受何种处理的影响（无干扰），且「处理」本身是定义明确的单一版本。在传染病疫苗试验、群-randomized 试验、或存在同伴效应的场景中，无干扰假设会被违反——此时需要专门的整群／溢出效应方法。

② 无未测量混杂 \(A\perp(Y(1),Y(0))\mid X\)：这是观察性研究中最关键、也最脆弱的一条。它要求在观测到的协变量 \(X\) 之后，医生「给不给这个药」的决定与病人的潜在结局无关。它等价于流行病学中说的「可忽略性（ignorability）／可交换性（exchangeability）／无残余混杂」。它无法用数据检验——你可以检验协变量平衡，但平衡只保证已测量的混杂被处理掉了。因此务必用有向无环图（DAG）梳理混杂路径，并做敏感性分析（如 E-value）评估未测量混杂需要多强才能解释掉你的结论。

③ 正值性 \(\epsilon\le\pi(x)\le1-\epsilon\)：每一种协变量组合的病人，都有实质性的机会被分到治疗组或对照组。违反正值性在临床上极其常见：例如某靶向药只用于晚期患者，那么早期患者的 \(\pi(x)\approx0\)；此时对早期患者的疗效估计依赖外推，极其不稳定。实操建议：画倾向得分的分布直方图／镜像直方图，检查两组是否重叠；对 \(\hat\pi\) 极端（如 < 0.05 或 > 0.95）的个体，考虑修剪（trimming）或明确限定目标人群（如「临床 equipoise 人群」）。

在本文余下部分，我们将使用一个基于 Horst、Hill 与 Gorman（2020）的 penguins（企鹅）数据集构建的半模拟示例。我们设想一项随机分配的营养干预，希望测量它对体重的因果效应。我们还有一个方差更小的测量指标：观察期内平均每日食物摄入量。Gentoo 企鹅会因这项干预平均增重，Adelie 企鹅则相反；Chinstrap 企鹅的平均体重变化为零。

penguins <- within(penguins, {
  id <- 1:n
  propensity_score <- 0.5
  treatment <- rbinom(n, 1, propensity_score)
  tau <- 0.2 * (species == "Gentoo") - 0.2 * (species == "Adelie") + rnorm(n, sd = 0.05)
  food_consumed_g <- rnorm(n, 500, 5) * (1 + tau * treatment)
  body_mass_g <- body_mass_g * (1 + tau * treatment)
})
背景与解释

这段代码在做什么？它把真实的企鹅形态学数据（喙长、喙深、鳍长、体重、物种、岛屿、性别、年份）当作「协变量」，再人为地叠加一个随机分配的处理 treatment（随机化概率 0.5）与一个已知的真实效应 tau：Gentoo 企鹅 +20%，Adelie 企鹅 −20%，Chinstrap 企鹅 0%，另加一个 sd = 0.05 的个体噪声。

结局有两个：food_consumed_g（平均每日食物摄入克数，噪声小，因为 rnorm(n, 500, 5) 的变异系数只有 1%）与 body_mass_g（体重克数，噪声大，因为要用真实体重乘以效应）。这样的设计正好演示了方法部分要说明的一件事：结局的噪声水平直接决定效应估计的精度——同一个真实效应，在「低噪声结局」上会被清晰地检测出来，在「高噪声结局」上则可能淹没在置信带里。

因为是随机分配，倾向得分 \(\pi(x)=0.5\) 是已知的（下文中用 add_known_propensity_score() 告知包），这为许多目标量带来无偏性。

方法概览

我们首先介绍下面的「DR-Learner」算法：

DR-learner 算法由三个主要步骤构成：

  1. 给定：在别处训练好的干扰函数估计 \(\left(\hat{\pi}, \hat{\mu}_0, \hat{\mu}_1\right)\)；
  2. 构造「伪结局」（pseudo-outcome）：该量是对已给干扰函数估计量做一个变换：

    \[ \hat{\psi}(Z) = \frac{A - \hat{\pi}(X)}{\hat{\pi}(X)(1 - \hat{\pi}(X))} \left( Y - \hat{\mu}_{A}(X) \right) + \hat{\mu}_{1}(X) - \hat{\mu}_{0}(X) \]

  3. 第二阶段回归：对变换后的伪结局构造一个平滑模型：

    \[ \hat{\tau}_{dr}(x) = \hat{\mathbb{E}}[\hat{\psi}(Z) \mid X = x] \]

该算法的写法假定干扰函数的估计是在另外的数据上训练的，因此可以被视为固定的。最简单的实现方式就是样本分割（sample-splitting）程序，之后再把各次分割的结果取平均。

关键性的结果——Kennedy（2020）的定理 2——表明：第二阶段回归的误差，将与「真实个体处理效应对协变量 \(X\) 做神谕（oracle）回归」的误差相匹配，相差的因子取决于两个干扰函数估计误差的乘积（即 \(\pi\) 的误差与 \(\mu\) 的误差之积）。

当第二阶段回归较为简单时——例如在由 \(X\) 定义的单元格内取亚组均值——DR-Learner 会像 AIPW 估计量那样继承其无偏性与有效性（Robins、Rotnitzky 与 Zhao，1995；Van der Laan、Laan 与 Robins，2003；Tsiatis，2006；Tsiatis 等，2008；Chernozhukov 等，2018）。

Kennedy（2020）的逼近结果应用于对这个变换后结局的回归，为目标量的估计提供了很大的灵活性。我们将利用这一事实，允许像「在个体因果效应本身上估计」那样去估计各种各样的模型：例如，变量重要性度量就建立在「各种第二阶段回归都将是准确的」这一假设之上。

背景与解释

伪结局（pseudo-outcome）到底是什么？为什么它这么重要？

个体处理效应 \(Y(1)-Y(0)\) 永远无法被观测——这就是因果推断的根本问题（Holland 称之为「the fundamental problem of causal inference」）。传统的回归思路是绕开它：拟合 \(\mu_1-\mu_0\)。而伪结局的思路是直面它：为每个个体构造一个数 \(\hat\psi(Z_i)\)，使得它在给定 \(X\) 时的条件期望近似等于真实的 CATE：

\(\mathbb{E}[\hat\psi(Z)\mid X=x]\approx\tau(x)\)

于是「估计 CATE 函数」就变成了一个普通的回归问题：把 \(\hat\psi\) 当成结局，对 \(X\) 做回归即可。所有现成的回归工具——线性模型、随机森林、核平滑、变量重要性——都可以直接用上。这就是为什么 tidyhte 能对「永远看不见的个体疗效」做变量重要性分析。

公式结构解读。右边第二项 \(\hat\mu_1(X)-\hat\mu_0(X)\) 是「结果回归之差」，也就是 T-learner 的插件估计，它平滑但可能有偏；第一项 \(\frac{A-\hat\pi(X)}{\hat\pi(X)(1-\hat\pi(X))}(Y-\hat\mu_A(X))\) 是「逆概率加权残差」，无偏但方差大。把两者相加，就得到了 AIPW 估计量（Robins 等，1995）——它兼具无偏性与效率。这也是「双重稳健」名字的由来：只要结果模型与倾向得分模型中任意一个正确，估计就一致。

定理 2 的「乘积」结构为什么是决定性的？它保证二阶回归的误差 ≈ 神谕回归误差 + \(O(\lVert\hat\pi-\pi\rVert\cdot\lVert\hat\mu-\mu\rVert)\)。由于是乘积，只要两个模型各自以 \(n^{-1/4}\) 的速度收敛，乘积就是 \(n^{-1/2}\)——比参数速率还快，不会拖累推断。这正是「可以用机器学习估计干扰函数，却仍然得到 \(\sqrt n\)-一致的效应估计与有效置信区间」的理论基础。

但这一切都建立在交叉拟合之上。如果不做样本分割、直接用同一批数据训练 \(\hat\pi,\hat\mu\) 再做二阶回归，机器学习模型的过拟合会与残差产生依赖，「乘积项」不再可忽略，置信区间就会失效。下一节的 make_splits() 与再下一节的交叉验证，正是为此而设。

设计原则

tidyhte 包的基本思想是：把 HTE 分析拆解成几个彼此独立的部分，然后按需把它们组合起来。第一步是定义一个配置对象（或称「配方」recipe），在高层次上描述 HTE 估计应当如何进行。在估计阶段，再指出具体关注的变量。这种设计使得以极低的开销重复非常相似的分析成为可能。这在以下情形中很有用：使用者希望在多个结局上探索异质性，或者存在多个特别关注的处理对比。这些分析往往具有共同特征——例如，用于干扰函数估计的集成中会包含相似的模型类别。

同样重要的是，所提供的方法支持对以下常见数据结构的使用：

聚类数据（Clustered data）

真实世界数据的一个常见特征是：处理可能是聚类的。换言之，如果一个单位接受了处理，那么可能存在其他单位也因而更可能接受处理。这类设计的一个典型例子是：以村落或乡镇为单位分配处理，但测量发生在个体层面。正如 Abadie 等（2023）所讨论的，这种设计意味着标准误应当按处理被分配的层级进行聚类调整。tidyhte 包把聚类作为一等公民（first class citizen）来支持，所有由此产生的估计都会基于这种聚类得到恰当的统计不确定性估计。在实践中，最终使用者只需在构造交叉验证折（make_splits()）时指定个体单位标识，此后所有分析都会自动加以考虑。

背景与解释

这在医学研究里就是「整群随机试验（cluster-randomized trial）」。当干预是在群组层面分配的（按医院、按村、按班级、按社区），同一群组内个体的结局与处理状态相关，若仍按个体计算标准误，会严重低估不确定性（因为有效样本量其实接近群组数而非个体数）。

tidyhte 的做法对你来说很省事：只要在 make_splits(unit_id, ...) 里给出群组/个体标识，后续所有估计的标准误都会按该层级聚类。这也顺便解决了另一个隐患——同一个体的多行数据会被分到同一个交叉验证折中，避免了「训练集里已经见过这个人」的信息泄漏。对纵向／重复测量数据（一个人多次随访），这一点同样重要：请务必把个体 ID 传进去。

提醒：聚类调整的标准误需要足够多的群组（经验法则：至少 30–40 个群）才可靠；群组很少时，应考虑小样本校正或随机化推断。

人群权重（Population weights）

实践中使用的设计还有一个常见特征：它们来自的样本，并不能完美代表其所抽取的更大人群。解决这一问题最常见的办法，是使用权重让样本更接近人群。tidyhte 同样支持这一点：只需在估计模型时指定权重（produce_plugin_estimates()），后续分析就会恰当地把权重纳入考虑。

背景与解释

对应流行病学中的「标准化」与「抽样权重」。当你的样本是非概率抽样或存在选择性参与（例如志愿者队列、单中心数据、失访），直接外推到目标人群会有偏。此时的标准做法是：先用权重把样本「校准」回目标人群（如分层后按人口构成加权、或基于倾向参与概率加权），再估计效应。

tidyhte 里这对应 PATE（人群平均处理效应）与 SATE（样本平均处理效应） 的区分：不指定权重时报告的是 SATE；指定权重后，估计的则是加权后目标人群上的 PATE。在实验数据教程的 ATE 一节里，我们用 grepl("SATE|PATE", estimand) 同时筛选这两者，但只出现了 SATE——正是因为没有提供权重。

两个实务提醒：权重只影响估计目标（把结果外推到哪个人群），不能修复识别问题——若某类人群在样本中完全缺失（\(\pi\) 或参与概率为 0），再怎么加权也无济于事。此外，权重方差过大会显著放大标准误，必要时请对权重做修剪（trimming / winsorizing）。

Recipe API

为了逐步建立关于「HTE 应当如何估计」的定义，tidyhte 提供了一个 API 来渐进式地构建配置对象。basic_config 函数创建一个骨架式（bare-bones）配置，它只包含用于各干扰函数的线性模型以及若干诊断。

cfg <- basic_config() %>%
  add_known_propensity_score("propensity_score") %>%
  add_outcome_model("SL.glmnet", alpha = c(0.0, 1.0)) %>%
  add_moderator("Stratified", species, island, sex, year) %>%
  add_moderator("KernelSmooth", bill_length_mm, bill_depth_mm, flipper_length_mm) %>%
  add_vimp(sample_splitting = FALSE)

由于研究对象是一项实验性干预，倾向得分是已知的。使用这个已知的倾向得分可以为许多目标量带来无偏性（尽管这可能会牺牲一部分效率）。在本例中，除了 SuperLearner 集成中默认包含的线性模型之外，我们还加入了一个弹性网络回归（Zou 与 Hastie，2005）。我们在 LASSO 与岭回归之间扫描一系列混合参数，把每一个由此产生的模型都投入集成。这意味着 SuperLearner 将执行模型选择与平均，以识别出最优的超参数取值（Van der Laan、Polley 与 Hubbard，2007）。此外，我们定义了所有感兴趣的调节变量，以及其结果应当如何被收集与展示。离散型调节变量只在其每个水平上取分层平均，而连续型调节变量则使用局部多项式回归（Fan 与 Gijbels，2018；Calonico、Cattaneo 与 Farrell，2019）。最后，我们加入了 Williamson 等（2021）的变量重要性度量。

配置完成后，就可以把它附加到数据集上。

penguins <- penguins %>% attach_config(cfg)
背景与解释

为什么要把「配置」与「数据」分开？这是本包最重要的设计决策，也是它对医学研究流程最友好的地方。配置（recipe）描述的是方法学选择——用哪些学习器、怎么交叉验证、报告哪些目标量、连续变量怎么做平滑；而「具体变量」（哪个是结局、哪个是处理、哪些是协变量）则留到运行时才指定。

这带来两个直接好处：① 一份方案，多处复用。「在 12 个结局上各跑一遍同样的 HTE 分析」只需要一个循环，方法学选择完全一致，不会出现「第 7 个结局忘了加 SL.glmnet」这类复制粘贴错误。② 便于预注册与审阅。配置对象可以单独保存、版本控制、附在统计分析计划（SAP）里，审稿人能够清楚看到你做了哪些方法学选择。

add_moderator("Stratified", ...) 与 add_moderator("KernelSmooth", ...) 的区分值得记住：分类变量走「分层」（直接在该水平取平均，无平滑、无外推，因此稳健）；连续变量走「核平滑」（局部多项式回归，能显示效应随剂量/生物标志物连续变化的形状）。把连续变量当分类变量强行分组，会损失信息并引入任意的 cut-point；反过来对分类变量做平滑则没有意义。请按变量的测量尺度正确选择。

交叉验证

按照本文所述流程开展异质性处理效应分析的第一步，是定义如何构造用于交叉验证的切分。tidyhte 的做法是使用分块（blocking）方法来构造切分，这比纯粹随机切分带来更低的方差。现有的切分生成方法通常会提供「基于二分类结局做分层」的选项，以确保即使结局非常稀疏，各切分中也都有结局的变异。例如，SuperLearner::SuperLearner.CV.control 就提供了这样一个选项。

tidyhte 中相应的函数是 make_splits。该函数接收一个数据框，并确定一组与所提供的单位标识符及切分数相符的切分。如果还向该函数提供了协变量，它就会把这些协变量纳入分块设计，使用 Higgins、Sävje 与 Sekhon（2016）的方法（由 quickblock 包实现）来构造随机切分。

关于这种用于交叉验证分层（strata）的分块方式，有几点方法学上的说明。简而言之：所构造的块，其大小至少等于将要使用的切分数。构造这些块的目标是最小化块内单位之间的距离（距离基于所提供的协变量，采用欧氏距离）。当有多行共享同一个标识符时，分块是对该标识符内协变量的平均值进行的；随后，具有相同标识符的行会被分配到同一个切分中。关于块构造的精确细节可参见 Higgins 等（2016）。在每个块内部，会构造一个切分 ID 向量，其边际分布尽可能接近切分上的均匀分布（误差仅来自整数除法）。这组切分 ID 随后在块内被随机置换。

与 tidy 语义一致，函数返回的是原始数据框，但额外增加了一列 .split_id 来表示这些新构造的切分，以及若干用于记账的属性（例如标识符的列名）。由于返回的对象与传入的对象是同一类型，因此可以很方便地用 dplyr 串联命令。

penguins <- penguins %>% make_splits(id, species, sex, flipper_length_mm, .num_splits = 3)

控制台输出（保留英文原文）

## `num_splits` must be even if VIMP is requested as a QoI. Rounding up.

## Dropped 11 of 344 rows (3.2%) through listwise deletion.

请注意，tidyhte 通过成列删除（listwise deletion）优雅地处理缺失数据。目前尚不支持更先进的插补方法。

背景与解释

那两行提示信息分别说了什么？

第一行 `num_splits` must be even if VIMP is requested as a QoI. Rounding up.：你请求了 3 折切分，但 VIMP 的计算额外需要在两半样本上分别拟合「全模型」与「去掉某变量的模型」，因此切分数必须是偶数。包自动向上取整（3 → 4），并给出提示。这不是错误，只是告诉你实际使用的是 4 折。

第二行 Dropped 11 of 344 rows (3.2%) through listwise deletion.：企鹅数据中有 11 行（3.2%）在本次分析用到的变量上存在缺失，已被整行删除。

关于缺失数据的三点医学研究提醒。① 成列删除（完全病例分析，complete-case analysis）只在数据完全随机缺失（MCAR）时才是无偏的；若缺失与结局或处理相关（MAR/MNAR），3.2% 的删除也可能引入偏倚，且样本量越小、缺失比例越高，风险越大。② 本包当前不支持多重插补（MI）。若你的数据缺失比例较高，推荐的变通做法是在多重插补后的每一个数据集上独立跑一遍 tidyhte，再按 Rubin 规则合并效应估计与标准误——请注意诊断类输出（如 VIMP、RROC）的合并需要更谨慎。③ 无论采用哪种方式，都请报告缺失的比例与模式，并比较纳入/排除缺失者的基线特征。

为什么交叉验证要用「分块」而不是纯随机？纯随机切分会让各折之间在协变量分布上出现偶然的不平衡；当样本量不大或协变量分布偏斜时，某一折可能缺少重要的协变量组合，导致该折上训练的模型外推严重。分块（blocking）先把相似的个体聚成小块（按协变量的欧氏距离），再在块内随机分配折号，从而保证每一折都覆盖各类协变量 profile。这与实验设计中的区组随机化（blocked randomization）是同一个思想。

干扰函数估计

诸如倾向得分与结果回归这样的干扰函数估计，通常由 SuperLearner 库来处理。通过 tidyhte 的 API，指定一整套带有多样化超参数的模型被大大简化了。若要用 SuperLearner 的语法来指定一个交叉验证学习器，则需要多得多的样板代码：

learners <- create.Learner(
  "SL.glmnet",
  tune = list(
    alpha = c(0.05, 0.15, 0.2, 0.25, 0.5, 0.75)
  ),
  detailed_names = TRUE,
  name_prefix = paste0("SLglmnet")
)

CV.SuperLearner(label, covariates, SL.library = learners$names)

相比之下，tidyhte 的 Recipe API 只需要下面这一行：

add_outcome_model(cfg, "SL.glmnet", alpha = c(0.0, 0.25, 0.5, 0.75, 1.0))
penguins <- penguins %>% produce_plugin_estimates(
  # 结局
  food_consumed_g,
  # 处理
  treatment,
  # 协变量
  species, island, sex, year, bill_length_mm, bill_depth_mm, flipper_length_mm
)
背景与解释

两段代码的对比说明了什么？上方是原生 SuperLearner 的写法：先调用 create.Learner() 手动枚举超参数网格、为生成的模型命名、再取出 learners$names 传给 CV.SuperLearner()；下方 tidyhte 只需一行 add_outcome_model(cfg, "SL.glmnet", alpha = c(0.0, 0.25, 0.5, 0.75, 1.0))——超参数的笛卡尔积、命名、集成权重的学习，全部由包自动完成。

对医学研究者的实际意义：方法学复杂度被封装了，但你仍然拥有全部控制权。你依然需要决定「往集成里放哪些学习器」这个实质性选择，而不再是「怎么写样板代码」这种技术性负担。

选择学习器的三条经验法则。① 保证多样性。集成的价值来自候选模型的差异，只放三个高度相似的线性模型没有意义——至少要覆盖「简单参数模型 + 正则化模型 + 至少一个灵活的非线性模型」。② 样本量小（如 \(n<200\)）时保持克制。随机森林、梯度提升在小样本上很难稳定，交叉验证风险反而更高；此时线性模型加正则化通常更可靠。③ 结局噪声大时不要指望奇迹。若所有学习器的 CV 风险都接近「用均值预测」的基线，说明协变量对结局几乎没有预测力，此时效应估计的方差必然很大——这是数据的性质，不是模型的过错。

伪结局构造

一旦干扰函数被估计出来，接下来的事情就只是把这些结果组合成恰当的伪结局。对于典型的 HTE 估计，我们所关心的伪结局就是 Kennedy（2020）所分析的那个：平均处理效应的未中心化影响函数（Robins、Rotnitzky 与 Zhao，1995）。

penguins <- penguins %>% construct_pseudo_outcomes(food_consumed_g, treatment)
背景与解释

「未中心化影响函数（uncentered influence function）」这个名字值得拆开讲。在半参数理论中，一个估计量 \(\hat\theta\) 的影响函数 \(\varphi(Z)\) 刻画的是：单个观测的微小扰动会对估计量造成多大影响。它有两条关键性质：\(\hat\theta - \theta = \frac{1}{n}\sum_i \varphi(Z_i) + o_p(n^{-1/2})\)，且 \(\mathrm{Var}(\hat\theta)=\mathrm{Var}(\varphi)/n\)。

也就是说，影响函数既是「估计量的一阶展开」，又是「方差的来源」。所谓「未中心化」，是指这里取的是 \(\varphi(Z_i)\) 本身而不是 \(\varphi(Z_i)-\theta\)；把它当作伪结局时，其条件期望正好是 CATE \(\tau(x)\)，非常自然。

这一视角解释了 tidyhte 的一个关键优势：因为伪结局就是影响函数，对它做任何平滑得到的估计量，都可以直接从伪结局的方差导出标准误——这正是 std_error 那一列的计算依据。你不需要为每一种新的目标量（MCATE、分层效应、VIMP）单独推导一套方差公式，它们共享同一个影响函数基础。这也是为什么本包能「像在个体疗效上做回归一样」去估计各种目标量，却不牺牲推断的有效性。

目标量（Quantities of Interest）

最后就来到了分析中最激动人心的部分：效应被估计出来，并被放进图表中。

tidyhte 的设计选择是：把绘图留给最终使用者，而只返回一个包含所有被请求目标量的整洁 tibble。本包关注以下几类目标量：

  • 边际条件平均处理效应（MCATEs）：即文献中标准的条件平均处理效应（CATEs），其中除一个协变量外的所有协变量都被边际化掉，从而为单个协变量的一个水平提供一个平均效应。这与「部分」CATE（PCATE）形成对照，后者以某种方式「控制住」了其他变量。若不假设处理与协变量的联合随机化，PCATE 无法提供令人满意的因果解释。
  • 变量重要性（VIMP）：使用 Williamson 等（2021）的方法，tidyhte 计算每个调节变量对「异质性效应联合模型」均方误差总体下降的贡献。
  • 诊断（Diagnostics）：为 tidyhte 估计过程中拟合的所有模型提供了种类繁多的诊断。它们既包括均方误差、AUC 这样的单值摘要，也包括完整的受试者工作特征曲线，以及 SuperLearner 集成中的系数。
results <- penguins %>%
  estimate_QoI(species, island, sex, year, bill_length_mm, bill_depth_mm, flipper_length_mm)

estimand 列表示待估计的目标量类别，其取值包括 MCATE、VIMP 等。term 列表示结果中所指的协变量（如果相关的话）。例如，一个计算出来的 MCATE 指向某个特定协变量，就由这一列指示。value 与 level 两列表示某个 term 内部更细粒度的划分：前者代表数值型取值，后者代表分类型取值。举例来说，对于 MCATE，若协变量是离散的，那么计算该 MCATE 时所处的取值会放在 level 列；若协变量是连续的，则会放在 value 列。因此，这两列各自都是类型稳定（type-stable）的。最后两列 estimate 与 std_error 的含义不言自明；它们的具体计算方式取决于所请求的特定目标量。

背景与解释

逐行读懂这张表，以及它揭示的因果结构。前 3 行是 species（物种）的分层 MCATE：Adelie 企鹅 −97.9、Gentoo 企鹅 +101、Chinstrap 企鹅 −7.70。这精确地还原了模拟时设定的真实效应——Gentoo +20%、Adelie −20%、Chinstrap 0%，且标准误（3–5）远小于效应量，说明估计非常精确。这要归功于 food_consumed_g 这个低噪声结局。

接下来的 island（岛屿）三行是一个极好的教学案例：Torgersen −94.2、Biscoe +47.1、Dream −49.7，看起来存在很强的「岛屿效应异质性」。但岛屿并不参与真实效应的生成！原因很简单：物种与岛屿高度相关（Torgersen 岛上几乎全是 Adelie，Biscoe 岛上 Gentoo 占比高）。由于 MCATE 只把其他变量边际化掉、不做条件化，这种混杂在边际效应中就会体现出来。

这正是 MCATE 与 PCATE 之别的临床含义所在。MCATE 回答的是「在实际人群中，岛屿 = Torgersen 这一类患者的平均疗效是多少」——它包含了该变量与真实效应修饰因子之间的关联，因此是可用于决策的（「我面前的病人来自 Torgersen 岛，预期疗效如何？」）。而 PCATE 试图回答「在固定其他变量不变时，岛屿本身的效应是多少」——除非处理与协变量联合随机化（即我们可以想象同时干预「住哪个岛」），否则这个量没有因果解释。把 MCATE 误读为「这个变量导致了疗效差异」是 HTE 分析最常见的错误之一。要区分二者，请看 VIMP 与联合模型，而不是单个 MCATE。

再看 sex 两行：male −7.35、female −9.85，标准误分别高达 7.77 与 7.27——两个估计的置信区间都宽宽地覆盖 0，没有证据表明性别修饰了疗效。year 三行同理。请把注意力放在标准误与效应量的相对大小上，而不是点估计的绝对大小。

这两段绘图代码的筛选条件 is.na(value) 与 is.na(level) 是理解结果结构的关键。回忆前文：value 装数值型细分位置（连续变量），level 装分类型细分位置（离散变量），两者互斥、其中之一必为 NA。因此 filter(..., is.na(value)) 正好挑出所有离散变量的行（画点＋误差棒），filter(..., is.na(level)) 正好挑出所有连续变量的行（画线＋阴影带）。这种「类型稳定」的设计让绘图筛选可以写得非常干净。

读图的两个层次。第一张图（离散变量）里，species 分面的三个点明显分开、置信区间都不跨 0，是真实的效应异质性；island 分面虽然看起来也有差异，但要记住那是「物种」这个真实修饰因子通过混杂映射过来的边际效应；sex 与 year 分面的区间都跨过虚线（0），没有证据支持效应修饰。

第二张图（连续变量，喙长／喙深／鳍长）的三条曲线应被读作：效应随这些形态学指标的变化没有显示出清晰模式，置信带很宽且大致覆盖 0 附近。这与模拟设定一致——这些变量不参与效应生成。facet_wrap(~term, scales = "free_y") 让各分面使用独立的纵轴尺度，便于看清每个变量的形状，但也意味着你不能跨分面比较效应大小——若需要比较，请去掉 scales = "free_y"。

背景与解释

怎么读这两张诊断图？

风险图（Risk）：横轴是各子模型的交叉验证风险（对连续结局即折外 MSE），越小越好；误差棒是 ±1.96 倍标准误。三个分面分别对应对照组结果模型、治疗组结果模型与效应曲面。看点是「集成是否真的优于（或至少不劣于）最好的单个学习器」——若最右侧（翻转后最上方）的学习器风险明显低于其他所有学习器，说明数据结构比较简单，某个学习器就能胜任。

系数图（Coefficient）：横轴是 SuperLearner 集成中分配给各子模型的权重，非负且总和为 1。请把它与风险图对照着读：风险最低的学习器通常拿到最高的权重。若出现明显的「低风险却低权重」，多半是因为它与另一个学习器高度相关，贡献被吸收了。

为什么诊断不是可选项？因为它们直接决定你对 MCATE 结论的信任程度。若「效应曲面」分面的风险很高，说明二阶回归对伪结局的拟合很差——此时你看到的 MCATE 曲线形状很可能主要是噪声；若某个学习器在集成中拿到了接近 1 的权重，说明其余候选模型都被交叉验证否定了，你的集成实际上退化成了单一模型，失去了集成带来的稳健性。建议做法：把这两张图与 MCATE、VIMP 图放在同一份附录里，作为分析可信度的证据一并报告。

背景与解释

VIMP 在临床上该怎么解读？纵轴的「Reduction in \(R^2\)」含义是：把某个协变量从效应联合模型中剔除后，模型的 \(R^2\) 下降了多少。它衡量的是该变量对解释疗效差异（而非结局本身）的贡献。

在本例中你应该期待：species（物种）的 VIMP 遥遥领先且误差棒远离 0——因为它是唯一真正参与效应生成的变量；island 可能也有一定数值（因为它与 species 高度相关），但应当明显小于 species；sex、year 与三个形态学指标的 VIMP 应接近 0 且置信区间跨过虚线。

这正是 VIMP 相对「逐个看 MCATE」的核心价值：MCATE 是边际量，混杂在协变量之间的关联会让它「看起来」有异质性；而 VIMP 基于联合模型，衡量的是「在已经控制了其他所有变量之后，这个变量还能额外解释多少效应变异」。因此把两者配合使用，就能把「真实的效应修饰因子」与「仅仅与效应修饰因子相关」的变量区分开——本例中 island 就是后者的典型。

预测因子 vs 预后因子。医学文献中极易混淆的一对概念：预后因子（prognostic factor）预测结局本身，预测因子（predictive factor）预测疗效差异。VIMP 在本包中衡量的是后者。一个能强烈预测疾病风险的生物标志物，其 VIMP 完全可能接近 0——这不矛盾，它只是不修饰疗效而已。开发伴随诊断／精准用药策略时，你要找的是预测因子。

三点注意事项。① VIMP 是联合模型的指标，高度相关的变量会互相稀释重要性，因此「两个都不显著」不等于「两个都不重要」。② VIMP 附带标准误，请只在误差棒完全位于 0 右侧时才断言存在效应修饰。③ VIMP 依赖「效应曲面模型拟合良好」这一前提，请务必先看上一节的诊断图确认。

复现分析

tidyhte 最大的好处之一，就是它能够重复相似的分析。

举例来说，要把上面用过的同一套分析施加到另一个结局上，只需下列代码：

results_mass <- penguins %>% produce_plugin_estimates(
  # 结局
  body_mass_g,
  # 处理
  treatment,
  # 协变量
  species, island, sex, year, bill_length_mm, bill_depth_mm, flipper_length_mm
) %>%
  construct_pseudo_outcomes(body_mass_g, treatment) %>%
  estimate_QoI(
    species, island, sex, year, bill_length_mm, bill_depth_mm, flipper_length_mm
  )

对这个结局而言，同样可以轻松地绘制出所有相同的量，并且结果可以方便地合并在一起。

results_all <- bind_rows(
  results %>% mutate(outcome = "food_consumed_g"),
  results_mass %>% mutate(outcome = "body_mass_g")
)

通过允许使用者灵活地组合 HTE 估计器，本包极大地减少了典型 HTE 分析所需的工作量——这类分析天然地涉及多个调节变量、多个模型与多个结局。

背景与解释

这一段演示的是「换结局」，但请注意哪一步被重跑了。produce_plugin_estimates() 与 construct_pseudo_outcomes() 都必须重跑（因为结局变了，结果模型与伪结局都变了），而 make_splits() 不需要重跑——交叉验证折应当在不同结局之间保持一致，这样才能干净地比较各结局的结果，也节省计算时间。配置项（recipe）更是完全不需要改动。

这一点对严谨的医学研究很重要：如果你对每个结局都重新随机切分交叉验证折，那么两个结局之间的任何比较都会混入「切分随机性」带来的差异。保持切分固定，结果才具有可比性与可复现性。配合 set.seed()，整份分析可以被完整重现。

关于多结局的多重比较：本段展示的 bind_rows() 让你可以一次性画出所有结局的森林图，非常方便。但请记住，跑 \(K\) 个结局就意味着做了 \(K\) 倍的推断。若属验证性分析，请事先确定主要结局并采用恰当的多重比较校正（如 Bonferroni、Holm 或 FDR）；用于探索性假设生成时，务必在论文中明确标注其探索性质，并说明需要独立验证。

结论

本文介绍了 tidyhte 包背后的概念，并给出了该包如何使用的示例。总的来说，本包的编写方式足够通用，因此某些特性可以以相对较少的工作量被添加进来。例如，增加新的插件模型，只需要提供若干配置信息以及标准化的 train / predict 方法即可。为 CATE 提供新的汇总方式（用于绘图）也同样如此，处理方式大体相同。这使得方法学家可以相对容易地把他们偏好的拟合方法接入进来，从而扩展 tidyhte 的功能。
