观察性数据分析教程

这一篇是 tidyhte 的观察性数据场景教程。它与实验数据分析教程在结构上完全平行，唯一的实质差别是：倾向得分不再已知，而必须用模型估计。正是这一个差别，让所有结论都依赖额外的识别假设，也让标准误明显变大。建议两篇对照着读。

简介

在这个示例分析中，我将演示如何使用 Kennedy（2023）的方法，在观察性研究（observational setting）中开展异质性处理效应分析。

本分析的重点是：使用机器学习集成（通过 SuperLearner）来估计干扰函数，然后给出一张包含条件处理效应估计值及其相应标准误的 tibble。

背景与解释

从实验走向观察性，你失去了什么？在实验教程里，随机化保证了处理分配 \(A\) 与潜在结局 \((Y(1),Y(0))\) 独立，也保证了倾向得分 \(\pi(x)\) 恰好已知。观察性数据里这两样都没有：医生根据患者的病情、年龄、合并症、社会经济状况来决定用不用这个药，于是 \(A\) 与 \(Y\) 通过协变量 \(X\) 纠缠在一起。

要把「相关」提升为「因果」，必须明确接受三条识别假设（详见方法细节）：

① 一致性（consistency） \(Y_i=Y_i(A_i)\)——观测到的结局就是该个体实际接受处理所对应的潜在结局；② 无未测量混杂（no unmeasured confounding / ignorability） \(A\perp(Y(1),Y(0))\mid X\)——在观测到的协变量之后，治疗决策与潜在结局无关；③ 正值性（positivity / overlap） \(\epsilon\le\pi(x)\le1-\epsilon\)——每种协变量组合的患者都有实质机会被分到两组。

其中第 ② 条无法用数据检验，只能靠学科知识论证。这决定了观察性 HTE 分析的证据等级天然低于 RCT：方法再先进，也只是把已测量的混杂处理干净。请务必配合有向无环图（DAG）梳理混杂路径、做敏感性分析（如 E-value），并在论文中如实说明这一局限。

模拟数据

如果使用真实数据，只需把这一段替换成相应的 readr::read_csv 调用（或等价方式），创建一个 tibble 即可。下文将假定这个 tibble 被存为 data。

请注意：数据类型既可以是连续型也可以是离散型，并且 tibble 中允许存在不被纳入任何后续分析的列。

set.seed(100)
n <- 500
data <- tibble(
  uid = 1:n
) %>%
  mutate(
    x1 = rnorm(n),
    x2 = factor(sample(1:4, n, prob = c(1 / 100, 39 / 100, 1 / 5, 2 / 5), replace = TRUE)),
    x3 = factor(sample(1:3, n, prob = c(1 / 5, 1 / 5, 3 / 5), replace = TRUE)),
    x4 = (x1 + rnorm(n)) / 2,
    x5 = rnorm(n),
    ps = plogis(x1 * 0.3 - as.double(x2) * 0.25 + x5 * 0.5),
    a = rbinom(n, 1, ps),
    y = (
      a + x1 - a * (x1 - mean(x1)) + (4 * rbinom(n, 1, 0.5) - 1) * a * (x2 == 2) +
        a * (x2 == 3) + 0.5 * a * (x2 == 4) +
        0.25 * rnorm(n)
    ),
    w = 0.1 + rexp(n, 1 / 0.9)
  )
背景与解释

与实验教程的关键差别就在这段代码里。实验教程中是 ps = rep(0.3, n)（人人都一样）后再随机分配；这里则是

ps = plogis(x1 * 0.3 - as.double(x2) * 0.25 + x5 * 0.5)，a = rbinom(n, 1, ps)

也就是说：接受处理的概率取决于协变量——x1 越大越可能接受处理，x5 越大越可能接受处理，x2 的水平越高反而越不可能接受处理（系数 −0.25）。这精确模拟了临床上的「混杂指征（confounding by indication）」：医生倾向于把新药用于病情更重（或更轻）的患者。

这正是观察性研究的核心困难：a 与 y 之间的关联里，混杂着 x1、x5、x2 的直接作用。若不调整，估计出来的「效应」只是这些变量预后作用的映射。tidyhte 在这一步要做的事，就是先用 SuperLearner 把 \(\pi(x)\) 估出来，再用它构造 AIPW 形式的伪结局来纠偏。

结局 y 的生成方式与实验教程完全相同，因此两篇教程的真实 CATE 结构一致：效应随 x1 线性下降、在 x2 上分层跳跃，x3/x4/x5 不参与异质性。这为对照阅读两篇教程提供了标准答案。

定义配方（Recipe）

倾向得分模型与结果模型

我们使用一组机器学习模型的集成来估计倾向得分与结局（T-learner）的插件估计，模型复杂度覆盖从线性模型、GAM 到正则化回归的广泛范围。在本例中，为了控制运行时间，没有纳入非线性模型，但只要把相应行取消注释，就可以轻松加入。

模型的每一个组件都提供一组超参数，算法会对这些超参数取完整的笛卡尔积，并估计所有由此产生的模型。例如，SL.glmnet 会扫描一个超参数（岭回归与 LASSO 之间的混合参数）；每一个超参数取值下的模型都会被估计并纳入集成。注意，SL.glmnet 会使用 cv.glmnet 自动调优正则化参数，因此它不作为一个超参数出现。

目标量（Quantities of Interest）

目标量（QoI）决定了结果以何种方式呈现给使用者。你可以把它理解为：决定了结果在最终图表中应当如何绘制。

为简洁起见，本例只以下面两种方式之一给出结果：

  • 离散型协变量：按层（stratified）估计，在该协变量的每一个不同水平上绘制条件效应。
  • 连续型协变量：使用 Calonico、Cattaneo 与 Farrell（2018）的 nprobust，通过局部线性回归估计效应曲面。类似地，可参考 Kennedy、Ma、McHugh 与 Small（2017）对这一做法的理论论证。结果在该协变量取值域上的 100 个分位数网格上给出。

此外提供的另一个目标量是：在一个（覆盖所有协变量的）条件效应联合模型上学习得到的变量重要性（variable importance）。所实现的方法见 Williamson、Gilbert、Carone 与 Simon（2020）。

hte_cfg <- basic_config() %>%
  add_propensity_score_model("SL.glm.interaction") %>%
  add_propensity_score_model("SL.glmnet", alpha = c(0, 1)) %>%
  add_propensity_score_model(
    "SL.glmnet.interaction", alpha = c(0, 1)
  ) %>%
  add_outcome_model("SL.glm.interaction") %>%
  add_outcome_model("SL.glmnet", alpha = c(0, 1)) %>%
  add_outcome_model("SL.glmnet.interaction", alpha = c(0, 1)) %>%
  add_outcome_diagnostic("RROC") %>%
  add_effect_model("SL.glm.interaction") %>%
  add_effect_model("SL.glmnet", alpha = c(0, 1)) %>%
  add_effect_model("SL.glmnet.interaction", alpha = c(0, 1)) %>%
  add_effect_diagnostic("RROC") %>%
  add_moderator("Stratified", x2, x3) %>%
  add_moderator("KernelSmooth", x1, x4, x5) %>%
  add_vimp(sample_splitting = FALSE)

背景与解释

与实验教程逐行对比，差别只有三行。实验教程里第一行是 add_known_propensity_score("ps")（把已知的随机化概率直接告诉包）；这里换成了三行 add_propensity_score_model(...)，用 SuperLearner 集成去估计倾向得分——成员包括含交互项的线性模型、弹性网络、含交互项的弹性网络。其余所有配置（结果模型、效应模型、诊断、调节变量、VIMP）两篇完全一致。

为什么倾向得分也要用集成学习？倾向得分在这里承担两个角色：一是作为逆概率加权的分母，二是与结果模型一起构成双重稳健保护。它的设定错误会直接传导为效应估计的偏倚。用 SuperLearner 估计 \(\pi(x)\)，意味着我们不再赌「logit 线性」这个参数形式是对的，而是让交叉验证在线性、含交互、正则化等多种形式之间自动权衡。

但请注意一项重要的实践补充：本教程没有做协变量平衡诊断。用 SuperLearner 得到低风险（预测准确）的 \(\hat\pi\)，不等于用它加权后协变量就平衡了——这两个目标并不完全等价。在真实的观察性研究中，请务必额外检查：

① 标准化均数差（SMD）：加权／匹配后，各协变量在两组间的 SMD 绝对值应小于 0.1；② 倾向得分分布重叠：画两组的 \(\hat\pi\) 直方图或镜像直方图，检查共同支撑区（common support）；③ 极端权重：若少数个体的 \(\hat\pi\) 接近 0 或 1，逆概率加权会产生极大权重、放大方差，此时应考虑修剪（trimming）或限定目标人群。tidyhte 的诊断输出覆盖结果模型与效应模型，但协变量平衡需要你自己补上。

背景与解释

请把这张表与实验教程的表并排放，这是本教程最重要的一次对照。两篇的真实 CATE 结构完全相同，数据生成过程的唯一差别是处理分配机制。对比 x1 的 MCATE：

实验教程：value 从 −1.80 到 −1.16，estimate 从 3.22 降到 2.56，std_error 约 0.13–0.17；
本教程：value 从 −1.79 到 −1.13，estimate 从 4.07 降到 2.96，std_error 约 0.21–0.56。

两个观察。① 标准误大了 2–3 倍。这是观察性数据必须付出的代价：倾向得分需要估计，估计的不确定性通过逆概率加权项进入伪结局，从而抬高了所有目标量的方差。这就是为什么「观察性研究的效应估计需要更大的样本量」。② 点估计略有偏移（4.07 vs 3.22）：在有限样本下，估计的 \(\hat\pi\) 与 \(\hat\mu\) 都会带来一定的有限样本偏差，双重稳健保证的是一致性（样本趋于无穷时偏差消失），不是有限样本无偏。

还请注意标准误的不均匀性：在 x1 取值低的一端（value = -1.79）标准误高达 0.556，而在高端只有 0.206。原因是混杂指征让 x1 低的个体接受处理的概率较低（ps 公式里 x1 的系数是 +0.3，x1 越小 ps 越小），那里接近正值性边界，逆概率加权放大了方差。这正是「正值性弱的地方估计不稳定」的直观体现——看图时请特别留意置信带在两端变宽的现象。

绘制集成系数

filter(results, grepl("SL coefficient", estimand)) %>%

  facet_wrap(~level) +
  coord_flip() +
  ggtitle("SuperLearner Ensemble") +
  theme_minimal()

背景与解释

怎么读这张 SuperLearner 集成系数图？横轴是各基学习器在集成中获得的权重（非负、总和为 1），误差棒是 ±1.96 倍标准误；两个分面分别对应对照组结果模型与治疗组结果模型。

注意本图只涉及结果模型的集成。代码中 facet_wrap 的 level 只保留了 "Control Response" 与 "Treatment Response" 两个水平——倾向得分模型的集成系数不在本图的筛选范围内。如果你也想检查倾向得分模型的集成是否工作正常，请把筛选条件里的 level 水平换成倾向得分模型对应的那一组（可先 unique(filter(results, grepl("SL coefficient", estimand))$level) 查看有哪些水平）。在观察性分析中，倾向得分模型的集成同样值得检查：若它被压缩成一两个学习器，或所有学习器的权重都集中在最灵活的模型上，往往提示处理分配机制较为复杂。

判读要点与实验教程相同：① 系数接近 0 的学习器基本被淘汰；② 拿到最高权重的学习器反映数据中最主要的信号形式（线性 / 需正则化 / 含交互）；③ 误差棒跨越 0 只是说明「这个学习器是否该进来」在统计上不确定，不影响集成整体的有效性；④ 不要把这张图当作「哪个模型最好」的检验，它是诊断工具而非推断工具。

背景与解释

怎么读这张风险（CV risk）图？横轴是各基学习器的交叉验证风险（对连续结局即折外 MSE），越小越好；误差棒是 ±1.96 倍标准误。三个分面分别是对照组结果模型、治疗组结果模型、效应曲面（二阶回归）。

三条判读规则：① 最上方（reorder(term, -estimate) 后风险最低的排在最上）的表现最好；② 把各学习器与集成整体比较——集成的风险若已接近最好的单个学习器，说明集成工作正常；③ 第三幅「Effect Surface」分面衡量二阶平滑模型对伪结局的拟合好坏，它决定你对 MCATE 曲线形状的信任程度。

本图的观察性专属提醒：风险值是尺度依赖的，因此不要把它与实验教程的图做绝对值比较——两篇的结局虽然生成方式相同，但这里的风险包含了倾向得分估计带来的额外变异。只在同一张图内部横向比较即可。

此外，与上一张系数图一样：如果你想一并检查倾向得分模型各子模型的交叉验证风险，请调整 level 的筛选范围。在观察性研究中，倾向得分模型的 CV 风险尤其值得看——若所有学习器的风险都接近「用边际频率预测」的基线，说明协变量对治疗决策几乎没有预测力，这反而提示混杂可能不严重（或者，你的协变量集没有抓住真正的决策依据）。

背景与解释

RROC 图怎么看？它是 ROC 曲线在回归问题上的类比：给模型的预测值加一个平移量 s，对每个 s 计算总的高估量（over-estimation，正残差之和）与低估量（under-estimation，负残差绝对值之和），前者画在横轴、后者画在纵轴。

判读规则：曲线越贴近坐标轴原点方向越好。圆点标记的是 s = 0（模型不做任何平移）时的位置，也就是模型原始状态下的高估／低估情况——请重点看这个点。若它明显偏离原点、且横轴（高估）与纵轴（低估）数值不对称，说明模型存在系统性偏移。

这一点在观察性研究中格外重要。如果结果模型系统性高估治疗组的结局，那么由 \(\hat\mu_1-\hat\mu_0\) 构成的插件估计就会系统性偏高，进而让「治疗有效」的结论过于乐观。RROC 图是你捕捉这类系统偏移的主要工具；配合双重稳健结构，偏差会在大样本下被纠正，但在有限样本下仍可能残留。coord_flip() 只是翻转坐标轴便于阅读，不改变判断。

三个分面中，「Effect Surface」分面通常最「难看」，因为伪结局本身包含逆概率加权项、噪声很大——这是正常现象，不必过度紧张。

绘制变量重要性（VIMP）

ggplot(filter(results, estimand == "VIMP")) +
  geom_abline(intercept = 0, slope = 0, linetype = "dashed") +
  geom_pointrange(
    aes(
      x = term,
      y = estimate,
      ymin = estimate - 1.96 * std_error,
      ymax = estimate + 1.96 * std_error
    )
  ) +
  expand_limits(y = 0) +
  scale_x_discrete("Covariate") +
  scale_y_continuous("Reduction in R² from full model") +
  coord_flip() +
  ggtitle("Covariate Importance") +
  theme_minimal()

背景与解释

VIMP 图在临床上该怎么解读？横轴是「把某协变量从效应联合模型中剔除后，\(R^2\) 下降了多少」，误差棒是 ±1.96 倍标准误。它衡量的是该变量对解释疗效差异的贡献，而不是对解释结局本身的贡献——这个区分是精准医学的核心。

判读要点：① 数值越大说明越能解释疗效异质性；② 只有误差棒完全位于 0 右侧的变量，才可以说「有证据表明它修饰了疗效」——跨过 0 的变量（本例中预期是 x3、x4、x5）没有统计学证据支持其效应修饰作用；③ VIMP 可以为负，此时通常直接视为「无贡献」。

观察性研究中的额外提醒。VIMP 建立在「效应曲面（联合）模型拟合良好」这一前提上，而该模型的输入是伪结局——伪结局的质量又取决于 \(\hat\pi\) 与 \(\hat\mu\)。因此在观察性数据中，VIMP 的标准误会更大、结论更脆弱：请对照本教程与实验教程两张 VIMP 图的误差棒宽度差异。若某变量的误差棒只是勉强跨过 0，请如实报告为「证据不足」，而不要因为点估计为正就宣称发现了效应修饰因子。

两个必须避免的误读。第一，VIMP 小不等于变量不重要——它可能是很强的预后因子（预测结局），却不是预测因子（预测疗效差异）。第二，VIMP 是联合模型的指标：高度相关的变量会互相稀释重要性，因此「两个都不显著」不等于「两个都不重要」。

绘制连续型协变量的 MCATE

for (cov in c("x1", "x4", "x5")) {
  gp <- ggplot(filter(results, estimand == "MCATE", term == cov)) +
    geom_abline(intercept = 0, slope = 0, linetype = "dashed") +
    geom_ribbon(
      aes(
        x = value,
        ymin = estimate - 1.96 * std_error,
        ymax = estimate + 1.96 * std_error
      ),
      alpha = 0.75
    ) +
    geom_line(
      aes(x = value, y = estimate)
    ) +
    expand_limits(y = 0) +
    scale_x_continuous("Covariate level") +
    scale_y_continuous("CATE") +
    ggtitle(paste("Marginal effects across", cov)) +
    theme_minimal()
  print(gp)
}

背景与解释

怎么读连续变量的 MCATE 曲线？实线是边际条件平均处理效应 \(\hat\tau(x)\)，阴影带是逐点的 95% 置信带，水平虚线是无效线（\(\tau=0\)），横轴是该协变量的 100 个分位数网格。

x1 的曲线明显单调下降，且整条曲线连同置信带都在 0 以上；x4 与 x5 基本水平——与模拟数据的真实结构一致（这两个变量不参与效应异质性）。

与实验教程对比，你会看到一个关键差别：置信带明显更宽，且在 x1 低端尤其宽。原因在「估计模型」一节已经说明：x1 低的个体接受处理的概率较低，接近正值性边界，逆概率加权在那里放大了方差。请把这种现象读作「这一带的数据支持较弱」，而不是「这一带的效应特别大」。

三条读图纪律。① 看趋势而非单点：平滑曲线上任意一点都不构成一次假设检验；要看整条曲线是否偏离水平、置信带是否整体偏离无效线。② 警惕两端：核平滑在数据稀疏的尾部方差更大，视觉上的「翘起」往往是噪声。③ 只有当某一段区间整段的置信带都不与无效线相交时，才有把握说「在这个取值范围内处理是有效（或有害）的」。

关于 MCATE 与 PCATE 之别，这里再强调一次。本图给出的是边际效应：其他协变量是按实际人群分布边际化掉的，而不是「控制住」的。因此曲线在不同 x1 处的差异，可能来自 x1 本身的效应修饰，也可能来自「x1 与真正修饰疗效的变量相关」。MCATE 回答的是可用于决策的问题（「x1 处于这个水平的患者，预期疗效是多少？」），而不是机制问题（「x1 是否导致了疗效差异？」）。要区分二者，请看 VIMP 与联合模型。

背景与解释

怎么读离散变量的分层 MCATE 图？离散变量不做平滑，而是在每一个水平上直接给出条件效应的点估计与 95% 置信区间，因此用点加误差棒（geom_pointrange）呈现。

判读要点：① 先看每个水平各自的区间是否与无效线相交——以此判断「在这个亚组内治疗是否有效」；② 再比较各水平之间——若两个水平的置信区间几乎不重叠，提示存在效应修饰；③ x2 的水平 1 区间明显更宽，因为该水平的抽样概率只有 1/100，样本极少。

在观察性数据中，水平 1 的不确定性还要再乘上一个隐患：回顾模拟数据，ps 的公式是 plogis(x1 * 0.3 - as.double(x2) * 0.25 + x5 * 0.5)——x2 的水平越低，接受处理的概率越高。但无论方向如何，当某个亚组样本极少时，其倾向得分的估计本身就极不稳定，逆概率加权会把这种不稳定性直接放大到效应估计上。真实临床数据中的对应情形是：罕见亚型、合并罕见基因突变的患者、或仅有个位数入组的中心。

关于亚组比较的统计陷阱：本图给出的每个区间都是亚组内部的置信区间，不是亚组间差异的置信区间。若要正式检验「水平 2 与水平 4 的疗效是否不同」，需要对差值构造估计量与标准误，而不能仅凭两个区间是否重叠来判断。
